NumPy 迭代数组

NumPy 迭代数组

#Python #Numpy
目录

简介

NumPy 的口号是”能用向量ized运算就别写循环”，但总有些时刻绕不开逐个访问元素：调试时打印内容、实现自定义聚合、与非 NumPy 库交互。这时就需要数组迭代。

NumPy 提供了从朴素到高效的完整工具链：for 循环、flat 迭代器、ndenumerate（带下标）、nditer（高性能迭代器）。重点理解一个事实：对多维数组直接 for，迭代的是第一维（一行一行来），而不是所有元素。

常用 API 详解

1. ndenumerate：元素 + 下标一起拿

给矩阵元素编号、生成坐标映射表时最顺手。

2. ndindex：只要下标

3. nditer：官方高性能迭代器

4. 多数组同步迭代：zip 的优雅替代

小结

  • 对多维数组 for 迭代的是第一维，要逐元素用 flat / ravel() / nditer
  • ndenumerate = 下标 + 值，ndindex = 只要下标，按需选
  • nditer 原地修改必须开 op_flags=['readwrite'] 且用 x[...] 赋值，直接 x = ... 无效
  • 迭代很慢：能写成 arr.sum()、arr*2 这种向量ized操作的，就别写循环
