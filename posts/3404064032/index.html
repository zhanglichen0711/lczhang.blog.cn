2.注释

3.常用快捷键

  • ctrl+/ 批量注释
  • ctrl+c 复制
  • ctrl+v 粘贴
  • ctrl+x 剪切
  • ctrl+z 撤销
  • ctrl+y 回滚
  • ctrl+d 快速复制粘贴本行
  • alt+z 快速换行
  • shift+ctrl+上下 移动该行位置
  • ctrl+alt+L 快速格式化
  • 按着alt 选中多行同时编辑
  • ctrl+f 查询
  • ctrl+r 替换

4.变量

  • 能够接收变量值的数据容器
  • 变量名=变量值
  • 变量本身没有数据类型，但他的值有数据类型
  • 变量是可以改变的，变量名=新变量值

5.数据类型

  • 字符串 string

  • 整数 int

  • 浮点数 float

  • 查看方式 type( )

6.数据类型转换

  • int(x) 将x转换为整数
  • float(x) 将x转换为小数
  • str(x) 将x转换为字符串
  • bool(x) 将x转换为布尔值

7.标识符

  • 类型
    • 变量（标识符）
    • 方法名（标识符）
    • 类名（标识符）
  • 规则
    • 内容限定
      • 只能包含数字、字母、下划线_、中文（不推荐使用），其中，数字不能作为开头
    • 区分大小写
      • abc和Abc为不同标识符
    • 不能使用关键字
      • 不能与python内置关键字重名
  • 规范
    • 见名知意
    • 用下划线_拼接
    • 英文字母全小写

8.运算符

  • 算数运算符

    + - * / 加减乘除

    // 取整除

    ** 指数运算

    % 取余数

  • 赋值运算符

    = 将=右侧的结果赋值给等式左侧的变量

    复合赋值运算符：将等式左侧的变量与右侧值先进行计算，再赋值给左侧变量

9.字符串扩展

  • 字符串拼接
    • print(‘字符串1’, ‘字符串2’) 字符串之间有空格
    • print(‘字符串1’+’字符串2’) 字符串之间没有空格，先执行代码运算，再输出计算结果
  • 百分号格式化
    • 占位符
      • %d 整数
      • %s 字符串
      • %f
        • % .2f 保留两位小数
        • % 5.2f 宽度保留5位，两位小数
    • print(‘字符串%d , %s , %f’ %(变量(int),变量(str),变量(float))
    • 几个占位符就对应几个变量
  • format格式化
    • print(‘字符串{},{},{}’.format(变量1,变量2,变量3)）
  • format简写
    • print(f’字符串{变量1}字符串{变量2}字符串{变量3}’）
    • 整数转小数 print(f’字符串{变量(整数): .2f}’）,保留两位小数

10.数据输入

  • 语法：input([提示的内容])
  • 输入语句的结果一定是字符串类型，可通过数据类型转换进行转换，int(input(输入内容))
  • 输入语句如果没有结束，不会执行后边的代码
  • 输入语句结束后会获取用户输入内容，可用变量进行接收保存，变量=input(输入内容)
