量化前后怎么评估：精度与速度的账

量化到底亏不亏？用同一套评测集对比 FP16 与 INT4 的精度，再算清速度与显存的账。

#评测 #模型量化
目录

量化不是”装上就完事”——你换了模型的权重精度，必须回答：质量掉了多少、速度与显存换回了多少、这笔交易值不值。这一篇给出量化评估的完整方法：精度怎么测、性能怎么测、账怎么算。这是量化工程里最容易被跳过、却最重要的环节。

精度评估：同题对比

核心方法：同一套评测集，FP16 与量化版各跑一遍，对比输出质量。

评估的三个层次（按成本从低到高）：

  1. 结构化任务自动比：分类、抽取、JSON 输出——直接比字段正确率，最容易量化；
  2. 通用基准：C-Eval 等学术集抽样——看通用能力退化幅度；
  3. 人工抽检生成质量：50 条代表性问答请业务专家打分——生成类任务最终裁判。

别用单条 prompt 判断——一次回答像不像不能代表整体质量。

关注两类退化信号

量化评估不能只看”平均分”，重点盯：

  1. 边界/长尾题目：量化误差在”容易的题目”上不明显，但难题目、精确引用、数学推理容易暴露退化——评测集要含这类题；
  2. 输出格式稳定性：量化模型偶尔会在格式上”飘”（JSON 不合法、漏字段）——把格式合规率单独统计。

经验法则：INT8 通常退化 <1%、INT4 多数任务 1~5%。如果 INT4 在你的领域评测里退化明显（>5%），考虑换方案（更细 group、或对敏感层不量化）。

小结

量化评估 = 同一评测集对比精度 + 压测对比性能 + 算清收益成本账。记住三个警惕：别用单条 prompt 判断、别只看平均分要盯边界题、INT4 退化明显时先试更稳方案。量化是把双刃剑——会用剑之前，先学会测剑。
