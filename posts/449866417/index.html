SQL约束

​ 数据类型本身就是一种约束，SQL约束是指在数据类型限定的基础上额外增加的要求。

​ 常见的约束：

​ 主键约束(PRIMARY KEY)

​ 其他约束：非空约束(NOT NULL)、唯一约束(UNIQUE)、默认值(DEFAULT)、外键约束(Foreign Key)

1. 主键约束

​ PRIMARY KEY 约束唯一标识数据库表中的每条记录

​ 主键必须包含唯一的值

​ 主键列不能包含 NULL 值

​ 每个表都应该有一个主键，并且每个表只能有一个主键

​ 主要作用: 在后续数据查询中, 根据主键查询效率最高（底层 有索引）

​ 唯一标识数据库表中的每条记录、加快数据的查找速度

​ 如何创建主键约束?

  • 方式一: 创建表时，在字段描述处，声明指定字段为主键
  • 方式二: 创建表时，在constraint约束区域，声明指定字段为主键
    • 格式: primary key (字段列表)
    • 字段列表需要使用小括号括住，如果有多字段需要使用逗号分隔。声明两个以上字段为主键，我们称为联合主键。
  • 方式三: 创建表后设置主键
    • 语法: alter table 表名 add primary key(主键字段列表…)

2. 非空约束

NOT NULL 约束强制列不接受 NULL 值。

NOT NULL 约束强制字段始终包含值。这意味着，如果不向字段添加值，就无法插入新记录或者更新记录。

3. 唯一约束

  • UNIQUE 约束唯一标识数据库表中的每条记录。

  • UNIQUE 和 PRIMARY KEY 约束均为列或列集合提供了唯一性的保证。

  • PRIMARY KEY 拥有自动定义的 UNIQUE 约束。

  • 请注意，每个表可以有多个 UNIQUE 约束，但是每个表只能有一个 PRIMARY KEY 约束。

4. 默认值

DEFAULT，默认值，插入数据时当不填写字段对应的值会使用默认值，如果填写时以填写为准。

格式: default 默认值

默认值: 如果值是非数值类型的 或者 关键词, 必须使用 引号引起来

放置位置: 字段的约束位置,如果有其他约束, 要求放置到其他约束的后面
