简介

加减乘除谁都会，但 NumPy 的算术函数有几个”懂行才用”的点：mod 和 remainder 的细微差别、reciprocal 倒数、整除的两种姿势，以及除零警告（Warning）而不是报错（Exception） 的设计哲学——运算出错不会中断程序，而是就地产生 inf/nan，让你算完统一清理。

这一篇把算术函数过一遍，重点讲清楚和 Python 原生行为不一样的地方。

常用 API 详解

1. mod / remainder / floor_divide：取余三兄弟

负数取余是经典面试题：np.mod(-7, 3) = 2（补成整除），np.fmod(-7, 3) = -1（直接砍）。日常分桶、周期对齐用 mod，移植 C 代码用 fmod。

2. reciprocal / negative / power

reciprocal 对整数数组会整型截断（1/10 变 0），求精确倒数先转 float：np.reciprocal(a.astype(float))。

5. divmod：商和余数一起拿

小结

  • 运算符 + - * / // % 和同名函数完全等价，团队协作时代码里常混用，都要看得懂
  • 负数取余：mod/remainder 跟随除数符号，fmod 跟随被除数符号，分桶场景用前者
  • NumPy 除零只警告不报错，产出 inf/nan——算完用 np.isfinite 清洗是标准动作
  • 涉及金额的浮点运算，先乘100转整数再算，能躲开 0.1+0.2 式的精度坑
