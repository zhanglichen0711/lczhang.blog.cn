一、类的基本使用

1. 定义类

  • class 类名:
  • class 类名():
  • class 类名(object):
  • 类名规范：大驼峰写法 FirstName

2. self 的使用

  • 谁调用了这个方法，self就是谁
  • 内置参数，系统自动传递参数，无需关注来源

3. 对象属性的差异化

  • 对象属性的差异化
    • 对象.属性名=属性值，给对象添加不同属性
    • self 指的是不同的对象，可通过不同对象获取不同属性

4. 魔法方法

  • 在特定情况下自动调用的方法
    • __ init __ 创建对象时自动执行
    • __ str __ 打印对象时自动调用
    • str(对象) 类型转换时自动调用
    • __ del __ 删除的时候自动调用

5. 案例

二、面向对象的三大特性

1. 封装

  • 把属性和方法写到类里
  • 私有化
    • 只能在类内部使用，不能在类外部使用
    • 私有属性
      • __属性
    • 私有方法
      • __方法()
    • 访问私有
      • _类__属性/方法

2. 继承

  • 子类可以同时继承多个父类
    • 先有的先继承，后来的找不同
  • 重写
    • 把父类的属性值改成当前这个值
  • 没有的才继承，已有的不继承，如果要继承多个，按顺序继承
  • 类.mro() 查看类的继承关系

3. 多态

  • python是弱类型语言，没有严格意义上的多态
  • 不同对象调用相同方法可以实现不同效果

三、面向对象

1. super关键字

作用：找到当前类型的下一级mro继承关系

类的动态属性和方法的继承

2. 静态方法和类方法

1.如果不需要创造多个实例对象，可以选择单例模式

2.如果需要创造多个不同的实例对象，选择工厂模式

3.如果类里面没有使用self,改造成staticmethod

4.如果单例模式想要使用类的属性，直接类.属性

如果一个变量无法访达，就会被认定为垃圾，系统会自动回收这个变量
