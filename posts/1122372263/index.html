NumPy 位运算

NumPy 位运算

#Python #Numpy
目录

简介

位运算直接操作二进制位：与、或、异或、取反、移位。它平时不显山露水，但潜伏在三个高频场景里——权限标志位（一个 int 存十几种开关）、图像二值化/掩码（0/1 位图）、状态压缩（遗传算法、位棋盘）。

NumPy 的位运算函数作用在整个数组上，配合整数类型，一次能处理百万个位标志，这正是 Python 循环做不到的。

常用 API 详解

1. bitwise_and / or / xor：掩码与差异检测

2. invert 与掩码取反

3. left_shift / right_shift：打包与解包

4. binary_repr / packbits：观察与打包位串

小结

  • 一组布尔开关不要存 10 个字段，一个整数的 10 个二进制位就够，NumPy 位运算可整体批量处理
  • & 判存在、| 合并、^ 找差异/翻转 0/1、~ 按位取反（uint 会得到 255-x）
  • 0/1 掩码翻转用 ^ 1，别用 ~（除非你真想要按字节取反）
  • packbits/unpackbits 是位串和字节的转换桥梁，通信协议、压缩场景常见
