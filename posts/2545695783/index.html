目录

一、KNN算法

1. 概念

  • K-近邻算法
    • 寻找与最近邻的K个样本，对未知样本进行预测
    • 样本的距离通过欧氏距离来度量

2. 分类

  • 基于选出的样本标签进行投票，出现次数最多的类别
    • sklearn.neighbors.KNeighborsClassifier

3. 回归

  • 基于选出的样本标签，求其平均值
    • sklearn.neighbors.KNeighborsRegressor

4. API的使用

5. 特征预处理

  • 归一化

    • sklearn.preprocessing.MinMaxScaler

    • 异常点对结果的影响较大

  • 数据标准化
    • sklearn.preprocessing.StandardScaler
    • 少量的异常点对于平均值的影响并不大

6. 超参数选择

  • 交叉验证
    • 数据集的划分：将训练集划分为 n 份，一份做验证集，其他做训练集
  • 网格搜索
    • 获取最优的超参数
      • best_params_：最优超参
      • best_score_：最好结果
      • best_estimator_：最佳模型
      • cv_results_：每次交叉验证后的验证集和训练集的准确率结果

7. 分类问题评估

  • 混淆矩阵
    • TP：真实值是正例 ，预测值为正例（正确）
    • FN：真实值是正例，预测值为反例（错误）
    • FP：真实值是反例，预测值为正例（错误）
    • TN：真实值是反例，预测值为反例（正确）

  • 精确率𝑃𝑟𝑒𝑐𝑖𝑠𝑖𝑜𝑛
    • 查准
    • P = TP / ( TP + FP )：猜对的正样本 / 预测的正样本数量
  • 召回率𝑅𝑒𝑐𝑎𝑙𝑙
    • 查全
    • P = TP / ( TP + FN )：猜对的正样本 / 真实的正样本数量
  • F1-score
    • 2 * 精确率 * 召回率 / (精确率+召回率)
    • 综合能力、综合稳定性指标

二、决策树

1.原理

  • 强制二分
  • 通过基尼值选择最优的划分节点
    • gini值=2(p正)(1-p正)
    • 基尼值越小划分质量越高
  • 重复逐层划分
  • 剪枝，防止过拟合

2.API

  • Criterion:特征选择标准
  • min_samples_split:内部节点再划分所需最小样本数
  • min_samples_leaf:叶子节点最少样本数
  • max_depth:决策树最大深度
  • model = DecisionTreeClassifier()
  • 独热编码
    • one-hot
    • new_x = pd.get_dummise(x) 把字符串改成布尔值

3. 波士顿房价预测

4. 剪枝

  • 预剪枝
    • 决策树生成过程中，每个节点划分前进行
    • 训练测试时间少，有欠拟合风险
    • 兜底
  • 后剪枝
    • 先生成完整决策树，自底向上地对非叶节点进行考察
    • 训练测试时间多，泛化能力强
    • 优化
