Numpy 数组操作

Numpy 数组操作

#Python #Numpy
目录

简介

数据从进来到成型，中间全是”变形记”：清洗完要拼接、维度不对要重塑、批次间要切分、冗余元素要增删。NumPy 数组操作分三大门派：

  • 改形状：reshape、transpose、flatten……只动”形状”不动数据
  • 拼与切：concatenate、stack、split……多合一、一分多
  • 增删改：append、insert、delete、unique

记住一个原则：改形状的操作几乎都返回视图（零拷贝），增删操作几乎都返回拷贝。前者快但要小心共享内存，后者安全但费内存。

常用 API 详解

1. flatten vs ravel：两种展平

2. 拼接三兄弟：concatenate / hstack / vstack

3. stack：新增维度堆叠

4. split / hsplit / vsplit：切分

5. append / insert / delete：增删元素

6. unique：去重 + 排序 + 计数

小结

  • reshape(-1) 万能展平；ravel 是视图、flatten 是拷贝，改数据前想清楚要哪种
  • 拼接记 concatenate(axis=...) 就够了，hstack/vstack 只是它的语义化包装
  • append/insert/delete 每次都全量拷贝，循环里调用是 O(n²) 陷阱，应预分配或用列表收集后一次 np.array()
  • unique(return_counts=True) 一行顶 Counter + sorted 两行
