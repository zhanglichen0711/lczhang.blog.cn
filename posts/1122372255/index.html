NumPy 创建数组

NumPy 创建数组

#Python #Numpy
目录

简介

一切 NumPy 操作都始于”先有一个数组”。创建数组的方式远不止 np.array() 一种：想要全 0、全 1、单位矩阵，有专门的工厂函数；想要随机数据，有 random 模块；想要从 Python 结构转换，asarray 更合适。选对创建方式，代码更短、意图更清晰、性能也更好。

这篇文章把最常用的创建手段一网打尽，重点是 array / zeros / ones / full / eye / arange / linspace / 随机系列这”八大金刚”。

基本用法

empty 的值是内存里残留的随机数据，用之前必须自己赋值，否则结果不可预测——这是新手大坑。

常用 API 详解

1. full：填充任意值

2. eye：单位矩阵

3. zeros_like / ones_like：照着别人的样子造

4. random 系列：随机数组

5. asarray：转换不拷贝

小结

  • 数值占位用 zeros/ones/full，形状模仿用 *_like 家族，随机数统一走 default_rng
  • empty 只分配不初始化，速度最快但内容是垃圾值，务必先填充再使用
  • 输入可能是 ndarray 时用 asarray 避免无谓拷贝
  • 新代码推荐 np.random.default_rng(seed=42)，老的 np.random.seed 全局状态写法可复现性差，逐步淘汰
