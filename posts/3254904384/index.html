python 判断、循环语句

一、分支语句

1. 单分支

  • 控制一个代码段是否执行

2. 双分支

  • 控制两个代码段是否执行

3. 多分支

  • 控制多个代码段是否执行

4. 分支嵌套

  • 使用单分支或双分支或多分支结合（通过缩进实现）

二、循环语句

1. while循环

1.1 死循环

  • 条件成立，无限循环

1.2 循环

  • 控制死循环，从而实现业务
  • 核心三要素
    • 初始变量
    • 结束条件
    • 变量修改

2. for循环

  • 总结
    • for循环就是用于循环内容的，不会出现死循环
    • for循环里的临时变量就是内容的每一项
    • 内容一定是一个可迭代对象：字符串、range()、列表、元组、集合、字典

1.1 range语句

  • range(num) 一个参数
    • 获得从0开始，到num结束，不包含num（使用最多）
  • range(num1,num2) 两个参数
    • 获得从num1开始，到num2结束，不包含num2
  • range(num1,num2,step) 三个参数
    • 获得从num1开始，到num2结束，不包含num2，步距为step

1.2 临时变量问题

  • 循环内的临时变量能在外部使用，但不推荐
  • 在循环外要使用循环内临时变量，先在外部定义个变量，再用变量存储循环内的值
  • 如果有多层循环嵌套，每个临时变量的变量名不能重复

1.3 跳出循环

1.3.1 continue

  • 跳过当前循环，本次循环后续代码不执行
  • 可能中断变量更新，形成死循环

1.3.2 break

  • 结束整个循环，本次循环后续代码不执行，后续的循环也不执行
