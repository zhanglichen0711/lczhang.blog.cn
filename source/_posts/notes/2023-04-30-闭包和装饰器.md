## 1. 闭包

- 闭包思想：绕过垃圾回收机制的高级编程技巧
- 闭包的实现：
  - 1.有嵌套
  - 2.有引用
  - 3.有返回
  - 闭包的作用：延申变量的作用域范围

```python
def outer_fn():
    count = 0
    # 1.有嵌套
    def inner_fn():
        # global 访问全局变量
        # nonlocal 访问外部函数变量
        nonlocal count
        # 2.有引用
        count+=1
        print(f"当前count是{count}")
    # 3.外部返回内部函数的函数名
    return inner_fn #没有括号！防止AI!
fn = outer_fn() #fn是一个函数
```

## 2. 装饰器

### 2.1 传统方法

```python
# 定义装饰函数
def out_fn(fn):
    # 有嵌套
    def login():
        # 有额外功能
        print('登录')
        # 有引用
        fn()
    # 有返回
    return login
# 定义要被装饰的函数
def comment():
    print('评论')
# 装饰函数并用新变量接收装饰函数的返回值
new_comment=out_fn(comment)
# 调用函数
new_comment()
```

### 2.2 语法糖

```python
# 定义装饰函数
def out_fn(fn):
    def login():
        print('登录')
        fn()
    return login
# 语法糖
@out_fn
def comment():
    print('评论')
# 调用函数
comment()
```

### 2.3 装饰器使用场景

#### 2.3.1 无参无返回

```python
# 定义任务计时函数：
import time
def task_time(fn):
    # 有嵌套
    def inner():
        # 任务开始时间
        start_time=time.time()
        # 有引用
        fn()
        # 任务结束时间
        end_time=time.time()
        print(f'函数{fn.__name__}耗时{end_time-start_time}秒')
    # 有返回
    return inner
# 装饰器语法糖
@task_time  # 无参无返回值
def task1():
    print(5**20)
    time.sleep(2)
task1()
```
