## SQL约束

​		数据类型本身就是一种约束，SQL约束是指在数据类型限定的基础上额外增加的要求。

​		常见的约束：

​		主键约束(PRIMARY KEY)

​		其他约束：非空约束(NOT NULL)、唯一约束(UNIQUE)、默认值(DEFAULT)、外键约束(Foreign Key)

### 1. 主键约束

​		PRIMARY KEY 约束唯一标识数据库表中的每条记录

​		**主键必须包含唯一的值**

​		**主键列不能包含 NULL 值**

​		每个表都应该有一个主键，并且每个表**只能有一个主键**

​		主要作用:  在后续数据查询中, 根据主键查询效率最高（底层 有索引）

​		唯一标识数据库表中的每条记录、加快数据的查找速度

​		如何创建主键约束?

* 方式一:  创建表时，在字段描述处，声明指定字段为主键

```sql
# 创建用于演示约束的数据库
drop database if exists day03_constraint;
create database day03_constraint;
use day03_constraint;
-- 方式一: 在创建表的时候, 直接在对应的字段后面的约束位置添加主键约束
-- 需求1: 构建persons表, 表中有 id last_name first_name address city字段,  需要为id设置主键
drop table if exists day03_constraint.persons1;
create table day03_constraint.persons1(
  id int primary key,
  last_name varchar(20),
  first_name varchar(20),
  address varchar(20),
  city varchar(20)
);

```

* 方式二:  创建表时，在constraint约束区域，声明指定字段为主键
  * 格式: primary key (字段列表)
  * 字段列表需要使用小括号括住，如果有多字段需要使用逗号分隔。声明两个以上字段为主键，我们称为联合主键。

```sql
-- 方式二: 在创建表的时候, 在表的 constraint 约束位置, 添加主键约束
-- 需求2: 构建persons表, 表中有 last_name first_name address city字段, 需要为last_name first_name 共同设置主键
-- 联合主键: 指的将表中多个字段合并在一起构建一个主键约束, 通过多个字段来唯一的确定表中某一条数据
drop table if exists day03_constraint.persons2;
create table day03_constraint.persons2(
  last_name varchar(20) ,
  first_name varchar(20),
  address varchar(20),
  city varchar(20),
  primary key (last_name,first_name) 
); 
```

* 方式三:   创建表后设置主键
  * 语法: alter table 表名 add primary key(主键字段列表...)

```sql
-- 方式三: 创建表后, 添加主键
-- 语法: alter table 表名 add primary key(字段列表);8
-- 需求3: 构建persons表, 表中有 last_name first_name address city字段, 构建后, 手动为last_name first_name 共同设置主键
drop table if exists day03_constraint.persons3;
create table day03_constraint.persons3(
  last_name varchar(20) ,
  first_name varchar(20),
  address varchar(20),
  city varchar(20)
);

-- 添加主键:
alter table day03_constraint.persons3 add primary key(last_name,first_name);

```

如何删除主键约束:

```sql
ALTER TABLE Persons DROP PRIMARY KEY;
```

验证主键约束:

```sql
-- 主键约束的相关演示:
-- 演示 向单一主键表数据处理
insert into day03_constraint.persons1 values (1,'三','张','南京市雨花台区','南京市'); # 初次插入 可以正常插入成功

# 再次插入 直接报错 (主键冲突) Duplicate entry '1' for key 'persons1.PRIMARY'
# 错误原因: 在表中 已经有了一条主键为1的数据, 再次插入主键为1的数据, 就会报错
insert into day03_constraint.persons1 values (1,'三','张','南京市雨花台区','南京市');
-- 思考: 如果将ID更改为2 是否可以插入呢? 可以的, 只要主键不冲突, 也没有其他约束 就可以正常插入
insert into day03_constraint.persons1 values (2,'三','张','南京市雨花台区','南京市');
insert into day03_constraint.persons1 values (3,NULL,NULL,'南京市雨花台区','南京市');

# 尝试 给主键设置为NULL  直接报错(不能为NULL)  Column 'id' cannot be null
insert into day03_constraint.persons1 values (NULL,'三','张','南京市雨花台区','南京市');

-- 演示: 联合主键
-- 初次插入: 可以正常插入
insert into day03_constraint.persons2 values ('四','李','南京市雨花台区','南京市');
-- 再次插入:  报错   主键冲突  Duplicate entry '四-李' for key 'persons2.PRIMARY'
insert into day03_constraint.persons2 values ('四','李','南京市雨花台区','南京市');

-- 思考 以下SQL 是否可以插入成功 :  可以成功的, 两个字段联合在一起 能够唯一的指定一条数据就可以
insert into day03_constraint.persons2 values ('五','李','南京市雨花台区','南京市');
insert into day03_constraint.persons2 values ('五','王','南京市雨花台区','南京市');

-- 思考 以下SQL 是否可以插入成功 : 非空性 是要求联合主键中的每个字段都要保证非空性
insert into day03_constraint.persons2 values (NULL ,'赵','南京市雨花台区','南京市'); #  Column 'last_name' cannot be null
insert into day03_constraint.persons2 values ('七',NULL,'南京市雨花台区','南京市'); # Column 'first_name' cannot be null

-- 如何删除唯一约束呢?
alter table  day03_constraint.persons2 drop primary key ;
-- 如何去掉非空呢? 一会讲
```

自动增长列:

- 我们通常希望在每次插入新记录时，数据库自动生成字段的值。

- 我们可以在表中使用 auto_increment（自动增长列）关键字，自动增长列类型必须是整形，自动增长列必须为键(一般是主键)。

演示:

```sql
-- 自动增长列: auto_increment
/*
    作用: 一旦给某个字段添加了此关键词,该列的值就会自动的增长, 每一次插入数据, 如果不给这一列赋值 即会自动增长

    使用要求:
        1- 列的数据类型必须为整数
        2- 列必须是一个键(一般就是主键)

 */
-- 需求:  构建persons表, 表中有 id last_name first_name address city字段, 需要为id设置主键  同时要求ID是自动增长列
drop table if exists day03_constraint.persons4;
create table day03_constraint.persons4(
  id int primary key auto_increment,
  last_name varchar(20),
  first_name varchar(20),
  address varchar(20),
  city varchar(20)
);

-- 尝试插入数据:
-- 在插入数据的时候, 不给主键赋值, 此时就会基于自动增长方案执行, 默认从 1开始 每次增加 1
insert into day03_constraint.persons4 (id, last_name, first_name, address, city) values (NULL,'三','张','南京市雨花台区','南京市');
insert into day03_constraint.persons4 (last_name, first_name, address, city) values ('三','张','南京市雨花台区','南京市');
-- 如果给ID直接赋值会有什么效果呢?
-- 如果你自己赋值了, 按照你赋值的来, 前提要保证主键的唯一性
insert into day03_constraint.persons4 (id, last_name, first_name, address, city) values (100,'三','张','南京市雨花台区','南京市');

-- 如果在重新添加数据呢. 不给主键赋值 会有效果呢?
insert into day03_constraint.persons4 (last_name, first_name, address, city) values ('三','张','南京市雨花台区','南京市');


-- 也可以设置自动增长列起始默认值:
alter table day03_constraint.persons4 AUTO_INCREMENT=10000;
-- ID就是从10000开始
insert into day03_constraint.persons4 (last_name, first_name, address, city) values ('三','张','南京市雨花台区','南京市');

```

- 扩展说明:  默认AUTO_INCREMENT 的开始值是 1，如果希望修改起始值，请使用下列 SQL 

```sql
alter table persons AUTO_INCREMENT=100
```

### 2. 非空约束

NOT NULL 约束强制列不接受 NULL 值。 

NOT NULL 约束强制字段始终包含值。这意味着，如果不向字段添加值，就无法插入新记录或者更新记录。

```sql
-- 非空约束: not null
/*
    特点:
      非空性  被标记列,该列的值必须保证不能为空
      非空约束可以在一个表中设置多个
 */
-- 需求: 构建person表, 有 id、last_name、first_name、address、city 字段， 要求 id、last_name 不接受null值, 并验证测试
drop table if exists day03_constraint.persons5;
create table day03_constraint.persons5(
  id int not null ,
  last_name varchar(20) not null,
  first_name varchar(20),
  address varchar(20),
  city varchar(20)
);

# 尝试添加数据
# 添加正常的数据
insert into day03_constraint.persons5 (id, last_name, first_name, address, city) values (1,'三','张','南京市雨花台区','南京市');
-- 尝试给ID 赋值为NULL ID有非空约束, 直接报错  Column 'id' cannot be null
insert into day03_constraint.persons5 (id, last_name, first_name, address, city) values (NULL,'三','张','南京市雨花台区','南京市');
-- 尝试给last_name 赋值为NULL last_name有非空约束, Column 'last_name' cannot be null
insert into day03_constraint.persons5 (id, last_name, first_name, address, city) values (2,NULL,'张','南京市雨花台区','南京市');

-- 尝试给first_name赋值为NULL  first_name没有非空约束  可以插入
insert into day03_constraint.persons5 (id, last_name, first_name, address, city) values (2,'四',NULL,'南京市雨花台区','南京市');

-- 尝试给last_name 赋值为'', 请问是否可以插入呢? 可以插入, 所以说 '' 和 NULL 是不一样的 认为 ''有值的, 只不过是一个空字符串而已
insert into day03_constraint.persons5 (id, last_name, first_name, address, city) values (2,'','张','南京市雨花台区','南京市');

-- 如何删除非空约束呢?
-- alter table day03_constraint.persons5 change id id int not null;  不写not null 就是删除约束 写了 就是增加该约束
-- modify 不能修改列名, 只能修改列的属性
-- alter table day03_constraint.persons5 modify id int;  不写not null 就是删除约束 写了 就是增加该约束
```

### 3. 唯一约束

- UNIQUE 约束唯一标识数据库表中的每条记录。

- UNIQUE 和 PRIMARY KEY 约束均为列或列集合提供了唯一性的保证。

- PRIMARY KEY 拥有自动定义的 UNIQUE 约束。

- 请注意，每个表可以有多个 UNIQUE 约束，但是每个表只能有一个 PRIMARY KEY 约束。

- 添加唯一约束:

```sql
-- 唯一约束: UNIQUE
/*
  特点:
    被标记的列, 必须保证唯一性, 不能有重复值 但是可以为NULL
    一个表中可以有多个唯一约束
 */
-- 需求1: 构建person表, 有 id、last_name、first_name、address、city、phone 字段， 要求phone字段必须唯一, 并验证测试
drop table if exists day03_constraint.persons6;
create table day03_constraint.persons6(
  id int,
  last_name varchar(20),
  first_name varchar(20),
  address varchar(20),
  city varchar(20),
  phone varchar(20) unique
);

-- 测试:
-- 正常添加:
insert into day03_constraint.persons6 values (1,'三','张','南京市雨花台区','南京市','13814253621');

-- 尝试再次执行 : 触发了唯一键冲突(有重复值) 直接报错 Duplicate entry '13814253621' for key 'persons6.phone'
insert into day03_constraint.persons6 values (1,'三','张','南京市雨花台区','南京市','13814253621');

-- 尝试添加Null值: 可以接收NULL, 也可以接受多个NULL
insert into day03_constraint.persons6 values (1,'三','张','南京市雨花台区','南京市',NULL);


-- 需求2: 构建person表, 有id、 last_name、first_name、address、city、phone 字段， 要求ID为主键， 同时姓名必须唯一 ,

drop table if exists day03_constraint.persons7;
create table day03_constraint.persons7(
  id int primary key ,
  last_name varchar(20) unique ,
  first_name varchar(20) unique,
  address varchar(20),
  city varchar(20),
  phone varchar(20)
);

-- 测试下
insert into day03_constraint.persons7 values (1,'三','张','南京市雨花台区','南京市',NULL);

-- 再次执行: Duplicate entry '1' for key 'persons7.PRIMARY'  会报错主键冲突错误
insert into day03_constraint.persons7 values (1,'三','张','南京市雨花台区','南京市',NULL);
-- 修改主键  此时报错 Duplicate entry '三' for key 'persons7.last_name' last_name唯一冲突
insert into day03_constraint.persons7 values (2,'三','张','南京市雨花台区','南京市',NULL);
-- 修改 last_name 内容, 此时报错 Duplicate entry '张' for key 'persons7.first_name'  first_name唯一冲突
insert into day03_constraint.persons7 values (2,'四','张','南京市雨花台区','南京市',NULL);
-- 修改 first_name 内容, 正常插入
insert into day03_constraint.persons7 values (2,'四','李','南京市雨花台区','南京市',NULL);

-- 想要插入 李五: 无法插入, 因为 李是重复  是不符合题意 现在的效果是 名和姓分别都不能重复
insert into day03_constraint.persons7 values (2,'五','李','南京市雨花台区','南京市',NULL);

-- 如何解决呢? 联合唯一键方案  类似于 联合主键
drop table if exists day03_constraint.persons8;
create table day03_constraint.persons8(
  id int primary key ,
  last_name varchar(20) ,
  first_name varchar(20),
  address varchar(20),
  city varchar(20),
  phone varchar(20),
  -- [constraint 键名字] unique(字段列表)   键名字 默认和字段名字一致, 如果是联合唯一键,默认为第一个字段的名字,建议联合唯一手动设置唯一键名字
  constraint last_first_unique  unique (last_name,first_name)  # 联合唯一
);

-- 验证:
insert into day03_constraint.persons8 values (1,'三','张','南京市雨花台区','南京市',NULL);

-- 修改主键和 其中一个名 或者 姓 观察是否可以成功
insert into day03_constraint.persons8 values (2,'四','张','南京市雨花台区','南京市',NULL);

-- 删除唯一约束
-- 格式: alter table 表名 drop key 键的名字;
-- 注意: 只有是键, 就必须使用 drop key 删除 不能使用change 或者 modify方案
alter table day03_constraint.persons8 drop key last_first_unique;
```

### 4. 默认值

DEFAULT，默认值，插入数据时当不填写字段对应的值会使用默认值，如果填写时以填写为准。

格式:  default 默认值

默认值:  如果值是非数值类型的 或者 关键词,  必须使用 引号引起来

放置位置: 字段的约束位置,如果有其他约束, 要求放置到其他约束的后面

```sql
-- 默认值: default
/*
    DEFAULT，默认值，插入数据时当不填写字段对应的值会使用默认值，如果填写时以填写为准。
    格式:  default 默认值
    默认值:  如果值是非数值类型的 或者 关键词,  必须使用 引号引起来
    放置位置: 字段的约束位置,如果有其他约束, 要求放置到其他约束的后面
*/
-- 需求: 构建person表, 有 id、last_name、first_name、address、city、phone 字段, 要求city字段默认值为北京，设置后验证测试
drop table if exists day03_constraint.persons9;
create table day03_constraint.persons9(
  id int primary key ,
  last_name varchar(20) ,
  first_name varchar(20),
  address varchar(20),
  city varchar(20) default '北京',
  phone varchar(20)
);
-- 测试
-- 完整数据插入:  你给定的数据是什么 就会插入什么 不会涉及到默认值
insert into day03_constraint.persons9 values (1,'三','张','南京市雨花台区','南京市','13812543625');
-- 对 city 不设置值 : 必须是不赋任何值, 哪怕NULL也不行
insert into day03_constraint.persons9(id, last_name, first_name, address, phone) values (2,'三','张','南京市雨花台区','1381243625');
-- 如果这样写, 结果是什么呢?  NULL  因为 这是我们手动赋值的内容
insert into day03_constraint.persons9(id, last_name, first_name, address,city, phone) values (3,'三','张','南京市雨花台区',NULL ,'1381243625');
-- 删除默认值 与 删除not null方案是一致的
```
