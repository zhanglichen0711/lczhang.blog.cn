### 2. 自定义函数

#### 2.1 无参数无返回值

- 定义函数
  - def + 函数名():
  - 函数体
- 调用函数
  - 函数名():

```python
def get_sum():                   # 定义函数
    x=int(input('请输入x：'))     #  函数体
    y=int(input('请输入y：'))
    total=0
    for i in range(x,y+1):
        total+=i
    print(f'x~y的值为{total}')
get_sum()                        #  调用函数
```

#### 2.2 有参数无返回值

- 定义函数
  - def + 函数名(形参):
  - 函数体
- 调用函数
  - 函数名(实参):
- 传入参数
  - 形参
    - 形式上的参数
    - 定义函数时的临时变量
  - 实参
    - 实际调用时传入的参数

```python
# x~y 的平均值函数
def get_sum(x,y):
    total=0
    for i in range(x,y+1):
        total+=i
    print(f'{x}~{y}的值为{total/(y-x+1)}')
get_sum(1,100)
```

#### 2.3 有参有返回值

- 定义函数
  - def + 函数名(形参):
  - 函数体
  - return + 内容  （不写内容默认返回None）
- 调用函数
  - 函数名(实参):
- 函数都是有返回值的，每个函数都会在最后一行默认加return None
- return可以返回一个内容，最终会作为函数运行的结果
- return后的代码都不会执行，可以中断函数执行

```python
#  x~y 的和函数
def get_sum(x,y):               # 定义函数及形参
    total=0
    for i in range(x,y+1):
        total+=i
    return total                # 返回total结果
result=get_sum(1,100)           # 传入实参，并接收返回结果
print(f'函数的结果是{result}')    # 打印结果
```
