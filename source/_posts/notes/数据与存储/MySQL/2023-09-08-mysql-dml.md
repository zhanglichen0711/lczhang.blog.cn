## DML数据库操作语言

作用: 对数据库的表中的记录进行相关的操作(添加数据、修改数据、删除数据)

### 1. 插入数据：insert

语法：

```sql
-- 向表中插入某些字段
insert into 表 (字段1,字段2,字段3..) values(值1,值2,值3..);

注意：
    值与字段必须对应，个数相同，类型相同
    值的数据大小必须在字段的长度范围内
    除了数值类型外，其它的字段类型的值必须使用引号引起（建议单引号）
    如果要插入空值，可以不写字段，或者插入 null
    表后的字段可以省略,一旦省略后, values后面需要填写该表的全部字段的值,必须按照表字段的顺序
```

### 2. 更新数据：update

语法：

```sql
-- 更新所有记录的指定字段
update 表名 set 需要修改的字段名1=修改后的值1,需要修改的字段名2=修改后的值2,...;
-- 更新符号条件记录的指定字段
update 表名 set 字段名=值,字段名=值,... where 条件;

注意：
	列名的类型与修改的值要一致
    修改值得时候不能超过最大长度
	除了数值类型外，其它的字段类型的值必须使用引号引起
```

需求：

```mysql
-- 更新数据操作:
/*
    语法格式:
        update 表名 set 字段1 = 值1,字段2=值2.... [where 条件]

        如果对表中某条或者某几条数据进行指定列的值修改操作, 需要使用 where 条件
        set 后面 主要用于设置对那个字段进行修改, 以及对应要修改为具体的值是多少
```

### 3. 删除表记录：delete

语法：

```sql
delete from 表名 [where 条件];
或者
truncate table 表名;
```

需求：

```sql
需求1： 删除商品表中，价格大于 5000元的商品  (price > 5000)

需求2： 清-- 删除表中数据
/*
    语法:
        delete from 表名 [where 条件]
        或
        truncate table 表名;  清空表

    发现 delete from 表名 和  truncate table 表名 都可以直接实现对表数据的清空操作, 那么有什么区别呢?

    区别1: 所属的SQL分类不同
      delete 属于 DML语句
      truncate 属于 DDL语句

    区别2:  执行机制不同
      delete : 将表中数据 是一条一条的执行删除操作
      truncate: 先将表直接删除, 然后 重新建表

    区别3: 对于表中自动增长列的处理方式不同
      delete 不会清空自动增长列所记录的增长的标记
      truncate 会直接将自动增长列的值恢复默认

    区别4: 对于事务处理也不同
      delete 可以被事务所管理
      truncate 不被事务所管理的

 */

# 需求1： 删除商品表中，价格大于 5000元的商品  (price > 5000)
delete  from day02_db.product where price > 5000;

# 需求2： 清空表操作(分类表 和 商品表 ,  分别使用二种方式)
delete from day02_db.product;
truncate table day02_db.category_test;空表操作(分类表 和 商品表 ,  分别使用二种方式)
```
