## 1. 交叉连接

概念：也叫无条件连接，将左表的每一行数据无差别和右表的每一行数据分别进行关联，组成新的数据。

语法:

```sql
select 字段名 from A表,B表;
或
select 字段名 from A表 [cross] join B表;
```

需求: 将分类表和商品表进行交叉连接

```sql
select
    *
from day05_mutiple_tab.table_category join day05_mutiple_tab.table_product where cid = category_id;
```

问题：笛卡尔积（交叉连接）很简单，为什么还需要有条件连接呢？

* 笛卡尔积（交叉连接）的结果行数可能非常恐怖！！！

* 笛卡尔积（交叉连接）的结果可能并不满足关联需求

## 2. 有条件连接

在实际表数据连接的过程中，经常需要在连接时跟上一个限制的连接条件，满足条件的数据行才能进行连接，这就是有条件连接。

对于有条件连接，共分为 4 种不同的连接方式：

* 内连接（INNER JOIN ... ON ...）

* 左外连接（LEFT OUTER JOIN... ON ...）

* 右外连接（RIGHT OUTER  JOIN... ON ...）

* 全连接（FULL OUTER  JOIN... ON ...）

基本语法结构:

```sql
SELECT
	* 
FROM 左表
INNER|LEFT|RIGHT|FULL JOIN 右表
ON 连接条件; -- 比如: ON 左表.列名 = 右表.列名
```

---

内连接: INNER JOIN，简写为 JOIN

* 返回两张表都满足连接条件的部分(交集)
* 左右两表关联时，满足关联条件的数据，才会出现在最终的关联结果中

左外连接: LEFT OUTER JOIN，简写为 LEFT JOIN

* 左侧+交集部分
* 左右两表关联时，除满足关联条件的数据会出现在最终的关联结果中，左表中不能和右边表联的数据也会出现，右表侧自动填充为NULL

右外连接: RIGHT OUTER JOIN，简写为 RIGHT JOIN

* 右侧+交集部分
* 左右两表关联时，除满足关联条件的数据会出现在最终的关联结果中，右表中不能和左表关联的数据也会出现，左表侧自动填充为NULL

全外连接:  FULL OUTER JOIN，简写为 FULL JOIN

* 左侧 + 交集部分 + 右则
* 左右两表关联时，除满足关联条件的数据会出现在最终的关联结果中，左右两表不能相互关联的数据也都会出现，对应侧自动填充为NULL
* 注意：MySQL数据库不支持全连接，需要将左连接和右连接的结果利用 UNION 关键字组合实现全连接的效果。

## 4. 子查询

​		概念：在一个 SELECT 语句中，嵌入了另外一个 SELECT 语句，那么被嵌入的 SELECT 语句称之为子查询语句，外部那个SELECT 语句则称为主查询(SQL的嵌套使用)。

​		**一个SQL语句的查询结果, 作为另一个SQL语句的输入**

​		作用：子查询是辅助主查询的

* 子查询的结果充当主查询的条件: 在where后面

* 子查询的结果充当主查询的数据源(临时表): 在 from的后面

* 子查询的结果充当主查询的查询字段 : 在 select 和 from的中间

```properties
/*
    概念:  一个SQL语句的结果作为另一个SQL语句的输入
 */
use day05_mutiple_tab;
-- 子查询: 一个SQL语句的查询结果 作为另一个SQL语句的输入

# 子查询的结果充当主查询的条件:
# 需求1: 查询当前商品大于平均价格的商品
-- 先 商品的平均价格
select round(avg(price),2) as price_avg from day05_mutiple_tab.table_product;  -- 1803.55

-- 查询商品的价格大于这个平均价格的商品信息 : 子查询
select
  *
from day05_mutiple_tab.table_product where price > (select round(avg(price),2) as price_avg from day05_mutiple_tab.table_product) ;

# 需求2: 查询价格最高的商品（价格最高的可能不只一个）
-- 先 找到最高的商品的价格是多少
select max(price) from day05_mutiple_tab.table_product;  -- 5000
-- 查询这个最高价格下有哪些商品信息
select
    *
from table_product where price = (select max(price) from day05_mutiple_tab.table_product);
# 子查询的结果充当主查询的数据源(临时表)
# 需求1: 查询不同类型的商品的平均价格，结果中包含分类的名称。
-- 多表查询
select
  cid,
  cname,
  round(avg(price),2) as avg_product
from day05_mutiple_tab.table_product p join day05_mutiple_tab.table_category c on p.category_id = c.cid
group by cid,cname;

-- 必须使用子查询
-- 先在商品表 查询每个分类下的商品平均价格
select category_id, round(avg(price),2) as avg_product from day05_mutiple_tab.table_product group by category_id;

-- 将上面的结果作为一张表 和 分类表关联
select
    c.*,
    tmp.avg_product
from day05_mutiple_tab.table_category c
       join (select category_id, round(avg(price),2) as avg_product from day05_mutiple_tab.table_product group by category_id) as tmp
          on c.cid = tmp.category_id;

-- 请改造为 with as
with t1 as (
     select category_id, round(avg(price),2) as avg_product from day05_mutiple_tab.table_product group by category_id
)
select
    c.*,
    t1.avg_product
from day05_mutiple_tab.table_category c
       join t1 on c.cid = t1.category_id;
# 需求2: 查询 价格在800~2000元的商品, 并显示对应分类名称
-- 第一步: 查询 价格在800~2000元的商品
select *  from day05_mutiple_tab.table_product where price >= 800 and price <= 2000;
select *  from day05_mutiple_tab.table_product where price between 800 and  2000;
-- 第二步: 将第一步的结果作为临时表 和 分类表 关联  获取分类的名称
select
    *
from (select *  from day05_mutiple_tab.table_product where price between 800 and  2000) as tmp
    join day05_mutiple_tab.table_category c on tmp.category_id = c.cid;

-- 关于将子查询作为表使用的另一种写法:
with t1 as (
    select *  from day05_mutiple_tab.table_product where price between 800 and  2000
)
select
    *
from t1 join day05_mutiple_tab.table_category c on t1.category_id = c.cid;
# 子查询的结果充当主查询的查询字段:
# 需求1: 计算每个商品的价格和商品整体的平均价格的差值
-- 商品的整体的平均价格
select round(avg(price),2) as avg_product from day05_mutiple_tab.table_product;
-- 计算商品和平均价格之间的差值
select
  pid,
  pname,
  price,
  flag,
  category_id,
  price - (select round(avg(price),2) as avg_product from day05_mutiple_tab.table_product) as '差值'
from day05_mutiple_tab.table_product;
-- 使用 充当表方式解决 : 可以使用笛卡尔积的思路 让表中每一条数据都和平均值进行关联
with t1 as (
  select round(avg(price),2) as avg_product from day05_mutiple_tab.table_product
)
select
    *,
    p.price - t1.avg_product as '差值'
from day05_mutiple_tab.table_product p join t1;
```
