### 1.1 数值函数

在编写SQL对数据处理和开发的过程中，经常需要对数字类型的数据进行处理操作。

数值函数分类：

* 小数位数处理

  **ROUND**、FORMAT、TRUNCATE、FLOOR、**CEIL**

* 求余数、求幂、随机数

  **MOD**、POW、RAND

```sql
导入资料中的tb_sales(每月销售表)
需求:
	计算每个月的销量占所有月份销量之和百分比(保留2位小数)
	查询结果字段: month、sales、sum(所有月份销售之和)、ratio(每月销量占所有月份销量之和的百分比)

-- 数值函数:
-- 四舍五入函数, 保留小数位: round
select round(3.123,2);

-- 小数截断: TRUNCATE(X,D)
select truncate(3.451,1); -- 返回 3.4  不进行四舍五入 直接截取指定的小数位


-- 向上取整函数: ceil()   向下取整函数: floor()
select ceil(3.000001); # 取这个小数最近的一个大于本身的整数, 如果本身就是一个整数,那么就是它自己
select floor(3.9999999); # 取这个小数最近的一个小于本身的整数, 如果本身就是一个整数,那么就是它自己

-- 求几次幂: 例如 3的2次方   pow(底数,指数)
select pow(3,3);

-- 随机值: RAND([N])  获取  0~1的随机数 如果传入N 会导致随时数固定
select rand();

-- 场景 可以实现数据打散 然后通过 limit 取样
-- SELECT * FROM tbl_name ORDER BY RAND();
```

### 1.2 字符串函数

在编写SQL对数据处理和开发的过程中，也经常需要对字符串类型的数据进行处理操作。

字符串函数分类：

* 大小写转换

  **LOWER**、**UPPER**

* 字符串反转、拼接、局部替换

  REVERSE、 REPEAT、**CONCAT**、**CONCAT_WS**、**REPLACE**

* 字符串截取

  **SUBSTR**、SUBSTRING、**LEFT**、**RIGHT**

* 字符串的字符个数以及存储长度

  CHAR_LENGTH、LENGTH

```mysql
-- Mysql的内置函数:
-- 字符串(文本)函数

-- 字符串的截取函数: SUBSTRING(字符串,起始值,获取多少个) SUBSTR()  起始值  1表示第一个  -1 表示倒数第一个
select substr('abcdefg',2); -- bcdefg  表示从第二个开始, 将后面的全部都获取
select substring('abcdefg',2,5); -- bcdef  表示从第二个开始,往后获取五个
select substring('abcdefg',-3); -- efg   表示从倒数的第三个开始,将后面的所有都获取
select substring('abcdefg',-6,2); -- bc 表示从倒数的第六个开始,将后面的所有都获取

-- 支持 从左侧 和 从右侧直接截取N个元素 left() right()
select left('abcdefg',3);  -- abc  从左侧直接获取3个元素
select right('abcdefg',3); -- efg  从右侧直接截取3个元素


-- 字符串转大写 和 小写的函数:   UPPER() 转换为大写   LOWER() 转换为小写
select upper('AbcDefG'); -- ABCDEFG
select lower('AbcDefG'); -- abcdefg

-- 将指定位置的数据替换为目标值: INSERT()
select insert('AbcDefG',3,2,'123'); -- 从第三个位置往后的2个,将其替换为123 (将 cD 更换为了 123)

-- 替换操作: REPLACE(str,from_str,to_str)  将字符串中指定元素替换为另一个元素
select replace('http://www.itcast.cn','t','A'); -- hAAp://www.iAcasA.cn

-- 字符串的反转操作: REVERSE(str)
select REVERSE('http://www.itcast.cn'); -- nc.tsacti.www//:ptth

-- 删除 字符串 左右二边的空内容(空格):  TRIM()  还有二个  LTRIM() 和 RTRIM 分别用于删除左侧或者右侧的空格
select trim(' a b c '); -- a b c  只删除 字符串左右二端空格 其他不关心
select ltrim(' a b c '); -- a b c   只删除了左侧的空格

-- 返回字符串的长度
select length('abc'); -- 3

-- 返回指定字符在字符串的位置: INSTR()
select instr('abcdecfg','c'); -- 3  告知第一次出现该元素的位置

-- 字符串拼接函数: concat  CONCAT_WS
select concat('abc','-','123','-','efg'); -- abc123efg 将给定几个字符串拼接在一起
select concat_ws('-','abc','123','efg'); -- abc-123-efg  根据给定的字符串 将后面的几个字符串拼接在一起

-- 导入资料中的users表
drop database if exists day06_fun;
create database day06_fun;
use day06_fun;
-- 需求: 编写一个 SQL 查询来修复名字，使得只有第一个字符是大写的，其余都是小写的

select
    user_id,
    concat(
        UPPER(left(name,1)),  -- 第一个字符
        LOWER(substring(name,2)) -- 其余的字符
    ) as name
from day06_fun.users;
```

### 1.3 时间日期函数

在编写SQL对数据处理和开发的过程中，也经常需要对时间日期类型的数据进行操作

时间日期函数分类：

* 获取当前时间的函数，比如当前的年月日

  **NOW**、CURRENT_DATE、CURRENT_TIME

* 计算时间差的函数，比如两个日期之间相差多少天，一个日期90天后是几月几号

  **DATE_ADD**、**DATE_SUB**、**DATEDIFF**、TIMESTAMPDIFF

* 获取年月日的函数，从一个时间中提取具体的年份、月份等

  **YEAR**、**MONTH**、**DAY**、HOUR、MINUTE、SECOND、WEEKDAY

* 时间转换的函数，比如将2021-10-05转换为时间戳

  字符串和时间的转换： **DATE_FORMAT**、STR_TO_DATE

  时间戳和时间的转换： UNIX_TIMESTAMP、FROM_UNIXTIME

  ​	时间戳（数字）：某个时间距离UTC时区的1970-01-01 00:00:00 过去了多久（通常以秒或毫秒为单位）。

  ​	比如：东八区的2023-06-01 17:20:44距离UTC时区的1970-01-01 00:00:00 已经过去了 1685611244 秒

```sql
-- 时间 日期的函数:
-- 如何分别获取 年year()  月month()  日day()  时hour()  分minute() 秒second() 星期几 weekday()  年月日: date  时分秒:time 当前时间 NOW()
SELECT YEAR('2025-11-09 10:22:50');
SELECT MONTH('2025-11-09 10:22:50');
SELECT DAY('2025-11-09 10:22:50');
SELECT HOUR('2025-11-09 10:22:50');
SELECT MINUTE('2025-11-09 10:22:50');
SELECT SECOND('2025-11-09 10:22:50');
SELECT WEEKDAY('2025-11-09 10:22:50');  -- 0~6 0表示周一  6 周日
SELECT DATE('2025-11-09 10:22:50');
SELECT TIME('2025-11-09 10:22:50');

-- 日期转换:  日期转换为时间戳 UNIX_TIMESTAMP()
select unix_timestamp('2025-11-09 10:22:50'); -- 1762654970

-- 日期转换:  从时间戳 转换为 日期 FROM_UNIXTIME

select from_unixtime(1762654970); -- 2025-11-09 10:22:50

-- 如何转换为指定格式呢?
select from_unixtime(1762654970,'%Y/%m/%d %H:%i:%s'); -- 2025/11/09 10:22:50

-- 将日期 转换为指定格式的字符串 DATE_FORMAT(date,format)
select date_format('2025-11-09 10:22:50','%Y/%m/%d %H:%i:%s'); -- 2025/11/09 10:22:50

-- 将字符串转换日期类型: 参数2 传入字符串日期类型的格式
select str_to_date('2025/11/09 10:22:50','%Y/%m/%d %H:%i:%s');

-- 日期的计算操作: 如何增减时间   DATE_ADD()  如果 数字为负数 表示减少指定单位时间  或  TIMESTAMPADD(MINUTE, 1, '2003-01-02');
-- 增加一年
select DATE_ADD('2025-11-09 10:22:50',interval 1 year );
select timestampadd(year ,1 ,'2025-11-09 10:22:50' );
-- 增加 1小时
select DATE_ADD('2025-11-09 10:22:50',interval 1 hour );
select timestampadd(hour,1,'2025-11-09 10:22:50' );
-- 减少1个月
select DATE_ADD('2025-10-31 10:22:50',interval -1 month );
select timestampadd(month ,-1,'2025-10-31 10:22:50' );

-- 日期直接的比较: TIMESTAMPDIFF(unit,datetime_expr1,datetime_expr2)
-- 计算二个日期相差了多少天
select timestampdiff(day,'2025-10-28 10:22:50','2025-11-09 10:22:50');
-- 计算相差了多少小时呢?
select timestampdiff(hour ,'2025-10-28 10:22:50','2025-11-09 10:22:50');

-- 需求1: 查询在 2020 年登录过的每个用户的本年度 最后一次 登录时间(导入资料中的logins表)
-- 思路：
-- 筛选出 2020 年的登录记录
-- 按照用户id进行分组，获取最近一次的登录时间
select
    user_id,
    max(time_stamp) as max_time
from day06_fun.logins where year(time_stamp) = 2020
group by user_id;

-- 需求2: 查询温度比前一天（昨天）温度高的记录id (导入资料中的weather表)  交叉连接 找相关数据 建议使用Excel 演示一下
select
    a.id
from day06_fun.weather a join day06_fun.weather b  on date_add(a.recordDate,interval -1 day) = b.recordDate
where a.temperature > b.temperature;
```

### 1.4 条件判断

在编写SQL对数据处理和开发的过程中，经常需要对数据进行条件判断操作。

```ini
if(expr,v1,v2): 表达式结果为true返回v1,否则返回v2

case when 
	用法1: CASE SCORE WHEN 'A' THEN '优' ELSE '不及格' END
	用法2: 
	     CASE 
	     	WHEN condition THEN result
         	[WHEN...THEN...]
         	ELSE result
         END
    用法3: 配合聚合函数根据条件统计.count(case when tpye=1 then 1 else 0 end)
```

```sql
-- 条件函数:
-- if函数
-- 需求:
/*
 (导入: tb_score表)
需求：查询学生的成绩信息，并将学生的成绩分成5个等级，结果中需要有一个学生成绩等级列:  基于IF 和 case when实现
成绩等级如下：
优秀：90分及以上
良好：80-90，包含80
中等：70-80，包含70
及格：60-70，包含60
不及格：60分以下
查询结果字段：
	name(姓名)、course(科目)、score(成绩)、grade(成绩等级)
*/
-- 演示 if如何使用
select
    name,
    course,
    score,
    if(score >= 90,'优秀','良') as '级别'
from day06_fun.tb_score;

-- if 支持 嵌套使用 : 实现了最终的需求
select
    name,
    course,
    score,
    if(
        score >= 90,
        '优秀',
        if(
            score >= 80,
            '良好',
            if(
                score >= 70,
                '中等',
               if(score >= 60,'及格','不及格')
            )
        )
    ) as '级别'
from day06_fun.tb_score;

-- if 一般不会嵌套太多的层数, 一般建议在3层以内即可, 如果层数太多, 请使用 case  when 方案

-- 基于 case when 实现刚刚需求
/*
    满足哪个条件 就执行哪个条件, 一旦进入其中一个条件 其他就不会执行了
    语法1:
        case
            when 条件1 then 成立返回结果
            when 条件2 then 成立返回结果
            when 条件3 then 成立返回结果
            when 条件4 then 成立返回结果
            ......
            else
                以上条件都不满足, 执行的内容
        end

    语法2: 判断某一个字段的值, 要根据不同的值要执行不同的操作 可以使用下列语法
        case  条件
            when 值1  then 成立返回结果
            when 值2  then 成立返回结果
            when 值3  then 成立返回结果
            .....
            else
                以上条件都不满足, 执行的内容
        end

 */
select
    name,
    course,
    score,
    case
        when score >= 90 then '优秀'
        when score >= 80  then '良好'
        when score >= 70 then '中等'
        when score >= 60 then '及格'
        else
            '不及格'

    end as '级别'
from day06_fun.tb_score;

# 需求: 对student表中性别进行处理, 如果性别为 Male 转换为 男  如果为Female 转换为 女 否则返回 NULL
select
    ID,
    Name,
    case Gender
        when 'Male' then '男'
        when 'Female' then '女'
        else NULL
    end as Gender,
    Score
from day06_fun.students;

-- 其他的判断语法:
-- ifnull(参数1,参数2) 判断参数1是否为NULL , 如果为null就返回参数2的值, 如果不为NULL 就返回参数1的值
select ifnull(NULL,1);

-- nullif() # 判断参数的两个参数是否一致, 如果一致返回NULL , 如果不一致 返回第一个参数的值
select nullif('李四',NULL); 

help 'nullif'

/*
需求2: 统计不同科目中，成绩在90分以上(包含90)和90分以下的人数各有多少
查询结果字段：
	course(科目)、gte_90(该科目90分以上是学生人数)、lt_90(该科目90分以下的学生人数)

    聚合函数, 会忽略NULL值
*/
select
    course,
    count(if(score >= 90,score,NULL)) as gt90_cnt,
    count(if(score < 90,score,NULL)) as lt90_cnt
from day06_fun.tb_score
group by course;

```

### 2.1 行转列(多行变一行)

需求：通过SELECT查询，将左边的数据转换为右边的形式

```sql
-- 采用表:score  演示 行 转 列
-- 解决思路: 基于 group by + sum/max聚合函数内部套IF方案解决

-- 行 转 列:
-- 技巧: group by +  sum/max 聚合函数 + if判断
select
    `学号`,
    sum(if(`科目` = '语文',`成绩`,0)) as '语文',
    max(if(`科目` = '数学',`成绩`,0)) as '数学',
    max(if(`科目` = '英语',`成绩`,0)) as '英语'
from day06_fun.score
group by `学号`;
```
