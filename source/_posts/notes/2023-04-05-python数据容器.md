# 数据容器

## 1. 字符串容器

- 索引查找
  - str[索引]
  - 切片  str[start: end: step]
    - 包左不包右
    - 负索引：从右往左计算的索引，起始-1
    - 负步长：从右往左切
    - 负向选中负步长切，正向选中正步长切
    - 起始索引、结束索引，步长都可以省略

```python
# 实例
str1='0123456789'
# 索引查看
print(str1[3])
# 取出345
print(str1[3:6])
# 取出369
print(str1[3::3])
# 从头到尾
print(str1[:])
# 从尾到头
print(str1[::-1])
```

- 获取字符串长度
  - len(字符串)
- 查询字符串中某字符出现次数
  - 字符串.count(查找的内容)
- 字符串的替换
  - 字符串.replace(要替换的内容，替换成什么)
    - 不会修改原字符串，生成新字符串
- 去除两端空格
  - 字符串.strip()
    - 不会修改原字符串，生成新字符串
- 字符串的切割
  - 字符串.split(用什么切割)
- 获取字符的索引
  - 字符串.index(字符)
    - 返回第一个字符的索引

```python
# 获取字符串长度
print(len(str1))
# 统计字符出现次数
print(str1.count('1'))
# 字符串替换
# 不能改变原字符串内容，生成新字符串
str2=str1.replace('0','1')
print(str2)
# 去除两端空格
# 不能改变原字符串内容，生成新字符串
str3=' itheima '
print(str3.strip())
# 字符串切分，切完生成列表
str4='1,2,3,4,5'
print(str4.split(','))
# 获取字符索引
print(str1.index('5'))
```

## 2. 列表容器

- 特点
  - 可以修改
  - 可以存放不同类型的数据
  - 支持嵌套
- 定义
  - 变量名=[内容1,内容2...]
  - 变量名=[]  空列表
  - 变量名=list() 构造列表
- 常用操作
  - 索引查找
    - list[索引]
      - 取出的是字符串
    - 切片
      - list[start: end: step]
        - 取出的是列表

```python
# 索引查看
print(name_list[1])  # 结果是字符串
# 切片
print(name_list[1:4]) # 结果是列表
print(type(name_list[1:4]))
```

- 获取列表长度
  - len(列表)
- 统计某元素出现的次数
  - 列表.count(查询的元素)
- 获取元素的索引
  - 字符串.index(元素)  返回元素的索引
- 修改元素
  - 列表[要修改元素的索引]=新值
- 增加元素
  - 列表.append(新增元素)  在列表尾部插入
  - 列表.insert(插入位置的索引,插入元素)  插入指定位置
- 列表合并
  - 列表.extend(新列表)
- 删除元素
  - 列表.remove(要删除的元素)  删除元素有重复的，只能删除第一个
  - 列表.pop(索引)  通过索引删除元素
  - del 列表[索引]

```python
# - 获取列表长度
print(len(name_list))
# - 统计某元素出现的次数
print(name_list.count('李正洋'))
# - 获取元素的索引
print(name_list.index('李正洋'))
# - 修改元素
name_list[1]='李反洋'
print(name_list)
# - 增加元素
#   - 列表.append(新增元素)  在列表尾部插入
name_list.append('成佳乐')
print(name_list)
#   - 列表.insert(插入位置的索引,插入元素)  插入指定位置
name_list.insert(1,'张博洋')
print(name_list)
# - 列表合并
#   - 列表.extend(新列表)
new_list=['宋钰','许润涵']
name_list.extend(new_list)
print(name_list)
# - 删除元素
# remove
name_list.remove('宋钰')
print(name_list)
# pop
print(name_list.pop(1))
# del
del name_list[7]
print(name_list)
```

## 3. 元组

- 特点
  - 不能修改，只读列表
  - 可以存放不同类型的数据
  - 支持嵌套
  - 列表和元组可以互相转换
  - 列表和元组可以拼接
- 定义
  - 元组名=（内容1,内容2...）
  - 元组名=(内容,)  单元素
  - 元组名=tuple() 构造元组
- 常用操作

```python
# 定义元组
t1=(1,2,3,4,5)
# 根据索引查找
print(t1[0])
# 统计元素数量
print(t1.count(1))
# 统计元组长度
print(len(t1))
# 获取元素索引
print(t1.index(3))
# 元组拼接
print(t1+t2)
# 类型转换
list(tuple)
tuple(list)
```

## 4. 集合

- 特点
  - 可以修改
  - 可以存放不同类型的数据
  - 支持嵌套
  - 无序不重复，不支持索引
- 定义
  - 变量名={内容1,内容2...}
  - 变量名={}  空集合
  - 变量名=set() 空集合
- 常用操作

```python
# 定义
s1={1,2,3,4}
s2={2,5}
# 集合长度
print(len(s1))
# 添加元素
s2.add(6)
print(s2)
# 删除元素
s2.remove(6)
print(s2)
# s2.pop()  # 随机删除一个元素
# print(s2)
# 并集
s1.update(s2)
print(s1)
# 差集
s1.difference_update(s2)  # s1.difference(s2)
print(s1)
# 交集
print(s1&s2)
```

## 5. 字典

- 特点
  - 对数据进行解释时使用的类型
  - 可以修改
  - 可以存放不同类型的数据
  - 支持嵌套
  - 无序，仅支持通过键查找
- 定义
  - 字典名={'键'：值,'键'：值...}
  - 字典名=dict{} 构造字典
- 常用操作

```python
# 定义字典
phone_dict={'brand' : 'iphone' , 'type' : '17 pro max' , 'price' : 8000 , 'publish_year' : 2026}
print(phone_dict)
# 获取字典长度
print(len(phone_dict))
# 获取所有键--返回列表
print(phone_dict.keys())
# 获取所有值--返回列表
print(phone_dict.values())
# 增加元素
phone_dict['month']=6
print(phone_dict)
# 删除元素
phone_dict.pop('month')
print(phone_dict)
# 修改元素
phone_dict['publish_year' ]=2025
print(phone_dict)

# 统计字符串中字符的重复次数
str='aggahwashoidqhepoieqpo564156prqtlzmnvnhalblds74896946314786qfagah'
# 定义一个空字典
new_dict={}
# 遍历字符串
for i in str:
    if i in new_dict:  # 字符在字典中
        new_dict[i]+=1 # 该字符的值增加1
    else:
        new_dict[i]=1 # 字符不在字典中，键=该字符，值=1
print(new_dict)
```
