## 4.变量

- 能够接收变量值的数据容器
- 变量名=变量值
- 变量本身没有数据类型，但他的值有数据类型
- 变量是可以改变的，变量名=新变量值

## 5.数据类型

- 字符串 string
- 整数 int
- 浮点数 float

- 查看方式 type( )

```python
# 测试方法
# 直接获取
print(type(1))
# 两步获取
name_type=type('张三')
print(name_type)
# 三部获取
name='张三'
name_type=type(name)
print(type(name_type ))
# 测试结果
# 1.整数类型
print(type(1)) <class 'int'>
# 2.浮点数类型
print(type(1.1)) <class 'float'>
# 3.复数类型
print(type(1+2j)) <class 'complex'>
# 4.布尔值类型
print(type(True)) <class 'bool'>
# 5.字符串类型
print(type('李正洋')) <class 'str'>
# 6.列表类型
print(type([2,5,8])) <class 'list'>
# 7.元组类型
print(type((2,5,8))) <class 'tuple'>
# 8.集合类型
print(type({2,5,8})) <class 'set'>
# 9.字典类型
print(type({'2':2,'5':5,'8':8})) <class 'dict'>
```

## 6.数据类型转换

- int(x) 将x转换为整数
- float(x) 将x转换为小数
- str(x) 将x转换为字符串
- bool(x) 将x转换为布尔值

```python
# 整数转换
x=123
# 转字符串
print(str(x))
# 转浮点数
print(float(x))
# 浮点数类型
x=123.5
# 转整数
print(int(x))
# 转字符串
print(str(x))
# 字符串类型
x='123'
# 转整数
print(int(x))
# 转浮点数
print(float(x))
```

## 8.运算符

- 算数运算符

  \+ - * /  加减乘除

  // 取整除

  ** 指数运算

  % 取余数

- 赋值运算符

  = 将=右侧的结果赋值给等式左侧的变量

  复合赋值运算符：将等式左侧的变量与右侧值先进行计算，再赋值给左侧变量

```python
num=10
num+=50 # num=num+50
print(num)
# -=
num-=20
print(num)
# *=
num*=5
print(num)
# /=
num/=10
print(num)
# //=
num//=3
print(num)
# **=
num**=3
print(num)
# %=
num%=5
print(num)
```

## 9.字符串扩展

- 字符串拼接
  - print('字符串1', '字符串2')  字符串之间有空格
  - print('字符串1'+'字符串2')  字符串之间没有空格，先执行代码运算，再输出计算结果
- 百分号格式化
  - 占位符
    - %d 整数
    - %s 字符串
    - %f
      - % .2f 保留两位小数
      - % 5.2f  宽度保留5位，两位小数
  - print('字符串%d , %s , %f' %(变量(int),变量(str),变量(float))
  - 几个占位符就对应几个变量
- format格式化
  - print('字符串{},{},{}'.format(变量1,变量2,变量3)）
- format简写
  - print(f'字符串{变量1}字符串{变量2}字符串{变量3}'）
  - 整数转小数  print(f'字符串{**变量(整数): .2f**}'）,保留两位小数

```python
# 字符串拼接
print("模型名称是", m_name )  # 中间有空格
print('模型名称是'+m_name ) # 中间没空格
# 字符串格式化
print('模型名称是：%s，厂家是：%s，发布年份是：%d，温度是：%.2f' %(m_name,m_manu,m_pubilsh ,m_temp))
print('模型名称是：%s，厂家是：%s，发布年份是：%d，温度是：%d' %(m_name,m_manu,m_pubilsh ,m_temp))
```

## 10.数据输入

- 语法：input([提示的内容])
- 输入语句的结果一定是字符串类型，可通过数据类型转换进行转换，int(input(输入内容))
- 输入语句如果没有结束，不会执行后边的代码
- 输入语句结束后会获取用户输入内容，可用变量进行接收保存，变量=input(输入内容)

```python
# 输入用户名，级别
name=input("请输入您的姓名：")
grade=input('请输入您的账户级别：')
print(f'欢迎尊贵的{name}，您的账户级别是{grade}，感谢您的光临！')

# ATM取款机

请选择您要办理的业务
1.查询余额              
2.存钱
3.取钱
4.退出系统
请输入：
""")
money=9999999
print(f'当前余额{money:.2f}')      # format格式化中，整数转小数
```

## 11. 扩展

```python
# bool格式转换
print(bool(123))
print(bool('asd'))
print(bool(1.2))
# 多数情况结果为True
# 少数情况为False
print(bool(0))
print(bool(''))
print(bool(None))

# eval 去除内容最外侧引号
count = '1'
# 要使用count变量，但内容为'count'
print(eval('count'))
# 拆解'count'最外侧引号后，拿到count变量，输出字符串格式的'1'，再拆解变量值'1'两侧的引号，得到int类型的1
print(eval(eval('count')))
# 如果没有引号，继续使用eval会报错
```
