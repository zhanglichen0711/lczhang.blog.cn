### 2. 简单查询

语法:

```sql
select [distinct]
* | 列名 [as 别名],列名 [as 别名]
from 表;

说明:
	distinct : 表示 去重,  对输出的结果进行去重操作
	* :  表示所有的字段
	| : 表示 或者的意思, 左边 和 右边的内容 不能再一个表中重复出现
```

需求说明:

```sql
-- 简单查询:
/*
   语法:
      select [distinct]
        * | 列名1 [as 别名1] ,列名2 [as 别名2] ....
      from 表;

   说明:
     * : 所有的字段
     | : 或者的关系, 表示要不就写左边语法 要不就写右边的语法 只能二选一
    distinct : 用于去重的操作.针对行与行之间如果有重复 可以通过该关键词去重
 */
-- 1 查询所有的商品.
select
  *
from day04_dql.product;
-- 2 查询商品名和商品价格.
select
  pname,
  price
from day04_dql.product;
-- 3 别名查询.使用的关键字是as（as可以省略的）.
-- 3.1 表别名: 为表起一个别名 p   在单表查询中 无意义
select
  p.pname,
  p.price
from day04_dql.product as p ;

select
  p.pname,
  p.price
from day04_dql.product p ;
-- 在实践应用中 表别名 建议省略 as 书写
-- 3.2 列别名: 将表中所有的字段在展示的时候全部使用中文
select
 pid as '商品编号' ,
 pname as '商品名称' ,
 price as '价格',
 category_id as '分类编号'
from day04_dql.product;

-- 在实践应用中 一般不会省略as操作
-- 4 去掉重复值:  查询商品分类ID , 并且去重展示
select
  distinct  category_id
from day04_dql.product;
-- 5 查询结果是表达式（运算查询）：将所有商品的价格+10元进行显示.
select
 pid,
 category_id,
 price + 10 as price,
 pname
from day04_dql.product;

```

### 3. 条件查询

| 比较运算符     |                             |                                                              |
| -------------- | --------------------------- | ------------------------------------------------------------ |
| 相等性         | > < <=  >=  =  <> !=        | 大于、小于、大于(小于)等于、不等于                           |
| 连续区间       | BETWEEN  ...AND...          | 显示在某一区间的值(含头含尾)                                 |
| 非连续区间     | IN(set)                     | 显示在in列表中的值，例：in(100,200)   in(a,b,c,d)            |
| 相似匹配       | LIKE '张%'<br />LIKE '_涛%' | 模糊查询，Like语句中，<br />%代表零个或多个任意字符，<br />\_代表一个字符，<br />例如：first_name like '_a%'; |
| 非空           | IS NULL <br />IS NOT NULL   | 判断是否为空                                                 |
| **逻辑运算符** |                             |                                                              |
|                | and                         | 多个条件同时成立                                             |
|                | or                          | 多个条件任一成立                                             |
|                | not                         | 不成立，例：where not(salary>100);                           |

需求说明:

```sql
/*
  语法:
      select [distinct]
        * | 列名1 [as 别名1] ,列名2 [as 别名2] ....
      from 表 [where 条件];


   比较运算符:
       > < >= <= <> !=
          条件语法格式:
                字段名 [>|<|>=|<=|<>|!=] 值
       between 起始值 and 结束值 : 范围查询
          作用: 获取某个范围内数据(包头包尾)
          条件语法格式:
                字段名 between 起始值 and 结束值
       in(值1,值2,值3....):
          作用: 用于获取某个字段的 值1,值2,值3的内容 有就显示, 没有就不显示
          条件语法格式:
               字段名 in(值1,值2,值3....)

       like : 模糊查询
          作用: 用于模糊匹配表中数据, 将匹配到的数据返回
          条件语法格式:
               字段名 like '通配符 + 要查询内容 组合'

          通配符有哪些?

             _ :  表示 1个任意字符
          例如:
              name like '张%' : 查询姓张用户
              name like '张_' : 查询姓张用户,并且名只有1个
              name like '%佳%' : 查询名字里面含有佳的用户
              name like '_佳%' : 查询名字里面第二个字为佳的用户
       is [not] null:  获取某列那些值为null 或者buweinull
           条件语法格式:
               字段名 is [not] null

       and :  多个条件必须同时都符合的情况获取出来
          条件语法格式:
               条件1 and 条件2 and 条件3 ....

          条件语法格式:
               条件1 or 条件2 or 条件3 ....
               条件1 or (条件2 and 条件3) ....
       not :  进行取反操作  把符合条件的反向的数据获取到
           条件语法格式:
               not (条件1 or 条件2 or 条件3 ....)
 */
-- 条件查询:

  *
from day04_dql.product where price = 800 ;

select
  *
from day04_dql.product where price != 800 ;
select
  *
from day04_dql.product where price <> 800 ;

  *
from day04_dql.product where not price = 800 ;

select
  *

  *
```

### 4. 排序查询

通过order by语句，可以将查询出的结果进行排序。暂时放置在select语句的最后。

格式:

```sql
select [distinct]
   * | 列名 [as 别名],列名 [as 别名]
from 表 
[where 条件]
-- 排序操作
[order by 排序字段1 [ASC | DESC] [,排序字段2 [ASC | DESC] ....] ];

ASC 升序 (默认)
DESC 降序
```

需求:

```sql
-- 排序查询:
/*
   语法:
    select [distinct]
       * | 列名 [as 别名],列名 [as 别名]
    from 表
    [where 条件]
    -- 排序操作
    [order by 排序字段1 [ASC | DESC] [,排序字段2 [ASC | DESC] ....] ];

    ASC 升序 (默认)
    DESC 降序
    注意: 排序操作 是针对的select语句执行后的结果进行排序
 */
use day04_dql;

-- 1.使用价格排序(降序)
select
  *
from day04_dql.product  order by price desc ;
-- 2.在价格排序(降序)的基础上，以分类排序(降序)
select
  *
from day04_dql.product  order by price desc ,category_id desc;
-- 3.显示商品的价格(去重复)，并排序(降序)
select
  distinct price
from day04_dql.product order by price desc;
```

### 5. 聚合查询

​	之前我们做的查询都是横向查询，它们都是根据条件一行一行的进行判断，而使用聚合函数查询是纵向查询，它是对一列的值进行计算，然后返回**一个**单一的值；**另外聚合函数会忽略空(NULL)值**。

特点: **多进一出**

| 聚合函数 | 作用                                                         |
| -------- | ------------------------------------------------------------ |
| count()  | 统计指定列不为NULL的记录行数；                               |
| sum()    | 计算指定列的数值和，如果指定列类型不是数值类型，那么计算结果为0 |
| max()    | 计算指定列的最大值，如果指定列是字符串类型，那么使用字符串排序运算； |
| min()    | 计算指定列的最小值，如果指定列是字符串类型，那么使用字符串排序运算； |
| avg()    | 计算指定列的平均值，如果指定列类型不是数值类型，那么计算结果为0 |

放置的位置: 大多数情况下是在 select 后面  from前面

需求:

```sql
-- 聚合查询:
-- 1 查询商品的总条数
select
   count(pid) as cnt
from day04_dql.product;

-- 如果表没有主键 如何准确的获取共计有多少条数据呢?
-- 推荐使用 count(1):  确保一定可以拿到总条数 同时 count(1) 在早期的数据库版本中效率更高
select
   count(1) as cnt
from day04_dql.product;

select
   count(*) as cnt
from day04_dql.product;

-- 2 查询价格大于200商品的总条数
select
  count(1) as cnt
from day04_dql.product where price > 200;
-- 3 查询分类为'c001'的所有商品的价格总和
select
   sum(price) as total_price
from day04_dql.product where category_id = 'c001';
-- 4 查询分类为'c002'所有商品的平均价格
select
   cast(avg(price) as decimal(10,2) )   as avg_price
from day04_dql.product where category_id = 'c002';

-- 5 查询商品的最大价格和最小价格
select 
   max(price) as max,
   min(price) as min
from day04_dql.product;
```

### 6. 分组查询

分组查询是指使用group by字句对查询信息进行分组

**1分组必2聚合**

格式：

```sql
SELECT 字段1,字段2… FROM 表名 GROUP BY 分组字段 [HAVING 分组条件];
```

分组操作中的having子语句，是用于在分组后对数据进行过滤的，作用类似于where条件

having与where的区别:

```sql
1) having是在分组后对数据进行过滤, where是在分组前对数据进行过滤
2) having后面可以使用分组函数(统计函数), where后面不可以使用分组函数
```

注意:

1-  分组必聚合:  只要执行了group by 那么就会使用到聚合函数

2-  一旦对表执行了分组, 那么select后面如果要直接写字段, 就只能写分组的字段, 不能出现分组字段以外的字段, 如果要使用其他字段请放置到聚合函数中

需求:

```sql
-- 分组查询: group by
/*
    语法:
      select [distinct]
       * | 列名 [as 别名],列名 [as 别名] | 聚合函数
      from 表
      -- 条件筛选
      [where 条件]
      -- 分组操作
      [group by 分组字段列表 [having 条件]]
      -- 排序操作
      [order by 排序字段1 [ASC | DESC] [,排序字段2 [ASC | DESC] ....] ];

   注意:
      1- 分组必聚合
      2- 一旦有分组后, select后面 只能出现 分组的字段和聚合函数 其他都不能用, 如果有其他字段会直接报错,除非将这些字段放置到聚合函数中
      3- having 是对 分组 聚合的结果进行过滤操作, 也支持直接在having进行聚合 然后过滤方案
   
   
   where 和  having区别:  
       1- where 是针对的 from 后面的表 进行过滤, 不支持聚合函数 只能做筛选
       2- having是针对的 group by 聚合后的结果进行过滤筛选的, 可以直接在having中先进行聚合操作
   
 */

-- 分组查询:

-- 1 统计各个分类商品的个数
-- 分组字段: 分类
-- 聚合操作: count   作用到每一个组内进行一次执行, 一个组返回一个结果(多进一出)
select
  category_id,
  count(1) as cnt
from day04_dql.product group by category_id;

-- 2 统计各个分类商品的个数,且只显示个数大于1的信息
select
  category_id,
  count(1) as cnt
from day04_dql.product group by category_id having cnt > 1;
```

### 7. insert into select 语句

insert into select 语句从一个表复制数据，然后把数据插入到一个已存在的表中。

基本语法:

```sql
INSERT INTO table2  SELECT column_name(s)  FROM table1;
```

注意: 

1-  查询的结果 和 保存到目标表的结构要保持一致

2-  查询的结果的字段顺序要和目标表的字段的顺序保持一致, 当然类型、长度也要一致

> 数据摆渡：数据库在A服务器上运行的，需要同步到B服务器上，这个时候就可以通过查询数据后进行报错，再插入查询结果到新的表中

需求:

```properties
-- insert + select 操作:
/*
     将select语句查询到的结果 插入到一个已经存在的表中(保存结果数据到结果表中)

     语法:
        insert into 表[(字段1,字段2,字段2....)] select 语句

      应用场景:  将分析后的结果 保存到目标表  用于后续的处理
 */

-- 将 分类ID为 C001的数据 写入到 新的表 product2中, 仅输出pid pname price
-- 查询SQL如何书写
select
   pid,
   pname,
   price
from day04_dql.product where category_id = 'c001';

-- 第一步: 创建目标表
drop table if exists day04_dql.product2;
create table day04_dql.product2(
   pid int,
   pname varchar(20),
   price decimal(10,2)
) comment '分析结果表';

-- 第二步: 编写插入数据
insert into day04_dql.product2
select
   pid,
   pname,
   price
from day04_dql.product where category_id = 'c001';

-- 另一种写法:  直接创建表并添加数据
-- 基于select语句字段的名字\类型 自动创建表
create table day04_dql.product3 as
select
   pid,
   pname,
   price
from day04_dql.product where category_id = 'c001';

-- 如果需要严格把控每个字段的类型,可以用下面的方式
drop table if exists day04_dql.product4;
create table day04_dql.product4(
   pid int,
   pname varchar(20),
   price double
)
as
select
   pid,
   pname,
   price
from day04_dql.product where category_id = 'c001';
```

### 8.  特殊MySQL分页查询

格式:  limit [start] num

MySQL的方言, 不属于标准的SQL语句内容,所以在其他数据库中有可能无法使用

````
start: 表示起始的条目, 从第几条开始查询  0表示第一条  可以省略不写, 不写默认为0
num:  显示多少条(每页条数)
````

放置位置:  查询SQL的最后面

```sql
-- MySQL分页查询:
-- 语法: limit [start,] num
-- start: 默认从 0开始 表示 表中的第一条数据  每页的起始值: 计算公式 (N -1) * 每页条数   N表示第几页
-- num: 获取多少条 (每页显示的条数)
-- 放置位置: 整个SQL最后面
-- 需求 要求每页显示3条, 分别展示第一页 第二页 第五页
-- 第一页
select
  *
from day04_dql.product limit 0,3;
-- 第二页
select
  *
from day04_dql.product limit 3,3;
-- 第三页
select
  *
from day04_dql.product limit 6,3;
-- 第五页
select
  *
from day04_dql.product limit 12,3;
```
