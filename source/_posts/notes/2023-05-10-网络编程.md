# 网络编程

## 1. 网络通信三要素

### 1.1 ip地址

计算机在网络通信中的唯一标识

ipv4: 十进制 XXX:XXX:XXX:XXX

​	每项数值范围0~255

ipv6:十六进制

### 1.2 端口

进程间传输数据的通道

公有端口0~1023

动态端口设置在8000以后

### 1.3 协议

TCP/UDP

#### 1.3.1 TCP协议

TCP协议的特点：

​	面向连接的：创建连接（三次握手），传输数据，断开连接（四次挥手）

​	可靠的：私密性好，消息不会丢失，重复发送

​	基于字节流的：通过字节传输，encode:文本转字节，decode:字节转文本

#### 1.3.2 UDP协议

UDP协议的特点：

​	不可靠的：相当于群发消息，只管发送，不管是否接收到

​	性能好：传输性能更好

## 2. TCP协议编程

### 2.1 socket套接字

进程之间通信的工具

可以通过socket.socket() 创建客户端和服务端

### 2.2 TCP编程

#### 2.2.1 客户端

```python
# 1.创建客户端
import socket
client=socket.socket(默认为ipv4,TCP协议)
# 2.连接服务端
client.connect((192.168.14.21,10086))  # 连接对应IP及端口
# 3.发送消息
message=input('请输入要发送的内容：')
client.send(message.encode('encoding=utf-8'))  # 发送消息将文本转为字节
# 4.接收消息
server_message=client.recv(1024)  # 内容大小
# 5.关闭客户端
client.close()
```

#### 2.2.2 服务端

```python
# 1.创建服务端
import socket
server=socket.socket()
# 2.绑定IP地址和端口号
server.bind((192.168.14.21,10086))
# 3.设置最大监听数量
server.listen(10)
```
