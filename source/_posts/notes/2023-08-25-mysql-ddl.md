## 一、DDL之数据库操作(database)

### 1. 创建数据库

格式:

```sql
create database 数据库名;    #直接创建数据库，如果存在则报错
create database if not exists 数据库名;  #如果数据库不存在则创建
create database 数据库名 character set 字符集; #创建数据库时设置字符集（utf8  gbk 拉丁字符）
```

实例：

```sql
-- DDL语句:  数据库定义操作
/*
    建库操作:
        语法:
            create database [if not exists]  数据库名称 [character set 字符集编码];

        说明:
          [] : 表示内部的语法是可选的
          if not exists :  判断是否不存在
          character set 字符集编码 : 设置 库的字符集编码 默认为UTF8  一般为UTF8,  可选 GBK ......

*/

-- 需求1:  请创建一个 day01_db  数据库
create database day01_db; # 仅能执行一次, 如果库存在, 直接报错 Can't create database 'day01_db'; database exists

-- 需求2:  请创建一个 day01_db_test1  数据库 要求该数据库不存在的时候创建它
create database if not exists day01_db_test1; # 如果库存在, 不执行 , 如果不存在 才会创建这个数据库  不会报错
-- 需求3:  请创建一个 day01_db_test2  数据库 要求该数据库采用GBK编码格式
create database if not exists day01_db_test2 character set gbk;
```

### 2. 查看所有数据库

格式：

```sql
show databases;
```

示例:

```sql
-- 2- 查看所有的数据库
show databases;
```

### 3. 删除数据库

格式：

```sql
drop database [if exists]  数据库名称
```

示例:

```sql
-- 删除数据库:
-- 语法:  drop database [if exists] 库名称;
-- if exists 是否存在
-- 需求: 请删除 day01_db_test1库
drop database day01_db_test1;

-- 需求: 如果 day01_db_test2库 存在, 请将其删除, 删除后, 请重新创建改库, 并且将编码设置为UTF8
drop database if exists day01_db_test2;
create database day01_db_test2 character set utf8;
```

### 4. 使用数据库

格式：

```sql
 use 数据库名字;
```

示例:

```sql
-- 使用数据库:
-- 语法:  use  库名;
-- 需求: 使用 day01_db
use day01_db;
```

## 二、DDL之表操作(table)

### 1. 数据类型

数据类型是用于约束每一列应该存储什么类型的数据

| 分类                         | 类型名称           | 说明                                                         |
| ---------------------------- | ------------------ | ------------------------------------------------------------ |
| **整数类型**                 | tinyInt            | 很小的整数                                                   |
|                              | smallint           | 小的整数                                                     |
|                              | mediumint          | 中等大小的整数                                               |
|                              | **int**            | 普通大小的整数                                               |
| **小数类型**                 | float              | 单精度浮点数                                                 |
|                              | double             | 双精度浮点数                                                 |
|                              | **decimal（m,d）** | 压缩严格的定点数  decimal(10,2)  m: 小数位+整数位最多可以有多少位  d: 必须保留多少位小数 |
| **日期类型**                 | year               | YYYY  1901~2155                                              |
|                              | time               | HH:MM:SS  -838:59:59~838:59:59                               |
|                              | date               | YYYY-MM-DD 1000-01-01~9999-12-3                              |
|                              | datetime           | YYYY-MM-DD HH:MM:SS 1000-01-01 00:00:00~ 9999-12-31 23:59:59 |
|                              | **timestamp**      | YYYY-MM-DD HH:MM:SS  1970~01~01 00:00:01 UTC~2038-01-19 03:14:07UTC  秒单位 时间戳 |
| **文本(字符串)、二进制类型** | char(m)            | m为0~255之间的整数定长 char(10) tom                          |
|                              | **varchar(m)**     | m为0~65535之间的整数变长 varchar(10) tom                     |
|                              | tinyblob           | 允许长度0~255字节                                            |
|                              | blob               | 允许长度0~65535字节                                          |
|                              | mediumblob         | 允许长度0~167772150字节                                      |
|                              | longblob           | 允许长度0~4294967295字节                                     |
|                              | tinytext           | 允许长度0~255字节                                            |
|                              | text               | 允许长度0~65535字节                                          |
|                              | mediumtext         | 允许长度0~167772150字节                                      |
|                              | longtext           | 允许长度0~4294967295字节                                     |
|                              | varbinary(m)       | 允许长度0~M个字节的变长字节字符串                            |
|                              | binary(m)          | 允许长度0~m个字节的定长字节字符串                            |

常见的数据类型:

* 整数类型:  int
* 小数类型: decimal(M,D) M：总共几位  D：小数有几位
* 日期类型: datetime 和 timestamp
* 文本类型:  varchar(长度) 

### 2. 创建数据表

基本语法：

```sql
create table [if not exists] 表名 (
    字段名1  数据类型 [约束],
    字段名2  数据类型 [约束]
    ...
) [character set 字符集];

-- 类型：
      varchar(n)字符串/文本
      int   整形
      decimal（m,d） 浮点/小数
      date   时间
      timestamp时间戳
-- 约束：
	  primary key  主键，被主键修饰字段中的数据，不能重复、不能为null。
	  一个表中应该有一个主键约束, 一个表有且只能有一个主键约束
```

需求1：

```properties
-- 创建表
/*
    语法:
    create table [if not exists]  表名(
        字段名称1 数据类型 [约束],
        字段名称2 数据类型 [约束]
        .....

    ) [character set 字符集编码];

    常见的数据类型:
        整数:  int
        小数: decimal(M,D)
        日期:  datetime  和 timestamp
        字符串(文本):  varchar(长度)

    约束:
        primary key:  主键约束
            被该关键词标注的列, 该列必须保证 非空 和 唯一
            注意: 一个表应该有一个主键约束, 一个表有且只能有一个主键约束
 */

# 在day02_db的库中创建分类表 category
# 字段说明： 分类 id  分类名称 cname
# 数据案例： c01   Phone

# 第一步 创建 day02_db库
drop database if exists day02_db;
create  database day02_db;

# 第二步: 使用库
use day02_db;

# 第三步: 创建表
create table if not exists category(
  id varchar(10) primary key ,
  cname varchar(20)
) ;
```

需求2：

```properties
# 在day02_db的库中创建商品表 product
# 字段说明： 编号: pid 商品名称: pname 商品价格: price 商品分类: category_id
# 数据案例：1 苹果手机 3999.9 c01

create table if not exists day02_db.product(
  pid int primary key ,
  pname varchar(50),
  price decimal(10,1),
  category_id varchar(10)
);
```

### 4. 删除表

格式：

```sql
drop table [if exists] 表名;
```

需求：

```properties
-- 删除表操作:
-- 语法:  drop table [if exists] 表名;

-- 删除 category, 如果表存在的情况下:
drop table if exists day02_db.category;

-- 删除 product, 并且重新创建该表
drop table  if exists day02_db.product;
create table day02_db.product(
  pid int primary key ,
  pname varchar(50),
  price decimal(10,1),
  category_id varchar(10)
);
```

### 5. 修改表结构格式

* 1- 修改表: 添加列

```sql
格式：
	alter table 表名 add 新列名 类型(长度) [约束];	
	
	
-- 需求：为分类表添加一个新的字段为分类描述 describe varchar(20)
-- 字段\表名\库名 这些在定义的时候, 不能和SQL语句中关键词, 例如: create  table  database ....
-- 如果想要使用某个关键词作为普通名称, 可以在SQL中强制使用: 在该关键词的两端使用飘号标记即可
-- 符号: `    esc下面的这个键 1旁边这边键  在英文的格式下 按下即可打出来该符号
alter table day02_db.category add `describe` varchar(20);

-- 查看是否添加成功?
desc day02_db.category;
```

* 2- 修改表: 修改列

```sql
格式：
	alter table 表名 change 旧列名 新列名 类型(长度) [约束];
	

-- 需求：为分类表的分类描述字段更换为  description  varchar(30)
alter table  day02_db.category change `describe` description varchar(30);

desc day02_db.category;
```

* 3- 修改表 删除列

```sql
格式:
	alter table 表名 drop 列名;	
-- 需求：删除分类表中description这列
alter table day02_db.category drop description; 
```

* 4- 修改表名

```sql
格式：
	rename table 旧表名 to 新表名;
-- 需求：为分类表category改名成 category_test
rename table day02_db.category to day02_db.category_test;

```
