## 简介

Python 自带的 `int`、`float`、`str` 是"万能型"数据类型——一个 Python 整数对象除了数值本身，还携带了引用计数、类型指针等一大堆附加信息，灵活但笨重。当做科学计算时，一百万个数字如果都用 Python 对象存储，内存和速度都吃不消。

NumPy 的解决思路和 C 语言一样：**给数据规定明确的类型和固定的字节宽度**。一个 `int32` 永远占 4 个字节，一个 `float64` 永远占 8 个字节，CPU 可以按连续内存块批量处理，这就是 NumPy 快的根本原因。理解 dtype（data type，数据类型）是理解 NumPy 的第一步，因为**创建数组、类型转换、内存估算、精度控制都绕不开它**。

## 基本用法

NumPy 支持的标量类型比 Python 内置丰富得多，按下表分类记忆：

| 类型 | 关键字 | 说明 |
|------|--------|------|
| 布尔 | `bool_` | True / False，占 1 字节 |
| 有符号整数 | `int8` / `int16` / `int32` / `int64` | 数字是位宽，int32 占 4 字节 |
| 无符号整数 | `uint8` / `uint16` / `uint32` / `uint64` | 只存非负数，同样位宽能存更大的正数 |
| 浮点数 | `float16` / `float32` / `float64` | 默认是 float64（双精度） |
| 复数 | `complex64` / `complex128` | 实部+虚部 |
| 字符串 | `str_` | 固定宽度的 Unicode 字符串 |
| 字节串 | `bytes_` | 面向二进制数据 |

```python
import numpy as np

# 创建数组时，dtype 决定了每个元素怎么存
a = np.array([1, 2, 3])                 # 整数列表 → 默认 int64（老版本Windows是int32）
print(a.dtype)                          # 输出: int64

b = np.array([1.5, 2.5, 3.5])           # 小数列表 → 默认 float64
print(b.dtype)                          # 输出: float64

c = np.array([1, 2, 3], dtype=np.int8)  # 显式指定类型，只占 1 字节
print(c.dtype)                          # 输出: int8
```

注意区分 `np.float64` 和 `np.float`：老代码里的 `np.float`、`np.int`、`np.object` 这种"别名写法"在新版 NumPy 中已被移除，必须写完整名字，比如 `np.float64`、`np.int64`、`np.object_`。

## 常用 API 详解

### 1. 查看类型：`dtype` 属性

```python
import numpy as np

a = np.array([[1.0, 2.0], [3.0, 4.0]])
print(a.dtype)            # 输出: float64
print(a.dtype.name)       # 输出: float64（类型名）
print(a.dtype.itemsize)   # 输出: 8（每个元素占的字节数）
print(a.dtype.type)       # 输出: <class 'numpy.float64'>
```

`itemsize` 在估算内存时非常好用：元素个数 × itemsize = 数组占用的裸内存。

### 2. 创建时指定：`dtype` 参数

```python
import numpy as np

a = np.array([1, 0, 1], dtype=np.bool_)     # 非零即 True
print(a)                                     # 输出: [ True False  True]

b = np.arange(5, dtype=np.float32)          # 生成 float32 序列
print(b, b.dtype)                            # 输出: [0. 1. 2. 3. 4.] float32

c = np.zeros(3, dtype=np.complex128)        # 复数零
print(c)                                     # 输出: [0.+0.j 0.+0.j 0.+0.j]
```

### 3. 类型转换：`astype()`

`astype` 返回**新数组**，原数组不变，这是 NumPy 里类型转换的标准姿势：

```python
import numpy as np

a = np.array([1.7, 2.3, 3.9])
b = a.astype(np.int32)          # 浮点转整数：直接截断小数，不是四舍五入
print(b)                        # 输出: [1 2 3]

c = a.astype(np.int32) + 0.5    # 截断后参与运算又会升回 float64
print(c)                        # 输出: [1.5 2.5 3.5]

s = np.array([1, 0, 1]).astype(np.str_)   # 转字符串
print(s, s.dtype)                # 输出: ['1' '0' '1'] <U21
```

### 4. 用字符代码简写

老代码里常见 `dtype='i4'`、`'f8'` 这种缩写：i=整数、u=无符号、f=浮点、U=Unicode 字符串，数字是字节数。

```python
import numpy as np

a = np.array([1, 2], dtype='i8')   # 8字节整数 = int64
print(a.dtype)                      # 输出: int64

b = np.array(['数据', '分析'], dtype='U4')  # 每个字符串最多4个字符
print(b.dtype)                      # 输出: <U4
```

### 5. 类型判断与机器极限

```python
import numpy as np

print(np.issubdtype(np.int32, np.integer))   # 输出: True（int32 属于整数家族）
print(np.issubdtype(np.float32, np.integer)) # 输出: False

# 溢出警告：int8 只能存 -128 ~ 127
a = np.array([125], dtype=np.int8)
print(a + 3)   # 输出: [-128]（溢出绕回，不报错！）
```

## 综合示例

场景：传感器采集的温度数据要落盘存储，用 float64 太浪费，评估各类型的精度和内存，再做安全转换：

```python
import numpy as np

# 1. 模拟 100 万个温度读数（单位：℃）
temps = np.random.uniform(-30, 45, 1_000_000)

# 2. 各类型的内存占用对比
for dt in [np.float64, np.float32, np.float16]:
    arr = temps.astype(dt)
    mb = arr.nbytes / 1024 / 1024
    max_err = np.max(np.abs(arr - temps))
    print(f"{dt.__name__:8s} 占用 {mb:6.1f} MB, 最大误差 {max_err:.4f} ℃")
# 输出:
# float64  占用    7.6 MB, 最大误差 0.0000 ℃
# float32  占用    3.8 MB, 最大误差 0.0000 ℃
# float16  占用    1.9 MB, 最大误差 0.0156 ℃

# 3. 结论：温度保留 2 位小数足够，选 float32（精度够、省一半内存）
storage = temps.astype(np.float32)

# 4. 转成整数分档（0~75 的档位索引）也可以进一步压缩
bins = (temps - (-30)).astype(np.uint8)
print(bins.min(), bins.max(), bins.dtype)   # 输出: 0 74 uint8
```

## 小结

- dtype 是 NumPy 性能的基石，创建数组时**能用小类型就别用默认的 float64**，大批量数据能省数倍内存
- `astype()` 是类型转换的唯一正规途径，浮点转整数是**截断**不是四舍五入
- 整数溢出不会报错而是"绕回"（125+3 变 -128），用 `int8`/`uint8` 存数据前先确认取值范围
- 新版 NumPy 已移除 `np.float`、`np.int` 这类别名，写完整名称才不会踩坑
