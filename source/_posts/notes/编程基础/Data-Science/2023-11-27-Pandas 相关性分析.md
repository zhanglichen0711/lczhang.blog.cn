## 简介

"广告费和销售额到底有没有关系？"——相关性分析回答的就是这类问题。**相关系数**把两个变量的关系压缩成一个 -1 到 1 的数：越接近 1 正相关越强（一起涨），越接近 -1 负相关越强（一涨一跌），接近 0 就是基本没关系。

Pandas 的 `corr()` 一行算出整张表的相关系数矩阵，是探索性分析（EDA）的起手式。但先立一条铁律：**相关不等于因果**——冰淇淋销量和溺水人数高度相关，真凶是夏天。

## 基本用法

```python
import numpy as np
import pandas as pd

# 固定随机种子，保证结果可复现
np.random.seed(7)
n = 30
adv = np.random.randint(50, 300, n)                    # 广告费
sales = adv * 3 + np.random.normal(0, 100, n).round(1) # 销售额 ≈ 广告费×3 + 噪声
temp = np.random.uniform(10, 40, n).round(1)           # 气温（和前两者无关）

df = pd.DataFrame({'广告费': adv, '销售额': sales.round(1), '气温': temp})

print(df.corr(numeric_only=True).round(3).to_string())
# 输出:
#        广告费    销售额     气温
# 广告费  1.000  0.944  0.160
# 销售额  0.944  1.000  0.135
# 气温   0.160  0.135  1.000
```

读这张矩阵：对角线恒为 1（自己和自己的相关），**广告费-销售额 0.944** 是强正相关（毕竟销售额就是按广告费造出来的），气温和谁都在 0.16 以下——纯噪声。

## 常用 API 详解

### 1. 两列相关：Series.corr

```python
import numpy as np
import pandas as pd

np.random.seed(7)
n = 30
adv = np.random.randint(50, 300, n)
sales = adv * 3 + np.random.normal(0, 100, n).round(1)

print(pd.Series(adv).corr(pd.Series(sales)))
# 输出: 0.9440615094196458 → 只关心一对变量时不用算整张矩阵
```

### 2. corrwith：一列对其他所有列

```python
import numpy as np
import pandas as pd

np.random.seed(7)
n = 30
adv = np.random.randint(50, 300, n)
sales = adv * 3 + np.random.normal(0, 100, n).round(1)
temp = np.random.uniform(10, 40, n).round(1)
df = pd.DataFrame({'广告费': adv, '销售额': sales.round(1), '气温': temp})

# 找"谁和销售额最相关"：corrwith 一行出答案
print(df.corrwith(df['销售额']).round(3).to_dict())
# 输出: {'广告费': 0.944, '销售额': 1.0, '气温': 0.135}
```

### 3. 三种方法：pearson / spearman / kendall

```python
import numpy as np
import pandas as pd

np.random.seed(7)
n = 30
adv = np.random.randint(50, 300, n)
sales = adv * 3 + np.random.normal(0, 100, n).round(1)
df = pd.DataFrame({'广告费': adv, '销售额': sales.round(1)})

# pearson：线性关系（默认），对异常值敏感
print(df.corr(method='pearson').loc['广告费', '销售额'].round(4))   # 输出: 0.9441
# spearman：按秩（排名）算相关，只看"是否同向"，抗异常值
print(df.corr(method='spearman').loc['广告费', '销售额'].round(4))  # 输出: 0.9444
# kendall：也是秩相关，小样本稳健
print(df.corr(method='kendall').loc['广告费', '销售额'].round(4))   # 输出: 0.7977
```

经验法则：数据干净、关系近似直线用 pearson；有异常值或关系是单调但非直线（如指数增长）用 spearman。

### 4. 从矩阵里捞最强相关对

```python
import numpy as np
import pandas as pd

np.random.seed(7)
n = 30
adv = np.random.randint(50, 300, n)
sales = adv * 3 + np.random.normal(0, 100, n).round(1)
temp = np.random.uniform(10, 40, n).round(1)
df = pd.DataFrame({'广告费': adv, '销售额': sales.round(1), '气温': temp})

# stack 把矩阵拉成长串，去掉自相关后按 |r| 排序
pairs = df.corr(numeric_only=True).stack()
pairs = pairs[pairs < 1].abs().sort_values(ascending=False).drop_duplicates()
print(pairs.round(3).to_dict())
# 输出: {('广告费', '销售额'): 0.944, ('广告费', '气温'): 0.16, ('销售额', '气温'): 0.135}
```

### 5. 滚动相关：关系随时间变化吗

```python
import numpy as np
import pandas as pd

np.random.seed(7)
n = 30
adv = np.random.randint(50, 300, n)
sales = adv * 3 + np.random.normal(0, 100, n).round(1)

# 窗口 10 天滚动计算：广告策略调整后相关性强不强，一眼可见
rolling_r = pd.Series(adv).rolling(10).corr(pd.Series(sales))
r = rolling_r.dropna().round(2)
print(len(r), r.tolist()[:5])   # 输出: 21 [0.94, 0.94, 0.95, 0.95, 0.93]
```

## 综合示例

一份完整的"营销数据相关性体检"：先算全表相关，再锁定关键变量，最后剔除弱相关变量：

```python
import numpy as np
import pandas as pd

np.random.seed(7)
n = 30
adv = np.random.randint(50, 300, n)
df = pd.DataFrame({
    '广告费': adv,
    '销售额': (adv * 3 + np.random.normal(0, 100, n)).round(1),
    '气温': np.random.uniform(10, 40, n).round(1),
    '投诉数': np.random.randint(0, 10, n),
})

# 1. 全表相关矩阵（numeric_only 跳过非数值列）
corr = df.corr(numeric_only=True)

# 2. 找出和销售额最相关的变量（排除自己）
target = corr['销售额'].drop('销售额').sort_values(ascending=False)
print(target.round(3).to_dict())
# 输出: {'广告费': 0.944, '投诉数': 0.177, '气温': 0.135}

# 3. 只保留与目标相关性够强（|r| > 0.3）的特征，砍掉噪声列
strong = target[target.abs() > 0.3].index.tolist()
print(f"进入建模的特征: {strong}")     # 输出: 进入建模的特征: ['广告费']

# 4. 稳健性校验：spearman 结论一致，说明不是异常值撑起来的假相关
sp = df.corr(method='spearman', numeric_only=True).loc['广告费', '销售额']
print(f"pearson=0.944, spearman={sp:.3f} → 结论稳健")
# 输出: pearson=0.944, spearman=0.944 → 结论稳健
```

## 小结

- 相关系数矩阵是 EDA 的雷达图，但**先画散点图再信相关系数**——Anscombe 四组数据相关系数几乎相同、形态天差地别
- 有异常值或非线性单调关系时换 `method='spearman'`，两种方法结论不一致本身就是重要信号
- 表里混了非数值列记得加 `numeric_only=True`，否则 pandas 3.0 直接报错
