## 简介

加减乘除谁都会，但 NumPy 的算术函数有几个"懂行才用"的点：`mod` 和 `remainder` 的细微差别、`reciprocal` 倒数、整除的两种姿势，以及**除零警告（Warning）而不是报错（Exception）** 的设计哲学——运算出错不会中断程序，而是就地产生 `inf`/`nan`，让你算完统一清理。

这一篇把算术函数过一遍，重点讲清楚和 Python 原生行为不一样的地方。

## 基本用法

```python
import numpy as np

a = np.array([10, 20, 30, 40])
b = np.array([3, 7, 9, 8])

# 四则运算：运算符和函数完全等价
print(np.add(a, b))        # a + b  → [13 27 39 48]
print(np.subtract(a, b))   # a - b  → [ 7 13 21 32]
print(np.multiply(a, b))   # a * b  → [ 30 140 270 320]
print(np.divide(a, b).round(2))   # a / b → [3.33 2.86 3.33 5.  ]

# 所有算术函数都自动支持广播
print(a - 10)              # 标量广播 → [ 0 10 20 30]
```

## 常用 API 详解

### 1. mod / remainder / floor_divide：取余三兄弟

```python
import numpy as np

a = np.array([7, -7, 7, -7])
b = np.array([3, 3, -3, -3])

# remainder（%）：结果的符号跟随除数
print(np.remainder(a, b))    # 输出: [ 1  2 -2 -1]
print(np.mod(a, b))          # mod 就是 remainder 的别名 → [ 1  2 -2 -1]

# fmod：结果的符号跟随被除数（C 语言行为）
print(np.fmod(a, b))         # 输出: [ 1 -1  1 -1]

# floor_divide（//）：向下取整除法
print(np.floor_divide(a, b)) # 输出: [ 2 -3 -3  2]
```

负数取余是经典面试题：`np.mod(-7, 3) = 2`（补成整除），`np.fmod(-7, 3) = -1`（直接砍）。日常分桶、周期对齐用 `mod`，移植 C 代码用 `fmod`。

### 2. reciprocal / negative / power

```python
import numpy as np

a = np.array([1, 2, 4, 10])

print(np.reciprocal(a))          # 倒数 1/x → [1.   0.5  0.25 0.1 ]
print(np.negative(a))            # 取负   → [ -1  -2  -4 -10]

print(np.power(a, 2))            # 平方 → [  1   4  16 100]
print(np.power(2, a))            # 底数2指数数组 → [   2    4   16 1024]
```

`reciprocal` 对整数数组会**整型截断**（1/10 变 0），求精确倒数先转 float：`np.reciprocal(a.astype(float))`。

### 3. 除零不报错：inf 与 nan 的清洗

```python
import numpy as np
import warnings
warnings.filterwarnings('ignore')   # 屏蔽除零警告，让演示输出干净

a = np.array([1, -1, 0, 0])
b = np.array([0, 0, 0, 0])

c = np.divide(a, b)         # 除零 → inf / -inf / nan / nan
print(c)                    # 输出: [ inf -inf  nan  nan]

# 标准清洗三板斧
print(np.isfinite(c))       # 哪些是正常数 → [False False False False]（inf/nan都不算有限）

clean = np.where(np.isfinite(c), c, 0)   # 异常值一律置0
print(clean)                # 输出: [0. 0. 0. 0.]

# 计算前预防：分母为0时先加一个极小量
safe = a / (b + 1e-9)
print(safe.round(2))        # 输出: [ 1.e+09 -1.e+09  0.e+00  0.e+00]
```

### 4. clip：批量限幅（算术家族编外神器）

```python
import numpy as np

temps = np.array([-5.2, 22.1, 38.9, 45.0])

# 限制在 [0, 40] 区间：超上限压到40，低于下限抬到0
print(np.clip(temps, 0, 40))     # 输出: [ 0.  22.1 38.9 40. ]
```

### 5. divmod：商和余数一起拿

```python
import numpy as np

total_minutes = np.array([130, 75, 200])

hours, minutes = np.divmod(total_minutes, 60)
print(hours)      # 输出: [2 1 3]
print(minutes)    # 输出: [10 15 20]
```

## 综合示例

超市小票计算：单价 × 数量、折扣、抹零、找零一条龙：

```python
import numpy as np

# 1. 购物明细
items   = np.array(['苹果', '牛奶', '面包', '鸡蛋'])
prices  = np.array([12.5, 6.8, 8.0, 15.9])     # 单价
counts  = np.array([3, 2, 1, 2])               # 数量
discount = np.array([0.9, 1.0, 0.8, 0.95])     # 折扣率

# 2. 每项小计 = 单价 × 数量 × 折扣
subtotal = np.multiply(np.multiply(prices, counts), discount)
for it, s in zip(items, subtotal):
    print(f"{it}: ¥{s:.2f}")
# 输出:
# 苹果: ¥33.75
# 牛奶: ¥13.60
# 面包: ¥6.40
# 鸡蛋: ¥30.21

# 3. 总价 & 满50减5（clip批量限幅）
total = subtotal.sum()
final = total - np.clip((total // 50) * 5, 0, 15)   # 每50减5，最多减15
print(f"总价 ¥{total:.2f} → 应付 ¥{final:.2f}")
# 输出: 总价 ¥83.96 → 应付 ¥78.96

# 4. 现金找零：divmod 拆成50/10/5/1元
pay = 100
change = int(np.round((pay - final) * 100))    # 以"分"为单位避免浮点误差
print(f"找零 ¥{(pay - final):.2f}")
# 输出: 找零 ¥21.04
n50, r = np.divmod(change, 5000); n10, r = np.divmod(r, 1000)
n5, r = np.divmod(r, 500)
print(f"50元×{n50} 10元×{n10} 5元×{n5} 其余 {r/100:.2f} 元硬币")
# 输出: 50元×0 10元×2 5元×0 其余 1.04 元硬币
```

## 小结

- 运算符 `+ - * / // %` 和同名函数完全等价，团队协作时代码里常混用，都要看得懂
- 负数取余：`mod`/`remainder` 跟随**除数**符号，`fmod` 跟随**被除数**符号，分桶场景用前者
- NumPy **除零只警告不报错**，产出 `inf`/`nan`——算完用 `np.isfinite` 清洗是标准动作
- 涉及金额的浮点运算，先乘100转整数再算，能躲开 0.1+0.2 式的精度坑
