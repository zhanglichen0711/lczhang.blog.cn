## 简介

数据分析师 80% 的时间花在清洗上，这不是玩笑：缺失值、重复行、异常值、格式混乱（"北京市"/"北京 "）、单位不统一（元/万元）……`read_csv` 拿到的原始数据几乎不能直接分析。

Pandas 清洗三板斧：**处理缺失（dropna/fillna）→ 去重（drop_duplicates）→ 修类型和格式（astype/str 方法）**，外加异常值过滤。这一篇用一个"脏订单表"把整套流程串起来，照着做就能覆盖日常 90% 的清洗需求。

## 基本用法

```python
import pandas as pd
import numpy as np

# 一张典型的"脏表"：缺失、重复、字符串数字混杂
dirty = pd.DataFrame({
    '订单号': ['A001', 'A002', 'A002', 'A004'],
    '金额': ['299', '158', '158', None],
    '城市': ['北京', '上海 ', '上海', None],
})
print(dirty.isna().sum().tolist())   # 输出: [0, 1, 1] → 每列缺失数
print(dirty.duplicated().sum())      # 输出: 0 → "上海 "多了个空格，整行重复没识别出来！
```

清洗前先"体检"：`isna().sum()` 看缺在哪、`duplicated().sum()` 看重复多少、`dtypes` 看类型对不对。**先诊断，再动手**。

## 常用 API 详解

### 1. 缺失值：dropna 与 fillna

```python
import pandas as pd
import numpy as np

df = pd.DataFrame({
    '商品': ['键盘', '鼠标', '支架', '耳机'],
    '评分': [4.5, np.nan, 4.2, np.nan],
    '评论数': [120, 35, np.nan, 8],
})

# 丢行：整行全空才丢 / 任一列空就丢
print(df.dropna(how='all').shape)        # 输出: (4, 3)
print(df.dropna().shape)                 # 输出: (2, 3)

# 填充：评分用中位数、评论数用 0，语义不同填法不同
df['评分'] = df['评分'].fillna(df['评分'].median())
df['评论数'] = df['评论数'].fillna(0)
print(df['评分'].tolist())   # 输出: [4.5, 4.35, 4.2, 4.35]
```

### 2. fillna 的进阶：ffill 与时间序列插值

```python
import pandas as pd
import numpy as np

# 传感器数据：某分钟掉线，用前后值推算比填 0 合理得多
ts = pd.Series(
    [22.1, np.nan, np.nan, 22.4, 22.6],
    index=pd.date_range('2023-01-01 10:00', periods=5, freq='min'),
    name='温度')

print(ts.ffill().tolist())          # 输出: [22.1, 22.1, 22.1, 22.4, 22.6] → 用前值
print(ts.interpolate().tolist())    # 输出: [22.1, 22.2, 22.3, 22.4, 22.6] → 线性插值
```

### 3. 去重：drop_duplicates

```python
import pandas as pd

df = pd.DataFrame({
    '订单号': ['A001', 'A002', 'A002', 'A003'],
    '渠道': ['官网', 'APP', 'APP', '小程序'],
    '金额': [299, 158, 158, 88],
})

# 整行重复才删
print(df.drop_duplicates().shape)                        # 输出: (3, 3)
# 按关键列判重：同一订单号只留第一条（上报系统重复合并的常用姿势）
print(df.drop_duplicates(subset=['订单号']).shape)       # 输出: (3, 3)
# keep=False：把所有"参与重复"的行都列出来，人工审核用
print(df[df.duplicated(subset=['订单号'], keep=False)]['订单号'].tolist())
# 输出: ['A002', 'A002']
```

### 4. 类型转换：astype 与 to_numeric

```python
import pandas as pd

df = pd.DataFrame({
    '金额': ['299', '158', 'abc'],       # 混进了脏字符串
    '日期': ['2023-01-01', '2023-01-02', '2023-01-03'],
})

# 直接 astype 会报错；errors='coerce' 把转不动的变成 NaN
df['金额'] = pd.to_numeric(df['金额'], errors='coerce')
print(df['金额'].tolist())     # 输出: [299.0, 158.0, nan]

df['日期'] = pd.to_datetime(df['日期'])
print(df['日期'].dt.year.unique().tolist())   # 输出: [2023]
```

### 5. 字符串清洗：strip / replace / 正则

```python
import pandas as pd

df = pd.DataFrame({'城市': [' 北京 ', '上海', '广州市', '深圳']})

# 链式清洗：去首尾空格 → 去掉"市"字 → 统一维一
df['城市'] = (df['城市'].str.strip()
                      .str.replace('市', '', regex=False))
print(df['城市'].tolist())     # 输出: ['北京', '上海', '广州', '深圳']

# 正则提取：从地址里抠出手机号
addr = pd.Series(['张三 13812345678 北京', '李四 15987654321 上海'])
print(addr.str.extract(r'(\d{11})')[0].tolist())
# 输出: ['13812345678', '15987654321']
```

### 6. 异常值：布尔过滤与 clip

```python
import pandas as pd

df = pd.DataFrame({'用户': ['A', 'B', 'C', 'D'],
                   '年龄': [25, 32, 300, 41]})    # 300 岁明显是录入错误

# 方式一：布尔过滤，直接剔除
clean = df[(df['年龄'] >= 0) & (df['年龄'] <= 120)]
print(clean['用户'].tolist())   # 输出: ['A', 'B', 'D']

# 方式二：clip 截断到边界（保留行，压平极端值）
df['年龄'] = df['年龄'].clip(0, 120)
print(df['年龄'].tolist())      # 输出: [25, 32, 120, 41]
```

## 综合示例

完整清洗一张电商脏订单表，输出可直接分析的干净数据：

```python
import pandas as pd
import numpy as np

raw = pd.DataFrame({
    '订单号': ['A001', 'A002', 'A002', 'A004', 'A005'],
    '金额': ['299', '158', '158', '999999', None],
    '城市': [' 北京 ', '上海市', '上海市', '深圳', 'guangzhou'],
    '日期': ['2023-01-01', '2023-01-02', '2023-01-02', '2023-01-03', '2023-01-04'],
})

# 1. 去重：完全重复的行先删
df = raw.drop_duplicates()

# 2. 修类型：金额转数字，脏值变 NaN
df['金额'] = pd.to_numeric(df['金额'], errors='coerce')

# 3. 修格式：城市去空格、去"市"、映射英文
city_map = {'guangzhou': '广州'}
df['城市'] = (df['城市'].str.strip()
                      .str.replace('市', '', regex=False)
                      .replace(city_map))

# 4. 补缺失：金额用中位数填充
df['金额'] = df['金额'].fillna(df['金额'].median())

# 5. 去异常：金额超过 10000 视为测试单，剔除
df = df[df['金额'] < 10000]

# 6. 日期转 datetime，便于后续按时间分析
df['日期'] = pd.to_datetime(df['日期'])

print(df[['订单号', '金额', '城市']].reset_index(drop=True))
# 输出:
#   订单号     金额   城市
# 0  A001  299.0   北京
# 1  A002  158.0   上海
# 2  A005  299.0   广州 → 缺失金额被填成了中位数 299（此时异常单已进中位数，见小结）

print(f"清洗率: {1 - len(df) / len(raw):.0%}")   # 输出: 清洗率: 40%
```

## 小结

- 清洗顺序有讲究：**先去重再填缺失**——重复行会污染中位数等统计量，进而污染填充值
- `pd.to_numeric(..., errors='coerce')` 和 `pd.to_datetime(..., errors='coerce')` 是脏数据转换的安全带，比 astype 稳
- `inplace=True` 在 pandas 3.0 已逐步弃用，统一写 `df = df.xxx()` 赋值风格，行为更可预期
