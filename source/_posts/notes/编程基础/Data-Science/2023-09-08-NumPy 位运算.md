## 简介

位运算直接操作二进制位：与、或、异或、取反、移位。它平时不显山露水，但潜伏在三个高频场景里——**权限标志位**（一个 int 存十几种开关）、**图像二值化/掩码**（0/1 位图）、**状态压缩**（遗传算法、位棋盘）。

NumPy 的位运算函数作用在整个数组上，配合整数类型，一次能处理百万个位标志，这正是 Python 循环做不到的。

## 基本用法

先把三个基础门电路的真值感觉建立起来：

```python
import numpy as np

a = np.array([1, 0, 1, 0], dtype=np.uint8)   # 二进制位序列
b = np.array([1, 1, 0, 0], dtype=np.uint8)

print(np.bitwise_and(a, b))   # 都为1才1 → 输出: [1 0 0 0]
print(np.bitwise_or(a, b))    # 有1就1   → 输出: [1 1 1 0]
print(np.bitwise_xor(a, b))   # 不同为1   → 输出: [0 1 1 0]
print(np.bitwise_not(a))      # 按位取反 → 输出: [254 255 254 255]
```

运算符写法更简洁：`&`、`|`、`^`、`~`、`<<`、`>>`，效果和函数完全一致。

## 常用 API 详解

### 1. bitwise_and / or / xor：掩码与差异检测

```python
import numpy as np

# 权限系统：每一位代表一种权限
READ, WRITE, EXEC = 1, 2, 4        # 001, 010, 100

user_perm = np.array([READ, READ | WRITE, READ | EXEC, 0])

# 检查谁有写权限：和 WRITE 按位与，非零即有
has_write = (user_perm & WRITE) != 0
print(has_write)      # 输出: [False  True False False]

# 异或找差异：两组权限哪几位不同
old_perm = np.array([READ, READ, READ, READ])
changed = old_perm ^ user_perm      # 非0的位置就是变化点
print(changed)        # 输出: [0 2 4 1]
```

### 2. invert 与掩码取反

```python
import numpy as np

# 二值图像掩码：1=保留，0=擦除
mask = np.array([1, 1, 0, 0, 1], dtype=np.uint8)

inverted = (mask ^ 1)          # 异或1 = 0/1 互换
print(inverted)                # 输出: [0 0 1 1 0]

# 注意：~mask 对 uint8 是按字节取反（1→254），做0/1翻转要用 ^1
print(~np.uint8(1))            # 输出: 254
```

### 3. left_shift / right_shift：打包与解包

```python
import numpy as np

# 左移一位 = ×2，右移一位 = ÷2（整数）
a = np.array([1, 2, 3])
print(np.left_shift(a, 3))     # ×8 → 输出: [ 8 16 24]
print(np.right_shift(a, 1))    # ÷2 → 输出: [0 1 1]

# 位打包：两个 0~15 的数拼进一个字节（高4位+低4位）
high = np.array([1, 15, 7], dtype=np.uint8)
low  = np.array([2, 9, 0], dtype=np.uint8)
packed = (high << 4) | low
print(packed)                  # 输出: [ 18 249 112]

# 解包：右移取高位，掩码0x0F取低位
print((packed >> 4, packed & 0x0F))
# 输出: (array([ 1, 15,  7], dtype=uint8), array([ 2,  9,  0], dtype=uint8))
```

### 4. binary_repr / packbits：观察与打包位串

```python
import numpy as np

print(np.binary_repr(10, width=8))    # 输出: 00001010
print(np.binary_repr(-10, width=8))   # 输出: 11110110（补码）

# packbits：8个0/1压成一个字节，unpackbits 反向拆开
bits = np.array([1,1,0,0,1,0,1,0], dtype=np.uint8)
byte = np.packbits(bits)
print(byte)                            # 输出: [202]   ← 正是二进制11001010

restored = np.unpackbits(byte)
print(restored)                        # 输出: [1 1 0 0 1 0 1 0]
```

## 综合示例

设计一个"用户权限批处理"系统，用位运算一次校验 10 万用户：

```python
import numpy as np

# 权限位定义
P_READ, P_WRITE, P_DELETE, P_ADMIN = 1, 2, 4, 8

rng = np.random.default_rng(3)
n = 100_000

# 1. 每个用户随机拥有若干权限（位组合）
users = rng.integers(0, 16, size=n).astype(np.uint8)

# 2. 一行判断所有用户是否同时具有 读+写 权限
rw_mask = (users & (P_READ | P_WRITE)) == (P_READ | P_WRITE)
print(f"读写双全用户: {rw_mask.sum()} 人, 占比 {rw_mask.mean():.1%}")
# 输出: 读写双全用户: 25041 人, 占比 25.0%

# 3. 批量提权：给所有管理员追加删除权限
is_admin = (users & P_ADMIN) != 0
users[is_admin] |= P_DELETE
print(f"管理员人数: {is_admin.sum()}, 现在全有删除权: "
      f"{np.all((users[is_admin] & P_DELETE) != 0)}")
# 输出: 管理员人数: 49978, 现在全有删除权: True

# 4. 权限组合去重统计：3秒内看清全部角色分布
combos, counts = np.unique(users, return_counts=True)
for c, k in zip(combos, counts):
    names = [nm for bit, nm in [(1,'读'),(2,'写'),(4,'删'),(8,'管')] if c & bit]
    print(f"权限[{'+'.join(names) or '无'}]: {k} 人")
# 输出（共12种组合，节选）:
# 权限[无]: 6433 人
# 权限[读]: 6278 人
# 权限[写]: 6219 人
# 权限[读+写]: 6209 人
# ...
# 权限[读+写+删+管]: 12558 人
```

## 小结

- 一组布尔开关不要存 10 个字段，**一个整数的 10 个二进制位**就够，NumPy 位运算可整体批量处理
- `&` 判存在、`|` 合并、`^` 找差异/翻转 0/1、`~` 按位取反（uint 会得到 255-x）
- 0/1 掩码翻转用 `^ 1`，别用 `~`（除非你真想要按字节取反）
- `packbits`/`unpackbits` 是位串和字节的转换桥梁，通信协议、压缩场景常见
