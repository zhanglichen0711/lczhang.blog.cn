## 简介

一个 ndarray 不仅有数据，还自带一份"身份证"——形状、维度、元素个数、内存占用、类型等信息。这些**数组属性**是调试和数据处理中最常打交道的对象：拿到一份数组，第一件事往往就是看它的 shape；广播报错了，八成是 shape 对不上；做机器学习时 batch 的形状检查更是家常便饭。

把这几个属性记熟，你就能随时"透视"任何数组，而不用靠猜。

## 基本用法

核心属性一览（假设 `a` 是任意 ndarray）：

| 属性 | 含义 | 举例（3行4列的二维数组） |
|------|------|------|
| `shape` | 各维度大小的元组 | `(3, 4)` |
| `ndim` | 维度个数（轴的个数） | `2` |
| `size` | 元素总个数 | `12` |
| `itemsize` | 单个元素字节数 | float64 → `8` |
| `nbytes` | 数组总字节数 | `12 × 8 = 96` |
| `dtype` | 元素数据类型 | `int64` |
| `T` | 转置视图 | shape 变 `(4, 3)` |

```python
import numpy as np

# 一个 3 行 4 列的成绩表：每行一个学生，每列一门课
scores = np.array([[92, 88, 79, 95],
                   [85, 90, 76, 88],
                   [78, 82, 91, 84]])

print(scores.shape)     # 输出: (3, 4)  → 3个学生 × 4门课
print(scores.ndim)      # 输出: 2       → 二维
print(scores.size)      # 输出: 12      → 共12个成绩
print(scores.dtype)     # 输出: int64
print(scores.nbytes)    # 输出: 96      → 12个元素 × 8字节
```

记忆技巧：**ndim 是 shape 元组的长度，size 是 shape 元素的乘积**。这三个属性永远满足 `a.size == np.prod(a.shape)`。

## 常用 API 详解

### 1. shape：最重要的属性

```python
import numpy as np

a = np.zeros((2, 3, 4))
print(a.shape)      # 输出: (2, 3, 4) → 三维：2个 3×4 的平面
print(len(a.shape)) # 输出: 3（等价于 ndim）

# shape 也可以被赋值（原地改变形状，元素总数必须一致）
b = np.arange(6)
b.shape = (2, 3)
print(b)
# 输出:
# [[0 1 2]
#  [3 4 5]]

# 一维数组的 shape 是只含一个数的元组
c = np.array([1, 2, 3])
print(c.shape)      # 输出: (3,)
```

`(3,)` 这个带逗号的元组是新手常见疑惑——它就是"长度为 3 的一维数组"，和 `(3, 1)`、`(1, 3)` 完全是三码事。

### 2. ndim / size / itemsize / nbytes

```python
import numpy as np

a = np.random.rand(100, 100)   # 1万个 float64

print(a.ndim)        # 输出: 2
print(a.size)        # 输出: 10000
print(a.itemsize)    # 输出: 8（float64 每个 8 字节）
print(a.nbytes)      # 输出: 80000（≈ 78 KB）

# 估算大数组内存时优先用 nbytes，一目了然
print(f"约 {a.nbytes / 1024 / 1024:.2f} MB")   # 输出: 约 0.08 MB
```

### 3. T：转置

```python
import numpy as np

a = np.arange(6).reshape(2, 3)
print(a)
# 输出:
# [[0 1 2]
#  [3 4 5]]

print(a.T)
# 输出:
# [[0 3]
#  [1 4]
#  [2 5]]

print(a.T.shape)   # 输出: (3, 2)
```

注意 `T` 返回的是**视图**（view）而不是拷贝，改 `a.T` 的元素会连带改到 `a`。

### 4. flags / real / imag 等进阶属性

```python
import numpy as np

a = np.array([1+2j, 3+4j])
print(a.real)    # 输出: [1. 3.]（实部）
print(a.imag)    # 输出: [2. 4.]（虚部）

b = np.arange(5)
print(b.flags['C_CONTIGUOUS'])   # 输出: True（内存按行连续）
```

## 综合示例

写一个通用的"数组体检函数"，数据管道里每一步都打印数组状态，方便定位问题：

```python
import numpy as np

def inspect(arr, name="数组"):
    """打印一个数组的关键属性，数据管道调试利器"""
    print(f"── {name} ──")
    print(f"  shape={arr.shape}, ndim={arr.ndim}, size={arr.size}")
    print(f"  dtype={arr.dtype}, nbytes={arr.nbytes/1024:.1f} KB")
    if arr.size:
        print(f"  min={arr.min()}, max={arr.max()}, mean={arr.mean():.2f}")

# 模拟一条数据处理流水线
raw = np.random.randn(1000, 28, 28)          # 1000张 28×28 的"图片"
inspect(raw, "原始数据")                       # shape=(1000, 28, 28)

flattened = raw.reshape(1000, 784)            # 展平成特征向量
inspect(flattened, "展平后")                   # shape=(1000, 784)

normalized = (flattened - flattened.mean()) / flattened.std()  # 标准化
inspect(normalized, "标准化后")                 # mean≈0, std≈1

# 输出:
# ── 原始数据 ──
#   shape=(1000, 28, 28), ndim=3, size=784000
#   dtype=float64, nbytes=6125.0 KB
#   ...
# ── 标准化后 ──
#   shape=(1000, 784), ndim=2, size=784000
#   min=-4.9x, max=5.0x, mean=0.00
```

## 小结

- 拿到陌生数组先打印 `shape` 和 `dtype`，80% 的维度错误当场就能发现
- `(3,)`、`(3,1)`、`(1,3)` 是三个不同的东西：一维向量、列向量、行向量，广播时尤其要分清
- `nbytes = size × itemsize`，处理大数组前先算内存，别等程序崩了才查
- `T` 是转置视图不拷贝数据，省内存但也意味着改动会互相影响
