## 简介

三角函数、指数、对数、开方、舍入——这些基础数学运算是数值计算的砖瓦。Python 内置的 `math` 模块一次只能算一个数，而 NumPy 的数学函数是**向量化的**：传入数组，逐元素计算，一次百万个。

一句话区分这一篇和下一篇：**数学函数是"对每个元素算一个值"（sin、log、round），算术函数是"元素与元素之间做运算"（加减乘除）**。

## 基本用法

```python
import numpy as np

# NumPy 数学函数吃数组，math 模块只能吃标量
angles = np.array([0, np.pi / 6, np.pi / 4, np.pi / 3, np.pi / 2])

print(np.sin(angles).round(2))
# 输出: [0.   0.5  0.71 0.87 1.  ]

# 角度制与弧度制互转：degrees / radians
print(np.degrees(np.pi / 2))   # 输出: 90.0
print(np.radians(180))         # 输出: 3.141592653589793
```

**新手第一坑：np.sin 的入参是弧度不是角度**，想算 sin(30°) 要写 `np.sin(np.radians(30))`。

## 常用 API 详解

### 1. 三角函数家族

```python
import numpy as np

deg = np.array([0, 30, 45, 60, 90])
rad = np.radians(deg)                 # 先转弧度

print(np.sin(rad).round(2))           # 输出: [0.   0.5  0.71 0.87 1.  ]
print(np.cos(rad).round(2))           # 输出: [1.   0.87 0.71 0.5  0.  ]
print(np.tan(rad).round(2))
# 输出: [0.00000000e+00 5.80000000e-01 1.00000000e+00 1.73000000e+00
#  1.63312394e+16]  ← tan(90°) 不是无穷大，是天文数字

# 反三角：arcsin/arccos/arctan 返回弧度
print(np.degrees(np.arcsin(0.5)))     # 输出: 30.000000000000004

# arctan2(y, x)：按坐标算角度，自动判断象限
print(np.degrees(np.arctan2(1, 1)))       # 输出: 45.0（第一象限）
print(np.degrees(np.arctan2(-1, -1)))     # 输出: -135.0（第三象限，不是45）
```

### 2. 指数与对数

```python
import numpy as np

x = np.array([1, 10, 100])

print(np.exp(1).round(4))         # e^1 ≈ 输出: 2.7183
print(np.exp2(np.array([2, 3])))  # 2的幂 → 输出: [4. 8.]
print(np.power(3, np.array([1, 2, 3])))   # 3的幂 → 输出: [ 3  9 27]

print(np.log(np.e))               # ln(e) → 输出: 1.0
print(np.log10(x))                # 常用对数 → 输出: [0. 1. 2.]
print(np.log2(np.array([8, 1024])))  # 输出: [ 3. 10.]

# 坑：log(0) = -inf、log(负数) = nan，会警告但不报错
bad = np.array([1, 0, -1])
print(np.log(bad))                # 输出: [  0. -inf   nan]
```

### 3. 舍入家族：around / floor / ceil / rint

```python
import numpy as np

prices = np.array([3.14159, 2.71828, 1.61803, -2.5])

print(np.round(prices, 2))        # 四舍五入到2位 → [ 3.14  2.72  1.62 -2.5 ]
print(np.floor(prices))           # 向下取整     → [ 3.  2.  1. -3.]
print(np.ceil(prices))            # 向上取整     → [ 4.  3.  2. -2.]
print(np.rint(prices))            # 就近取整     → [ 3.  3.  2. -2.]
print(np.trunc(prices))           # 截断小数     → [ 3.  2.  1. -2.]
```

注意 `floor/ceil` 对负数的行为：`floor(-2.5) = -3`（往更小方向），`trunc(-2.5) = -2`（朝零砍）。

### 4. sqrt / cbrt / abs / sign

```python
import numpy as np

a = np.array([4, 9, 16])
print(np.sqrt(a))                     # 输出: [2. 3. 4.]
print(np.cbrt(27))                    # 立方根 → 输出: 3.0

b = np.array([-3, -1, 0, 2])
print(np.abs(b))                      # 绝对值 → [3 1 0 2]
print(np.sign(b))                     # 符号 → [-1 -1  0  1]

# 实战：L2 范数（向量化勾股定理）
v = np.array([3, 4])
print(np.sqrt((v ** 2).sum()))        # 输出: 5.0
```

### 5. 浮点误差的天敌：np.isclose

```python
import numpy as np

a = 0.1 + 0.2
print(a == 0.3)                       # 输出: False！（浮点误差）

print(np.isclose(a, 0.3))             # 输出: True
print(np.isclose([0.1, 0.2, 0.3], [0.1, 0.2, 0.30000001], atol=1e-6))
# 输出: [ True  True  True]
```

## 综合示例

信号处理入门：生成一段含噪声的正弦波，再做频谱量级分析：

```python
import numpy as np

# 1. 生成时间轴：0~1秒，采样率1000Hz
t = np.linspace(0, 1, 1000)

# 2. 纯净信号：50Hz 正弦 + 120Hz 干扰
signal = 1.0 * np.sin(2 * np.pi * 50 * t) + 0.5 * np.sin(2 * np.pi * 120 * t)

# 3. 加噪声
rng = np.random.default_rng(0)
noisy = signal + rng.normal(0, 0.2, t.size)

# 4. 基本统计：噪声让信噪发生什么变化
print(f"纯净信号: 峰值 {np.abs(signal).max():.2f}, 有效值 "
      f"{np.sqrt((signal**2).mean()):.3f}")
# 输出: 纯净信号: 峰值 1.49, 有效值 0.790
print(f"含噪信号: 峰值 {np.abs(noisy).max():.2f}, 有效值 "
      f"{np.sqrt((noisy**2).mean()):.3f}")
# 输出: 含噪信号: 峰值 1.79, 有效值 0.819

# 5. dB 表示（对数换算）
power_ratio = (noisy ** 2).sum() / (signal ** 2).sum()
print(f"功率比: {power_ratio:.3f} = {10 * np.log10(power_ratio):.2f} dB")
# 输出: 功率比: 1.074 = 0.31 dB

# 6. 量化电平：舍入到 0.25 的网格（模拟 ADC 采样）
adc = np.round(noisy / 0.25) * 0.25
print(f"量化误差最大 {np.abs(adc - noisy).max():.3f}")
# 输出: 量化误差最大 0.125
```

## 小结

- 三角函数**永远先转弧度**，`np.radians` 是最容易忘的一步；反算象限角度用 `arctan2`
- `log(0)` 得 `-inf`、`log(-1)` 得 `nan`，不报错只警告，取对数前先筛非正数
- `floor` 向负无穷走、`trunc` 朝零砍，处理负数时二者不同，别混用
- 浮点数比较**永远用 `np.isclose`**，`==` 会让你在 0.1+0.2 问题上怀疑人生
