## 简介

数据分析的第一步永远是"把数据弄进来"，最后一步是"把结果送出去"。Pandas 提供了一套统一的读写接口：**读取用 `pd.read_xxx()`，写出用 `df.to_xxx()`**，涵盖 CSV、Excel、JSON、SQL、HTML、Parquet 等十几种格式。

好消息是这些接口的参数高度一致（`index_col`、`dtype`、`encoding`……学一个等于学十个），所以这篇文章不逐个深讲，而是把**整体地图**和**通用套路**讲清楚，后续每种格式各有一篇专文展开。

## 基本用法

```python
import pandas as pd

WORK = 'E:/workbuddy/2026-09-04-20-53-16/tmp_data/'

# 先造一份示例数据（实际使用时你的文件已经存在，直接读即可）
demo = pd.DataFrame({'商品': ['键盘', '鼠标'], '销量': [10, 20]})
demo.to_csv(WORK + 'sales.csv', index=False)
demo.to_excel(WORK + 'report.xlsx', index=False)
demo.to_json(WORK + 'data.json', orient='records', force_ascii=False)

# 一行读，一行写，格式对称
df = pd.read_csv(WORK + 'sales.csv')          # 读CSV
df.to_csv(WORK + 'sales_backup.csv')          # 写CSV

df2 = pd.read_excel(WORK + 'report.xlsx')     # 读Excel
df2.to_excel(WORK + 'report_out.xlsx')        # 写Excel

df3 = pd.read_json(WORK + 'data.json')        # 读JSON
df3.to_json(WORK + 'data_out.json')           # 写JSON
```

读进来的统一是 DataFrame——**不管源头是什么格式，进了 Pandas 就是同一张表**，后面清洗、分析、可视化的代码完全复用。这就是"格式无关"的威力。

## 常用 API 详解

### 1. 读取时的通用参数（以 CSV 为例，其他格式同理）

```python
import pandas as pd

WORK = 'E:/workbuddy/2026-09-04-20-53-16/tmp_data/'

# 造一份带编号/日期/金额的订单表
demo = pd.DataFrame({
    '编号': ['D001', 'D002'],
    '日期': ['2023-10-01', '2023-10-02'],
    '金额': [299.0, 89.0],
})
demo.to_csv(WORK + 'orders_demo.csv', index=False)

df = pd.read_csv(
    WORK + 'orders_demo.csv',
    index_col='编号',      # 用"编号"列当行索引（而不是生成0,1,2...）
    encoding='utf-8',     # 中文乱码时换 'gbk' 试试
    dtype={'金额': float}, # 指定列类型，避免被猜错
    parse_dates=['日期'],  # 日期字符串自动转 datetime 类型
    nrows=100,            # 只读前N行（先探探大文件的结构）
)
print(df.dtypes)
# 输出:
# 日期     datetime64[ns]
# 金额             float64
```

### 3. 各格式速查表

| 格式 | 读取 | 写出 | 一句话场景 |
|------|------|------|-----------|
| CSV | `read_csv` | `to_csv` | 通用交换格式，首选 |
| Excel | `read_excel` | `to_excel` | 人类友好，老板爱看 |
| JSON | `read_json` | `to_json` | API/前端对接 |
| SQL | `read_sql` | `to_sql` | 数据库直连 |
| HTML | `read_html` | — | 网页表格抓取 |
| Parquet | `read_parquet` | `to_parquet` | 大数据存储，又快又小 |
| Feather | `read_feather` | `to_feather` | 本地临时缓存，读写飞快 |
| 剪贴板 | `read_clipboard` | `to_clipboard` | 从Excel复制的数据直接读 |

### 4. 写出时的通用参数

```python
import pandas as pd

df = pd.DataFrame({'a': [1, 2], 'b': ['x', 'y']})

df.to_csv(
    'out.csv',
    index=False,       # 不写行索引（最常见的设置！默认会多出一列0,1,2）
    encoding='utf-8-sig',  # 带BOM的UTF-8，Excel打开中文不乱码
    columns=['a', 'b'],    # 只写指定列，还能顺便控制顺序
)
```

`index=False` 记住：默认写出会带一列没意义的行号，99% 场景都要关掉。

## 综合示例

一次完整的数据进出流程：生成 → 存 CSV → 读回 → 分析 → 存 Excel 报告：

```python
import pandas as pd

WORK = 'E:/workbuddy/2026-09-04-20-53-16/tmp_data/'

# 1. 准备示例数据（一个电商订单表）
df = pd.DataFrame({
    '订单号': ['D001', 'D002', 'D003', 'D004'],
    '商品': ['键盘', '鼠标', '显示器', '键盘'],
    '金额': [299.0, 89.0, 1599.0, 349.0],
    '日期': pd.to_datetime(['2023-10-01', '2023-10-01', '2023-10-02', '2023-10-02']),
})

# 2. 存成 CSV（索引不要，日期带BOM防乱码）
df.to_csv(WORK + 'orders.csv', index=False, encoding='utf-8-sig')

# 3. 读回来：日期列自动解析
back = pd.read_csv(WORK + 'orders.csv', parse_dates=['日期'])
print(back.dtypes)
# 输出:
# 订单号            object
# 商品              object
# 金额             float64
# 日期      datetime64[ns]

# 4. 简单分析：各商品销售额
summary = back.groupby('商品')['金额'].agg(['count', 'sum'])
print(summary)
# 输出:
#       count    sum
# 商品
# 显示器      1  1599.0
# 键盘       2   648.0
# 鼠标       1    89.0

# 5. 结果写入 Excel 报告
summary.to_excel(WORK + 'report.xlsx', sheet_name='商品汇总')
print("报告已生成")
# 输出: 报告已生成
```

## 小结

- 读写接口**对称记忆**：`read_xxx` / `to_xxx`，参数大同小异，学会 CSV 其余触类旁通
- 读大文件先 `nrows` 侦察，再 `chunksize` 分块，别一上来就整读把自己撑死
- 写 CSV 记得 `index=False` 和 `encoding='utf-8-sig'`（要给 Excel 用户看的话）
- 格式选择：交换用 CSV、给人看用 Excel、API 用 JSON、存大数据用 Parquet
