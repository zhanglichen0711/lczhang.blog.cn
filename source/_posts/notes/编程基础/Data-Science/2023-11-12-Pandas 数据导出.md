## 简介

分析做完了，最后一公里是把结果**交出去**：给老板的 Excel、给下游系统的 CSV、给数据平台的 Parquet……Pandas 的 `to_*` 家族覆盖了几乎所有出口。导出看似简单，翻车却最多：中文乱码、莫名多出一列 `Unnamed: 0`、小数位一长串、追加写把表头重复写了八遍——都是参数没用对。

这一篇把导出的高频参数一次讲透。记住一个心智模型：**`to_xxx` 的参数回答三个问题——写哪些（index/columns）、怎么写（sep/float_format）、写到哪（mode/sheet_name）**。

## 基本用法

```python
import pandas as pd

WORK = 'E:/workbuddy/2026-09-04-20-53-16/tmp_data/'

df = pd.DataFrame({
    '商品': ['机械键盘', '无线鼠标', '显示器支架'],
    '销量': [120, 350, 88],
    '单价': [599.0, 149.0, 259.0],
})

df.to_csv(WORK + 'out.csv', index=False)        # index=False：别把行号写出去
back = pd.read_csv(WORK + 'out.csv')
print(back.columns.tolist())    # 输出: ['商品', '销量', '单价'] → 没有多余的索引列
```

`index=False` 是导出 CSV 的第一原则：默认行索引（往往是无意义的 0,1,2…）会占掉第一列，别人读回来就多一列 `Unnamed: 0`。

## 常用 API 详解

### 1. 编码：中文乱码的终结者

```python
import pandas as pd

WORK = 'E:/workbuddy/2026-09-04-20-53-16/tmp_data/'
df = pd.DataFrame({'姓名': ['张三'], '工资': [12500]})

# UTF-8 带 BOM：Excel 双击打开中文不乱码（无 BOM 的 UTF-8 是乱码重灾区）
df.to_csv(WORK + 'salary_excel.csv', index=False, encoding='utf-8-sig')

# 交给老系统可能需要 GBK
df.to_csv(WORK + 'salary_gbk.csv', index=False, encoding='gbk')
print(pd.read_csv(WORK + 'salary_gbk.csv', encoding='gbk')['姓名'].tolist())
# 输出: ['张三'] → 读写编码一致才不乱码
```

### 2. na_rep 与 float_format：控制输出细节

```python
import pandas as pd
import numpy as np

WORK = 'E:/workbuddy/2026-09-04-20-53-16/tmp_data/'
df = pd.DataFrame({
    '商品': ['键盘', '鼠标', '支架'],
    '评分': [4.333333, np.nan, 4.666667],
})

# 缺失值写成 "未评分"，小数保留1位
df.to_csv(WORK + 'rating.csv', index=False, na_rep='未评分', float_format='%.1f')
print(open(WORK + 'rating.csv', encoding='utf-8').read())
# 输出:
# 商品,评分
# 键盘,4.3
# 鼠标,未评分
# 支架,4.7
```

### 3. columns 与 header：只导出需要的列

```python
import pandas as pd

WORK = 'E:/workbuddy/2026-09-04-20-53-16/tmp_data/'
df = pd.DataFrame({
    '工号': ['E001', 'E002'],
    '姓名': ['张三', '李四'],
    '身份证号': ['110***', '310***'],     # 敏感字段不能导出
    '工资': [12500, 9800],
})

# 白名单导出 + 自定义表头（脱敏交付）
df.to_csv(WORK + 'public.csv', index=False,
          columns=['工号', '姓名', '工资'], header=['ID', 'Name', 'Salary'])
print(pd.read_csv(WORK + 'public.csv').columns.tolist())   # 输出: ['ID', 'Name', 'Salary']
```

### 4. 追加写与跳过表头

```python
import pandas as pd

WORK = 'E:/workbuddy/2026-09-04-20-53-16/tmp_data/'

# 定时任务每小时写一批新数据到同一个文件
batch1 = pd.DataFrame({'时间': ['10:00'], '在线人数': [5320]})
batch2 = pd.DataFrame({'时间': ['11:00'], '在线人数': [6410]})
batch1.to_csv(WORK + 'online.csv', index=False, mode='w')            # 首批写表头
batch2.to_csv(WORK + 'online.csv', index=False, mode='a', header=False)  # 追加不写表头

log = pd.read_csv(WORK + 'online.csv')
print(len(log))     # 输出: 2 → 表头只有一份
```

### 5. 一个 Excel 写多个 Sheet

```python
import pandas as pd

WORK = 'E:/workbuddy/2026-09-04-20-53-16/tmp_data/'
sales = pd.DataFrame({'月份': ['1月', '2月'], '销售额': [120.5, 135.2]})
cost = pd.DataFrame({'月份': ['1月', '2月'], '成本': [80.1, 88.7]})

# ExcelWriter 上下文管理器：多个 df 写进同一个文件的不同 Sheet
with pd.ExcelWriter(WORK + 'report.xlsx') as w:
    sales.to_excel(w, sheet_name='销售', index=False)
    cost.to_excel(w, sheet_name='成本', index=False)

sheets = pd.read_excel(WORK + 'report.xlsx', sheet_name=None)
print(list(sheets.keys()))    # 输出: ['销售', '成本']
```

### 6. to_markdown / to_clipboard：写给"人"看的导出

```python
import pandas as pd

df = pd.DataFrame({'语言': ['Python', 'SQL'], '占比': [0.62, 0.27]})

# 直接生成 Markdown 表格（写文档、贴周报神器），依赖 tabulate
print(df.to_markdown(index=False))
# 输出:
# | 语言     |   占比 |
# |:-------|-----:|
# | Python | 0.62 |
# | SQL    | 0.27 |

# 复制到系统剪贴板，Ctrl+V 直接贴进 Excel/邮件
df.to_clipboard(index=False)
```

## 综合示例

把一份分析结果按"领导版 / 系统版 / 文档版"三种口径分别导出：

```python
import pandas as pd

WORK = 'E:/workbuddy/2026-09-04-20-53-16/tmp_data/'

result = pd.DataFrame({
    '门店': ['中关村', '五道口', '西二旗'],
    '销售额': [128000.456, 98650.123, 76200.89],
    '完成率': [1.062, 0.987, 0.843],
})

# 1. 领导版：Excel 双 Sheet（明细 + 汇总），小数干净、中文不乱码
summary = pd.DataFrame({'总销售额': [result['销售额'].sum()],
                        '平均完成率': [result['完成率'].mean().round(3)]})
with pd.ExcelWriter(WORK + '领导版.xlsx') as w:
    result.to_excel(w, sheet_name='明细', index=False, float_format='%.2f')
    summary.to_excel(w, sheet_name='汇总', index=False)

# 2. 系统版：CSV 无表头、竖线分隔（对接老系统接口的常见要求）
result.to_csv(WORK + 'system.txt', index=False, header=False, sep='|',
              float_format='%.0f')
print(open(WORK + 'system.txt', encoding='utf-8').read().splitlines()[0])
# 输出: 中关村|128000|1 → 完成率也被 %.0f 格式化成了 1

# 3. 文档版：Markdown 表格，直接贴进周报
print(result.to_markdown(index=False, floatfmt='.1f'))
# 输出:
# | 门店   |      销售额 |   完成率 |
# |:-----|---------:|------:|
# | 中关村  | 128000.5 |   1.1 |
# | 五道口  |  98650.1 |   1.0 |
# | 西二旗  |  76200.9 |   0.8 |
```

## 小结

- 给人看用 `encoding='utf-8-sig'`（Excel 打开不乱码）、给机器看用默认 `utf-8`
- `index=False` 是导出的肌肉记忆；追加写记得 `mode='a', header=False` 成对出现
- 敏感字段导出前用 `columns` 白名单过滤——数据一旦出了门，就收不回来了
