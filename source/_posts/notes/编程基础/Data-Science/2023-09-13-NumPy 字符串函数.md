## 简介

清洗数据时最烦的就是字符串：统一大小写、去空格、拆列、替换脏字符……用 Python 的 for 循环一个个处理 10 万条记录？慢得让人心焦。

NumPy 的 `np.char` 模块把 Python 字符串方法"搬"到了数组层面：**一个函数调用，整个数组的每个元素同时处理**，写法向量化，速度数量级提升。对于 ETL 数据清洗的第一道工序（标准化字符串字段），它是趁手的快刀。

## 基本用法

```python
import numpy as np

names = np.array(['  Alice  ', 'BOB', ' charlie '])

# 去除首尾空格 + 转小写：链式调用
clean = np.char.strip(names)
clean = np.char.lower(clean)
print(clean)         # 输出: ['alice' 'bob' 'charlie']

# 拼接前缀：add 或 + 运算符
greet = np.char.add('hi_', clean)
print(greet)         # 输出: ['hi_alice' 'hi_bob' 'hi_charlie']

# 字符串重复：multiply
tag = np.char.multiply(np.array(['ab']), 3)
print(tag)           # 输出: ['ababab']
```

注意：`np.char` 系列函数返回的是 dtype 为 `<Uxx` 的字符串数组，长度取最长元素。

## 常用 API 详解

### 1. 大小写家族

```python
import numpy as np

s = np.array(['hello world', 'PYTHON numpy', 'data Science'])

print(np.char.upper(s))        # 全大写 → ['HELLO WORLD' 'PYTHON NUMPY' 'DATA SCIENCE']
print(np.char.lower(s))        # 全小写 → ['hello world' 'python numpy' 'data science']
print(np.char.capitalize(s))   # 首字母大写 → ['Hello world' 'Python numpy' 'Data science']
print(np.char.title(s))        # 每个单词首字母大写 → ['Hello World' 'Python Numpy' 'Data Science']
```

### 2. split：拆列（返回列表的数组）

```python
import numpy as np

records = np.array(['张三,18,男', '李四,19,女', '王五,20,男'])

parts = np.char.split(records, sep=',')
print(parts)
# 输出: [list(['张三', '18', '男']) list(['李四', '19', '女']) list(['王五', '20', '男'])]

# 想还原成规整的二维数组，用 list comprehension + vstack
table = np.array([p for p in parts])
print(table[:, 0])       # 输出: ['张三' '李四' '王五']
print(table[:, 1])       # 输出: ['18' '19' '20']
```

### 3. replace：批量替换脏字符

```python
import numpy as np

dirty = np.array(['￥1,200', '￥850', '￥3,000'])

clean = np.char.replace(dirty, '￥', '')      # 去货币符号
clean = np.char.replace(clean, ',', '')       # 去千分位逗号
print(clean)                                   # 输出: ['1200' '850' '3000']
print(clean.astype(np.int32) * 2)              # 转回数值参与计算 → [2400 1700 6000]
```

### 4. strip / lstrip / rstrip：去空白

```python
import numpy as np

s = np.array(['__data__', '__science__', 'x_info'])

print(np.char.strip(s, '_'))      # 两边都去 → ['data' 'science' 'x_info']
print(np.char.lstrip(s, '_'))     # 只去左边 → ['data__' 'science__' 'x_info']
```

### 5. 判断类函数：向量化正则预筛

```python
import numpy as np

s = np.array(['abc', '123', 'abc123', '  ', 'A1'])

print(np.char.isdigit(s))    # 纯数字？ → [False  True False False False]
print(np.char.isalpha(s))    # 纯字母？ → [ True False False False False]
print(np.char.isspace(s))    # 纯空白？ → [False False False  True False]
print(np.char.startswith(s, 'a'))   # 输出: [ True False False False False]
```

## 综合示例

一个"脏数据表"的完整清洗流水线：

```python
import numpy as np

# 1. 从CSV读进来的原始字符串（模拟各种脏法）
raw = np.array([
    '  Alice , 168 , beijing ',
    'BOB,175.5,SHANGHAI',
    ' charlie , 159 , 广州 ',
    'BOB,175.5,SHANGHAI',
])

# 2. 逐行拆分（先strip整体，再split）
rows = np.char.strip(raw)
parts = np.array([line.split(',') for line in rows])

# 3. 各列独立清洗
names = np.char.strip(parts[:, 0])
names = np.char.capitalize(names)              # 统一姓名格式

heights = np.char.strip(parts[:, 1]).astype(float)

cities = np.char.strip(parts[:, 2])
cities = np.char.lower(cities)                 # 统一小写便于匹配
city_map = {'beijing': '北京', 'shanghai': '上海', '广州': '广州'}
cities = np.array([city_map.get(c, c) for c in cities])

print(names)      # 输出: ['Alice' 'Bob' 'Charlie' 'Bob']
print(heights)    # 输出: [168.  175.5 159.  175.5]
print(cities)     # 输出: ['北京' '上海' '广州' '上海']

# 4. 姓名去重，保留唯一记录
_, idx = np.unique(names, return_index=True)
unique_names = names[np.sort(idx)]
print(unique_names)    # 输出: ['Alice' 'Bob' 'Charlie']
```

## 小结

- `np.char` 是字符串数组版本的 Python 字符串方法集，**清洗流程先统一格式（strip/lower）再拆分（split）**
- 字符串数组不能直接算术，记得 `astype` 转回数值；反过来数值转字符串用 `astype(str)`
- `np.char.split` 返回的是"列表的数组"，需要规整表格时用列表推导 + `np.array` 重建
- 特复杂的清洗逻辑（正则、多条件）交给 `np.char.mod` 或直接转 Pandas 的 `str` 访问器更省心
