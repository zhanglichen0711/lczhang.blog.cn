## 简介

明细数据看趋势，聚合数据看结论。"各部门平均工资多少？哪个门店销售额垫底？"——这类问题的答案都藏在 **分组聚合（groupby）** 里。如果说 DataFrame 是一张明细账，groupby 就是把账本按维度折叠成报表的机器。

排序（sort_values）则是聚合的好搭档：算完"各城市 GMV"之后再排个序，Top / 垫底一目了然。这一篇讲透 `sort_values`、`groupby`、`agg`、`pivot_table` 四个核心，它们能覆盖日常分析 80% 的场景。

## 基本用法

```python
import pandas as pd

df = pd.DataFrame({
    '部门': ['技术', '技术', '运营', '运营', '财务', '财务'],
    '姓名': ['张三', '李四', '王五', '赵六', '钱七', '孙八'],
    '工资': [25000, 21000, 14000, 16000, 18000, 17500],
    '绩效': ['A', 'B', 'A', 'C', 'B', 'A'],
})

# 排序：按工资降序
print(df.sort_values('工资', ascending=False)['姓名'].tolist())
# 输出: ['张三', '李四', '钱七', '孙八', '赵六', '王五']

# 分组聚合：各部门平均工资（select 部门, avg(工资) group by 部门 的 Pandas 版）
print(df.groupby('部门')['工资'].mean().round(1).to_dict())
# 输出: {'技术': 23000.0, '财务': 17750.0, '运营': 15000.0}
```

groupby 的心智模型是 **拆-算-合**：按部门把 6 行拆成 3 堆，每堆独立算 mean，再合成一张以部门为索引的新表。

## 常用 API 详解

### 1. sort_values：多列多方向排序

```python
import pandas as pd

df = pd.DataFrame({
    '部门': ['技术', '技术', '运营', '运营', '财务', '财务'],
    '姓名': ['张三', '李四', '王五', '赵六', '钱七', '孙八'],
    '工资': [25000, 21000, 14000, 16000, 18000, 17500],
})

# 先按部门升序，部门内按工资降序：ascending 列表逐列对应
res = df.sort_values(['部门', '工资'], ascending=[True, False])
print(res[['部门', '姓名', '工资']].to_string(index=False))
# 输出:
# 部门 姓名    工资
# 技术 张三 25000
# 技术 李四 21000
# 财务 钱七 18000
# 财务 孙八 17500
# 运营 赵六 16000
# 运营 王五 14000
```

### 2. 多种聚合一次算：agg 传列表

```python
import pandas as pd

df = pd.DataFrame({
    '部门': ['技术', '技术', '运营', '运营', '财务', '财务'],
    '工资': [25000, 21000, 14000, 16000, 18000, 17500],
})

g = df.groupby('部门')['工资'].agg(['mean', 'max', 'count'])
print(g.to_string())
# 输出:
#         mean    max  count
# 部门
# 技术  23000.0  25000      2
# 财务  17750.0  18000      2
# 运营  15000.0  16000      2
```

### 3. 命名聚合：自定义结果列名

```python
import pandas as pd

df = pd.DataFrame({
    '部门': ['技术', '技术', '运营', '运营', '财务', '财务'],
    '工资': [25000, 21000, 14000, 16000, 18000, 17500],
})

# 列名=（聚合列, 函数）：不同列可以用不同函数，结果列名自己定
named = df.groupby('部门').agg(平均工资=('工资', 'mean'), 最高工资=('工资', 'max'))
print(named.to_string())
# 输出:
#        平均工资   最高工资
# 部门
# 技术  23000.0  25000
# 财务  17750.0  18000
# 运营  15000.0  16000
```

### 4. transform：聚合结果贴回每一行

```python
import pandas as pd

df = pd.DataFrame({
    '部门': ['技术', '技术', '运营', '运营'],
    '姓名': ['张三', '李四', '王五', '赵六'],
    '工资': [25000, 21000, 14000, 16000],
})

# 想知道"每人比部门平均高多少"？transform 保持行数不变
df['部门平均'] = df.groupby('部门')['工资'].transform('mean')
df['差额'] = df['工资'] - df['部门平均']
print(df[['姓名', '工资', '部门平均', '差额']].to_string(index=False))
# 输出:
#  姓名    工资   部门平均     差额
#  张三 25000 23000.0  2000.0
#  李四 21000 23000.0 -2000.0
#  王五 14000 15000.0 -1000.0
#  赵六 16000 15000.0  1000.0
```

agg 是"折叠"（6 行变 3 行），transform 是"广播"（还是 6 行，每行带上所属组的统计量）——这是 groupby 最容易混淆的一对兄弟。

### 5. pivot_table：二维交叉报表

```python
import pandas as pd

df = pd.DataFrame({
    '部门': ['技术', '技术', '运营', '运营', '财务', '财务'],
    '姓名': ['张三', '李四', '王五', '赵六', '钱七', '孙八'],
    '工资': [25000, 21000, 14000, 16000, 18000, 17500],
    '绩效': ['A', 'B', 'A', 'C', 'B', 'A'],
})

# 部门 × 绩效 的平均工资矩阵（Excel 数据透视表的原型）
pv = df.pivot_table(index='部门', columns='绩效', values='工资', aggfunc='mean')
print(pv.to_string())
# 输出:
# 绩效        A        B        C
# 部门
# 技术  25000.0  21000.0      NaN
# 财务  17500.0  18000.0      NaN
# 运营  14000.0      NaN  16000.0
```

### 6. 分组后排序：报表的最后一笔

```python
import pandas as pd

df = pd.DataFrame({
    '门店': ['中关村', '五道口', '西二旗', '望京'],
    '销售额': [128.0, 98.7, 76.2, 115.5],
})

# 聚合结果直接排序，报表不用再导入 Excel 调整
report = df.sort_values('销售额', ascending=False).reset_index(drop=True)
report['排名'] = report.index + 1
print(report.to_string(index=False))
# 输出:
#    门店   销售额  排名
#  中关村  128.0   1
#   望京  115.5   2
#  五道口   98.7   3
#  西二旗   76.2   4
```

## 综合示例

一张员工明细表，做"部门绩效 × 薪资"完整分析报表：

```python
import pandas as pd

df = pd.DataFrame({
    '部门': ['技术', '技术', '技术', '运营', '运营', '财务', '财务', '财务'],
    '姓名': ['张三', '李四', '王五', '赵六', '孙九', '钱七', '周八', '吴十'],
    '工资': [25000, 21000, 32000, 14000, 16000, 18000, 17500, 15000],
    '绩效': ['A', 'B', 'A', 'C', 'B', 'B', 'A', 'C'],
})

# 1. 部门级汇总：人数、总薪资、平均薪资，按平均薪资降序
report = (df.groupby('部门')
            .agg(人数=('姓名', 'count'), 总薪资=('工资', 'sum'), 平均薪资=('工资', 'mean'))
            .sort_values('平均薪资', ascending=False)
            .round(0))
print(report.to_string())
# 输出:
#      人数     总薪资   平均薪资
# 部门
# 技术    3  78000  26000.0
# 财务    3  50500  16833.0
# 运营    2  30000  15000.0

# 2. 每个部门工资最高的人（先组内排序再取第一个）
top = (df.sort_values('工资', ascending=False)
         .groupby('部门').head(1)
         .set_index('部门')['姓名'])
print(top.to_dict())    # 输出: {'技术': '王五', '财务': '钱七', '运营': '孙九'}

# 3. 绩效 A 占比（分组计数 + 占比）
perf = df.groupby('部门')['绩效'].apply(lambda s: (s == 'A').mean()).round(2)
print(perf.to_dict())   # 输出: {'技术': 0.67, '运营': 0.0, '财务': 0.33}

# 4. 部门 × 绩效 看薪资分布
pv = df.pivot_table(index='部门', columns='绩效', values='工资',
                    aggfunc='mean').round(0)
print(pv.to_string())
# 输出:
# 绩效       A      B      C
# 部门
# 技术  28500.0  21000.0      NaN
# 财务  17500.0  18000.0  15000.0
# 运营      NaN  16000.0  14000.0
```

## 小结

- groupby 之后接的函数决定了输出形态：**`agg` 折叠、`transform` 广播、`apply` 任意自定义**（最灵活也最慢，能用前两个就别用 apply）
- `groupby.head(1)` 配合预排序是"每组 Top N"的万能解法，比 `apply(lambda g: g.nlargest(1, ...))` 快得多
- `pivot_table` 默认会丢掉组合为空的格子（NaN），想保留计数就用 `aggfunc='count'` 加 `fill_value=0`
