## 简介

学 Pandas 像学一门语言：DataFrame 是语法，**常用函数是词汇量**。这一篇挑出日常出现频率最高的十来个函数：看数据的 `head/info/describe`、数数的 `value_counts`、变换的 `apply/map`、分箱的 `cut/qcut`、筛选的 `isin/between/query`、找尖子的 `nlargest`。

它们单独都不难，难的是"遇到问题时想得起来用哪个"。每个函数我都配一个"它替代了什么"的说明——知道它省了哪些事，才会真正用它。

## 基本用法：先看数据长什么样

```python
import pandas as pd

df = pd.DataFrame({
    '姓名': ['张三', '李四', '王五', '赵六', '钱七'],
    '部门': ['技术', '技术', '运营', '运营', '财务'],
    '工资': [25000, 21000, 14000, 16000, 18000],
    '绩效': ['A', 'B', 'A', 'C', 'B'],
})

print(df.shape)               # 输出: (5, 4) → 5行4列
print(df['部门'].value_counts().to_dict())
# 输出: {'技术': 2, '运营': 2, '财务': 1} → 各部门人数，一行搞定
print(df['工资'].describe()['max'])   # 输出: 25000.0
```

`value_counts` 是 `df.groupby(...).size()` 的快枪手版本：想数"某列每种值出现几次"，直接用它。

## 常用 API 详解

### 1. unique / nunique：看类别

```python
import pandas as pd

df = pd.DataFrame({'城市': ['北京', '上海', '北京', '深圳', '上海']})

print(df['城市'].unique().tolist())    # 输出: ['北京', '上海', '深圳'] → 有哪些值
print(df['城市'].nunique())            # 输出: 3 → 有几种值（不数 NaN）
```

### 2. apply：一行代码的自定义变换

```python
import pandas as pd

df = pd.DataFrame({'姓名': ['张三', '李四'], '工资': [25000, 14000]})

# Series.apply：对每个值调用函数
df['税后'] = df['工资'].apply(lambda x: x * 0.85 if x > 20000 else x * 0.95)
print(df['税后'].tolist())     # 输出: [21250.0, 13300.0]

# DataFrame.apply(axis=1)：对每行调用函数，拿整行做参数
df['级别'] = df.apply(lambda r: '高薪' if r['工资'] > 20000 else '普通', axis=1)
print(df['级别'].tolist())     # 输出: ['高薪', '普通']
```

`apply` 灵活但慢（本质是 Python 循环）。简单变换优先用向量化写法（如 `df['工资'] * 0.9`），`apply` 留给逻辑复杂的场景。

### 3. map：一一映射

```python
import pandas as pd

df = pd.DataFrame({'绩效': ['A', 'B', 'C', 'B']})

# 字典映射：绩效字母 → 奖金系数
bonus_map = {'A': 2.0, 'B': 1.5, 'C': 1.0}
df['系数'] = df['绩效'].map(bonus_map)
print(df['系数'].tolist())     # 输出: [2.0, 1.5, 1.0, 1.5]
```

### 4. cut / qcut：连续值分箱

```python
import pandas as pd

ages = pd.Series([22, 25, 32, 45, 51, 63])

# cut：按固定边界切，labels 命名
group = pd.cut(ages, bins=[0, 30, 50, 100], labels=['青年', '中年', '老年'])
print(group.tolist())     # 输出: ['青年', '青年', '中年', '中年', '老年', '老年']

# qcut：按分位数切，每组人数尽量相等
rank = pd.qcut(ages, q=3, labels=['低', '中', '高'])
print(rank.value_counts().to_dict())   # 输出: {'低': 2, '中': 2, '高': 2}
```

### 5. isin / between：批量筛选

```python
import pandas as pd

df = pd.DataFrame({'城市': ['北京', '上海', '深圳', '杭州'],
                   '房价': [6.2, 6.8, 5.5, 3.9]})

# isin：命中列表里的任意一个
print(df[df['城市'].isin(['北京', '深圳'])]['城市'].tolist())
# 输出: ['北京', '深圳']

# between：闭区间筛选（杭州 3.9 不在 [4, 6] 内）
print(df[df['房价'].between(4, 6)]['城市'].tolist())
# 输出: ['深圳']
```

### 6. query：SQL 味的筛选写法

```python
import pandas as pd

df = pd.DataFrame({'城市': ['北京', '上海', '深圳'], '房价': [6.2, 6.8, 5.5]})

# 字符串表达式当筛选条件，多条件时可读性高于布尔索引
result = df.query('房价 > 5 and 城市 != "深圳"')
print(result['城市'].tolist())    # 输出: ['北京', '上海']
```

### 7. nlargest / nsmallest：直接取 Top N

```python
import pandas as pd

df = pd.DataFrame({'商品': ['键盘', '鼠标', '支架', '耳机', '底座'],
                   '销量': [120, 350, 88, 260, 45]})

print(df.nlargest(3, '销量')['商品'].tolist())     # 输出: ['鼠标', '耳机', '键盘']
print(df.nsmallest(2, '销量')['商品'].tolist())    # 输出: ['底座', '支架']
```

比 `df.sort_values('销量', ascending=False).head(3)` 少写一半，意图也更清楚。

### 8. rename / astype：收尾微调

```python
import pandas as pd

df = pd.DataFrame({'user_name': ['a', 'b'], 'age': ['25', '30']})

# 列名映射 + 类型转换，规范化的最后一步
df = df.rename(columns={'user_name': '姓名', 'age': '年龄'})
df['年龄'] = df['年龄'].astype(int)
print(df.dtypes['年龄'].name)      # 输出: int64
```

## 综合示例

用这一篇的函数拼一个"员工薪资速览报告"：

```python
import pandas as pd

df = pd.DataFrame({
    '姓名': ['张三', '李四', '王五', '赵六', '钱七', '孙八', '周九', '吴十'],
    '部门': ['技术', '技术', '技术', '运营', '运营', '财务', '财务', '运营'],
    '工资': [25000, 21000, 32000, 14000, 16000, 18000, 17500, 15000],
    '绩效': ['A', 'B', 'A', 'C', 'B', 'B', 'A', 'C'],
})

# 1. 薪资分档（连续值 → 类别）
df['档位'] = pd.cut(df['工资'], bins=[0, 15000, 22000, 999999],
                   labels=['初级', '中级', '高级'])

# 2. 绩效映射奖金系数
df['奖金'] = df['工资'] * df['绩效'].map({'A': 0.4, 'B': 0.25, 'C': 0.1})

# 3. 一行速览：各部门 Top 薪资
print(df.nlargest(3, '工资')[['姓名', '部门', '工资']].to_string(index=False))
# 输出:
#  姓名 部门   工资
#  王五 技术 32000
#  张三 技术 25000
#  李四 技术 21000

# 4. 高绩效（A）且高薪（>20000）的明星员工
stars = df.query("绩效 == 'A' and 工资 > 20000")['姓名'].tolist()
print(f"明星员工: {stars}")            # 输出: 明星员工: ['张三', '王五']

# 5. 档位分布
print(df['档位'].value_counts().to_dict())
# 输出: {'中级': 4, '初级': 2, '高级': 2}
```

## 小结

- 遇到"数一下每个值有多少"先想 `value_counts`，遇到"取前几名"先想 `nlargest`——别急着 groupby + sort + head 三连
- `apply` 是万能后手但性能差，能用向量化运算、`map`、`cut` 解决的就不用它
- `cut` 按边界分箱（档位语义），`qcut` 按分位分箱（等量语义），做用户分层时先想清楚要哪种
