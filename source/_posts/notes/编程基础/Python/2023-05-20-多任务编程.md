## 多任务编程

### 1. 多进程

- 进程是CPU资源分配的最小单位，进程之间的内存是隔离的
- 实现

```python
import time
import multiprocessing  # 导包
def eat(name,food):
    for i in range(10):
        time.sleep(0.5)
        print(f'{name}吃了一口{food}')
def drink(name,drink):
    for i in range(10):
        time.sleep(0.5)
        print(f'{name}喝了一口{drink}')

if __name__ == '__main__':  # 主进程
    # 多进程创建
    # group表示任务分组
    # target表示进程要执行的任务
    # name表示任务的名称
    # p1就是产生的进程对象
    # 创建进程对象
    p1=multiprocessing.Process (target=eat, name='吃饭',args=('李正洋', '奥利给'))
    p2=multiprocessing.Process ( target=drink, name='喝水',kwargs={'name':'张力琛','drink':'可乐'})
    # 开始执行
    p1.start()  # 子进程
    p2.start()  # 子进程
```

- 开始任务会创建一个新的进程，进程结束后自动关闭进程
- 子进程结束，主进程同步结束
- 获取进程编号
  - os.getpid() 当前进程编号
  - os.getppid() 当前进程的父进程编号

```python
import os
import time
import multiprocessing
def eat(name,food):
    # 打印进程id和父进程id
    print(f'eat的进程id是：{os.getpid()}，父进程id是：{os.getppid()}')
    for i in range(10):
        time.sleep(0.5)
        print(f'{name}吃了一口{food}')
def drink(name,drink):
    # 打印进程id和父进程id
    print(f'drink的进程id是：{os.getpid()}，父进程id是：{os.getppid()}')
    for i in range(10):
        time.sleep(0.5)
        print(f'{name}喝了一口{drink}')

if __name__ == '__main__':  # 主进程
    # 打印进程id和父进程id
    print(f'主进程的进程id是：{os.getpid()}，父进程id是：{os.getppid()}')
    # 创建进程对象
    p1=multiprocessing.Process (target=eat, name='吃饭',args=('张力琛', '奥利给'))
    p2=multiprocessing.Process ( target=drink, name='喝水',kwargs={'name':'张力琛','drink':'可乐'})
    # 开始执行
    p1.start()  # 子进程
    p2.start()  # 子进程
```

- 注意点
  - 子进程和主进程不共享全局变量
  - 子进程会复制一份主进程的变量
  - 进程之间可以通过queue创建管道共享数据

```python
import multiprocessing
l=[1,2,3]
def fn():
    # 子进程拷贝主进程的变量l
    print(l)
    l.append(4)
    print(l)
if __name__ == '__main__':
    # 创建子进程
    p=multiprocessing.Process(target=fn)
    # 启动子进程
    p.start()
    # 等p子进程结束之后，再打印主进程的l
    p.join()
    print(l)
```

### 2. 多线程

- 线程是CPU调度的最小单位
- 实现

```python
if __name__ == '__main__':  # 主线程w 
    t1=threading.Thread(target=eat,args=('李正洋', '奥利给'))
    t2=threading.Thread(target=drink,kwargs={'name':'张力琛','drink':'可乐'})
    t1.start()
    t2.start()
```

- 守护进程
  - daemon=True
  - 要守护就都守护，要不都不守护
- 注意点
  - 线程之间可以共享全局变量，但修改全局变量会出现问题
  - 解决线程之间共享数据的问题可以使用互斥锁
    - 创建锁
      - lock=threading.Lock()
    - 把锁传递给线程
      - args=(lock,)
    - 在线程修改数据的地方上锁
      - with lock
    - 上锁会保证数据安全性，但会降低执行效率

```python
# 模拟抢票
import threading
import time
num=3
def fn(lock):
    with lock:
        global num
        if num>0:
            time.sleep(0.5)
            num -= 1
            print(f'{threading.current_thread().name}抢票成功，剩余票数是：{num}')
if __name__ == '__main__':
    # 创建互斥锁
    lock=threading.Lock()
    # 把锁对象作为参数传递给线程
    t1=threading.Thread(target=fn,name='线程1',args=(lock,))
    t2=threading.Thread(target=fn,name='线程2',args=(lock,))
    t3=threading.Thread(target=fn,name='线程3',args=(lock,))
    t4=threading.Thread(target=fn,name='线程4',args=(lock,))
    t5=threading.Thread(target=fn,name='线程5',args=(lock,))
    t1.start()
    t2.start()
    t3.start()
    t4.start()
    t5.start()

    t1.join()
    t2.join()
    t3.join()
    t4.join()
    t5.join()
    print(f'当前剩余票数是：{num}')

```

### 3. GIL

- global interpreter lock 全局解释器锁
- 1个CPU处理1个进程
- 10个CPU处理8个进程（并行8个任务）
- 10个CPU处理4个进程，每个进程4个线程（并行4个任务，并发16个）
- CPU如果处理了某个进程就会在内部形成一个锁，接下来进程的所有线程任务都只能让这个CPU处理（python特有）
