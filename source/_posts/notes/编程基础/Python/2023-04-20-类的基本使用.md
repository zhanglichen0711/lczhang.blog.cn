## 一、类的基本使用

### 1. 定义类

- class 类名:
- class 类名():
- class 类名(object):
- 类名规范：大驼峰写法 FirstName

```python
# 1.定义类：
class Student():
    # 2.创建类属性
    name='李正洋'
    age=25
    height=172
    # 3.创建类方法
    def study(self):
        print(f'{self.name}认真学习')
# 4.创建对象
stu=Student()
# 5.调用类属性及类方法
print(f'学生的姓名是{stu.name},年龄是{stu.age},身高是{stu.height}')
stu.study()
```

### 2. self 的使用

- 谁调用了这个方法，self就是谁
- 内置参数，系统自动传递参数，无需关注来源

```python
# 定义类
class Phone():
    # 定义类属性
    brand='HuaWei'
    price=6999
    publish_year=2023
    # 定义类方法
    def pay(self):
        print(f'{self}微信付款18000元，手机品牌{self.brand}')
# 创建对象
my_phone=Phone()
# 调用类方法
my_phone.pay()     # self是my_phone
your_phone.pay()   # self是your_phone
```

### 3. 对象属性的差异化

- 对象属性的差异化
  - 对象.属性名=属性值，给对象添加不同属性
  - self 指的是不同的对象，可通过不同对象获取不同属性

```python
# 定义类
class Computer():
    def introduce(self):
        print(f'我是{self.brand}的电脑')
lianxiang=Computer()
huashuo=Computer()
lianxiang.brand='联想'
huashuo.brand='华硕'
lianxiang.introduce()
huashuo.introduce()
```

### 4. 魔法方法

- 在特定情况下自动调用的方法
  - __ init __ 创建对象时自动执行
  - __ str __ 打印对象时自动调用
  - str(对象) 类型转换时自动调用
  - __ del __ 删除的时候自动调用

```python
# __init__方法
class Car():
    # 创建对象时自动执行
    def __init__(self,num,brand):
        self.num=num
        self.brand=brand
    def run(self):
        print(f'{self.brand}有{self.num}个轮子，车在跑')
byd=Car(4,'比亚迪')
byd.run()
```

### 5. 案例

```python
# 减肥案例
class Person():
    def __init__(self,weight,name):
        self.weight=weight
        self.name=name
    def run(self):
        self.weight-=0.5
        print(f'{self.name}跑步后，体重减少到{self.weight}kg了')
    def eat(self):
        self.weight+=2
        print(f'{self.name}大吃了一顿，体重增加到{self.weight}kg了')
lzy=Person(75,'李正洋')
lzy.eat()
lzy.run()

# 烤地瓜案例
# 定义烤地瓜类
class Digua():
    # 初始默认属性
    def __init__(self):
        self.time=0
        self.status='生的'
        self.tiaoliao=[]
    # 定义烤地瓜方法，传入烤的时间
    def cook(self,cook_time):
        self.time+=cook_time
        if self.time <3:
            self.status='生的'
        elif self.time<7:
            self.status = '半生不熟'
        elif self.time<12:
            self.status = '熟的'
        else:
            self.status = '烤糊了'
    # 定义添加调料的方法
    def add_tiaoliao(self,tiaoliao):
        self.tiaoliao.append(tiaoliao)
    # 创建魔法方法用于打印对象
    def __str__(self):
        print(f'已经烤了{self.time}分钟，加入的调料有{self.tiaoliao}，当前状态是{self.status}')
        return ''
digua1=Digua()
digua1.cook(5)
digua1.add_tiaoliao('白砂糖')
digua1.cook(3)
digua1.add_tiaoliao('蜂蜜')
print(digua1)
```

## 二、面向对象的三大特性

### 1. 封装

- 把属性和方法写到类里
- 私有化
  - 只能在类内部使用，不能在类外部使用
  - 私有属性
    - __属性
  - 私有方法
    - __方法()
  - 访问私有
    - _类__属性/方法

### 2. 继承

- 子类可以同时继承多个父类
  - 先有的先继承，后来的找不同
- 重写
  - 把父类的属性值改成当前这个值
- 没有的才继承，已有的不继承，如果要继承多个，按顺序继承
- 类.mro() 查看类的继承关系

### 3. 多态

- python是弱类型语言，没有严格意义上的多态
- 不同对象调用相同方法可以实现不同效果

## 三、面向对象

### 1. super关键字

作用：找到当前类型的下一级mro继承关系

类的属性和方法的继承

```python
# 继承类的属性和方法
class A():
    name = '张三'
    def fn():
        print('函数')
class B(A):
    pass
b = B()
print(b.name)
b.fn()
```

类的动态属性和方法的继承

```python
# 继承实例对象的属性
class C():
    def __init__(self):
        self.name = '张三'
class D():
    pass   # 没有重写，直接继承C的init属性
d = D()
print(d.name)
-------------------------------------------
class C():
    def __init__(self):
        self.name = '张三'
class D():
    def __init__(self):
        # 有重写，需要手动调用才能实现继承
        C.__init__(self)
d = D()
print(d.name)
```

### 2. 静态方法和类方法

1.如果不需要创造多个实例对象，可以选择单例模式

2.如果需要创造多个不同的实例对象，选择工厂模式

3.如果类里面没有使用self,改造成staticmethod

4.如果单例模式想要使用类的属性，直接类.属性

```python
class Car():
    # 静态属性
    num = 4
    # 静态方法，不需要self
    @staticmethod
    def run():
        print('跑起来了~')
    # 类方法
    # @classmethod
    # def introduce(cls):
    #     # cls表示类自身
    #     print(f"我有{cls.num}个轮子")
    @staticmethod
    def introduce():
        print(f"我有{Car.num}个轮子")
```

### 3. 垃圾回收机制

如果一个变量无法访达，就会被认定为垃圾，系统会自动回收这个变量

```python
def fn():
    l1 = [i ** 2 for i in range(99999999)]
# fn执行完成后l1变的不可访达，就成了垃圾
fn()
```
