# Linux 文件基本属性

先说结论：`ls -l` 那串 `drwxr-xr-x` 就是 Linux 的权限系统，看懂它，再用 chmod/chown 改，权限问题九成就解决了。

## 看懂 ls -l 的输出

```
-rwxr-xr--  1  ops  dev  1024  Sep  4 10:00  run.sh
│└─┬─┘└─┬─┘└─┬─┘   │    │     │
│ 属主  属组  其他人  链接数 属主  属组
└ 第 1 位是类型：- 文件，d 目录，l 软链接
```

- `r`=4 读，`w`=2 写，`x`=1 执行，每三位一组，对应属主/属组/其他人。
- `rwxr-xr--` = 754：属主可读写执行，属组可读执行，其他人只读。

## chmod：改权限

```bash
chmod 755 run.sh      # 数字法：rwxr-xr-x
chmod 644 file.txt    # 数字法：rw-r--r--（普通文件最常见）
chmod u+x run.sh      # 符号法：给属主加执行权限
chmod g-w file.txt    # 去掉属组的写权限
chmod -R 755 mydir/   # 递归改整个目录
```

常用组合：目录 755，普通文件 644，私钥 600，脚本 755。

## chown / chgrp：改归属

```bash
sudo chown ops file.txt            # 改属主
sudo chown ops:dev file.txt        # 属主和属组一起改
sudo chown -R www:www /var/www/    # 递归改，网站目录常用
chgrp dev file.txt                 # 只改属组
```

## 目录的 x 权限很特殊

- 目录的 `r`：能列出里面有什么文件。
- 目录的 `x`：**能进入并访问里面的文件**。
- 所以目录常见 755 而不是 644——没有 x 的目录进不去。

## umask：新文件的默认权限

```bash
umask              # 常见输出 0022
# 新文件权限 = 666 - umask；新目录 = 777 - umask
# 022 → 文件默认 644，目录默认 755
```

## 数字对照速记

```
7 = rwx    6 = rw-    5 = r-x    4 = r--
755 目录可进可执行 | 644 文件标准权限 | 600 只有自己能看 | 777 能不给就不给
```
