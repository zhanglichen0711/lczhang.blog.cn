# Linux 系统目录结构

先说结论：Linux 一切从根 `/` 开始，没有 C 盘 D 盘。记熟 FHS 标准目录，看到路径就知道东西在哪。

## 一切皆文件

- Windows 有盘符，Linux 只有一棵目录树，根是 `/`。
- 硬盘、U 盘要"挂载"到树上的某个目录才能访问。
- 大小写敏感：`Readme.txt` 和 `readme.txt` 是两个文件。

## 核心目录速查表

| 目录 | 放什么 | 记忆点 |
|------|--------|--------|
| `/bin` | 基础命令（ls、cp） | 所有用户可用 |
| `/sbin` | 管理员命令 | system bin |
| `/boot` | 内核与引导文件 | 删了就开不了机 |
| `/dev` | 设备文件 | 硬盘是 /dev/sda，一切皆文件 |
| `/etc` | **系统和服务配置** | 最常来的目录 |
| `/home` | 普通用户家目录 | /home/用户名 |
| `/root` | root 的家目录 | 不在 /home 里 |
| `/lib` | 系统库文件 | 程序的"零件库" |
| `/media` `/mnt` | 挂载点 | U 盘、临时挂载 |
| `/opt` | 第三方大型软件 | 可选软件包 |
| `/proc` | 内核与进程的虚拟文件 | /proc/cpuinfo、/proc/meminfo |
| `/sys` | 内核设备信息 | 类似 /proc |
| `/tmp` | 临时文件 | 重启可能清空，别放重要东西 |
| `/usr` | 用户级程序与资源 | /usr/local 放自己装的软件 |
| `/var` | 经常变化的数据 | **日志在 /var/log**，网站在 /var/www |
| `/run` | 运行时数据 | 进程 PID 等 |

## 最常用的路径惯性

- 改服务配置 → `/etc/`
- 看日志 → `/var/log/`
- 自己编译装的软件 → `/usr/local/`
- 查硬件信息 → `/proc/`、`lsblk`、`lscpu`

## 记忆方法

不用死背。记住三个高频：**配置在 etc、日志在 var/log、家在 home**，其余的用到时回来查这张表就行。

```bash
tree -L 1 /        # 只看根目录第一层（需安装 tree）
du -sh /var/log    # 感受一下某个目录占多大
```
