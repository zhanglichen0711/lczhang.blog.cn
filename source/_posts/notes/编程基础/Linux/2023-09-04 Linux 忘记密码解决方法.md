# Linux 忘记密码解决方法

先说结论：物理机/虚拟机通过 GRUB 进单用户模式改密码；云服务器直接用控制台重置，最省事。

## 场景一：云服务器（推荐直接用控制台）

阿里云/腾讯云控制台都有"重置实例密码"功能，重置后重启生效。VNC 救急登录也不依赖 SSH。能走控制台就别折腾 GRUB。

## 场景二：RHEL / CentOS / Rocky（rd.break 法）

1. 重启，在 GRUB 菜单选中第一项，按 **e** 进入编辑。
2. 找到以 `linux` 开头的那行，在行末追加：`rd.break`
3. 按 `Ctrl+X` 启动，进入救援 shell，然后：

```bash
mount -o remount,rw /sysroot   # 根分区默认只读，先改成可写
chroot /sysroot                # 切进真正的系统
passwd root                    # 改密码
touch /.autorelabel            # 关键！让 SELinux 重新打标签，漏了会登录不上
exit
exit                           # 系统自动继续启动
```

## 场景三：Debian / Ubuntu（init=/bin/bash 法）

同样按 **e** 编辑 GRUB，在 `linux` 行末把 `ro quiet splash` 改成：`rw init=/bin/bash`，按 `Ctrl+X` 启动：

```bash
mount -o remount,rw /          # 确认可写（如已是 rw 可跳过）
passwd root
sync                           # 把数据刷回磁盘
exec /sbin/init                # 或直接强制重启
```

## 改别人/自己的普通用户密码

有 sudo 权限就很简单，不需要任何救援模式：

```bash
sudo passwd 用户名     # 改指定用户密码
passwd                 # 改自己密码（先输旧密码）
```

## 几个提醒

- GRUB 编辑界面是**本机物理操作**才能做的，所以这本质上说明：物理接触机器的人总能改密码，服务器要放在安全的物理环境里。
- `touch /.autorelabel` 在 SELinux 系统上不能省；Ubuntu 没有 SELinux，不涉及。
- 改完密码顺手记进密码管理器，别下次再折腾一遍。
