# Linux vi/vim

先说结论：vim 只需要记住"三种模式 + 十几个按键"，就能应付服务器上改配置的所有场景。

## 三种模式

```
普通模式（启动默认） --i/a/o--> 插入模式（打字）
     ↑                      |
     Esc                    |
普通模式 --:--> 命令行模式（保存/退出/查找替换）
```

核心逻辑：**插入模式只管打字，其他一切操作先按 Esc 回普通模式再做。**

## 最小生存命令

打开文件后：

```
i          在光标前进入插入模式（o 另起一行插入，够用了）
Esc        回到普通模式
:wq        保存退出
:q!        不保存强退（改砸了用）
```

会这五个键就不会被 vim 关住了。

## 普通模式常用按键

**移动：**

```
h j k l     左 下 上 右（方向键也行）
gg          跳到文件开头        G     跳到文件末尾
0           行首                $     行尾
:w 行号 或 行号gg     跳到指定行
```

**编辑：**

```
x           删一个字符
dd          删（剪切）整行      3dd   删 3 行
yy          复制整行            3yy   复制 3 行
p           粘贴到光标后        P     粘贴到光标前
u           撤销                Ctrl+r 重做
```

**查找替换：**

```
/关键词      向下查找     n 下一个    N 上一个
:1,$s/旧/新/g      全文替换
:%s/旧/新/g        同上（% 等价于 1,$）
:set nu            显示行号（去掉是 :set nonu）
```

## 新手最常犯的错

1. 一进去就打字，结果满屏乱跳——先按 `i`。
2. 想退出退不出——`Esc` 然后 `:q!`。
3. 大小写敏感搞混——`dd` 和 `DD` 不是一回事，命令都是小写。

## 一份够用的 ~/.vimrc

```vim
set number          " 行号
syntax on           " 语法高亮
set tabstop=4       " Tab 宽度
set expandtab       " Tab 转空格
set hlsearch        " 查找高亮
```

## 补充

- 很多系统默认只有 vi（功能阉割版），`sudo apt install vim` 装完整的。
- 万一在服务器上被 vim 之外的东西困住：`nano` 更简单，`Ctrl+O` 保存、`Ctrl+X` 退出。
