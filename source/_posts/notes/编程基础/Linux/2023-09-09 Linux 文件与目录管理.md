# Linux 文件与目录管理

先说结论：日常操作就靠 `ls cd pwd mkdir cp mv rm` 这一套，加上通配符和 find，文件操作基本无敌。

## 路径先搞清楚

- 绝对路径从 `/` 写起：`/etc/hosts`；相对路径从当前位置写起。
- `.` 当前目录，`..` 上一级，`~` 家目录，`-` 上一次所在目录。
- `cd -` 在两个目录之间来回切换，很顺手。

## 核心命令

```bash
pwd                     # 我在哪
ls -lh                  # 长格式 + 人类可读大小；-a 看隐藏文件
cd /etc                 # 去哪
mkdir -p a/b/c          # 一次建多层目录
touch file.txt          # 建空文件 / 更新时间戳
cp -r src/ dst/         # 复制（目录要 -r）
cp -i a.txt /tmp/       # 覆盖前询问，保险
mv old new              # 改名 / 移动，同一个用法
rm -rf dir/             # 递归强删——输入前停一秒确认路径！
rmdir empty_dir         # 只能删空目录，比 rm 温和
file a.bin              # 看文件真实类型
tree -L 2               # 目录树，两层
```

## rm 的安全习惯

1. 先 `ls` 确认要删的东西，再换成 `rm`。
2. 通配符打完后**看一眼再回车**，`rm -rf / tmp/*` 少个空格就是事故。
3. 删重要东西用 `mv` 挪到 /tmp 隔离几天，比直接删稳。

## 通配符

```bash
ls *.log          # 所有 .log 文件
ls file?.txt      # ? 匹配单个字符
ls file[123].txt  # 匹配 1/2/3 中一个
cp report*.md bak/
```

## find：按条件找文件

```bash
find /var/log -name "*.log"          # 按名字
find . -size +100M                   # 找大于 100M 的
find . -mtime -7 -type f             # 7 天内改过的文件
find . -name "*.tmp" -delete         # 找到即删（先不加 -delete 预览）
```

## 软链接与硬链接

```bash
ln -s /opt/app/bin/run /usr/local/bin/run   # 软链接：路径的快捷方式
ln file.txt file.bak                        # 硬链接：同一份数据的另一个名字
```

- 软链接可以跨分区、可以链目录，原文件删了就失效（红色闪烁提示）。
- 硬链接不能跨分区、不能链目录，删掉其中一个不影响另一个。
- 常用的就是软链接。

## 命令本身在哪

```bash
which python3       # 命令的可执行文件路径
whereis ls          # 二进制 + 帮助文档 + 源码位置
```
