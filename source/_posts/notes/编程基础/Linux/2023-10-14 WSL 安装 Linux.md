# WSL 安装 Linux

先说结论：Windows 用户想学 Linux 命令，WSL 是起点——不用虚拟机、不用双系统，文件还能互访。

## 一条命令安装

以**管理员身份**打开 PowerShell：

```powershell
wsl --install
```

默认装 Ubuntu，装完重启电脑，首次进入会让你设置 UNIX 用户名和密码（这个密码 sudo 时要用）。

## 常用命令速查

```powershell
wsl --list --online          # 看可安装的发行版
wsl --install -d Debian      # 安装指定发行版
wsl -l -v                    # 看已装的列表和版本
wsl --set-default Ubuntu     # 设默认发行版
wsl --shutdown               # 全部关机（排查问题常用）
wsl --unregister Ubuntu      # 彻底删除某个发行版（数据会清空）
```

## WSL1 和 WSL2

- 现在默认都是 **WSL2**：真内核、完整系统调用、能用 Docker。
- 检查/转换：`wsl -l -v` 看 VERSION 列；`wsl --set-version Ubuntu 2` 转换。
- 没有特殊理由，一律用 WSL2。

## 文件互访（最实用的部分）

- WSL 里访问 Windows：`/mnt/c/` 就是你的 C 盘。
- Windows 里访问 WSL：资源管理器地址栏输入 `\\wsl$\Ubuntu`，或在侧边栏找 Linux 企鹅图标。
- **项目代码放 WSL 自己的文件系统里**（如 `~/code`），别放 `/mnt/c`，否则 git 和编译会慢好几倍。

## 常见坑

- **报错"虚拟化未开启"**：进 BIOS 打开 VT-x/AMD-V。
- **报错 0x80370102**：BIOS 开虚拟化 + 启用"虚拟机平台"功能。
- **想装到 D 盘**：新版支持 `wsl --install Ubuntu --location D:\wsl\Ubuntu`；旧版用 `wsl --export` 导出再 `--import` 导入。
- **里面没网/慢**：`wsl --shutdown` 后重进，多数能解决。
