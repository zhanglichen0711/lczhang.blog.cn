# Linux yum 命令

先说结论：yum 是 RHEL/CentOS 系的包管理器，自动解决依赖；装、更、卸、查四类命令记住就够用。新版系统（CentOS 8+/Rocky/Fedora）里 yum 已由 dnf 接管，命令用法完全兼容。

## 适用系统

- RHEL / CentOS / Rocky / AlmaLinux / Fedora → `yum`（新系统实际是 `dnf` 的别名）。
- Debian / Ubuntu 用的是 apt，命令不通用。

## 常用命令

```bash
yum install nginx -y          # 安装（-y 自动确认）
yum update                    # 更新所有包（谨慎，生产先看列表）
yum update nginx              # 只更新指定包
yum remove nginx              # 卸载
yum search 关键词              # 按名字/描述搜索
yum info nginx                # 看包详情（版本、大小、简介）
yum list installed            # 已安装的包（配合 grep 用）
yum provides "*/ifconfig"     # 反查：这个文件属于哪个包，找不到命令时神器
yum history                   # 查看安装/卸载历史，可回滚
```

## 高频组合

```bash
# 装东西前先找：命令不存在时，先看哪个包提供它
yum provides "*/netstat"      # → 告诉你装 net-tools

# 已装了什么、要不要升级
yum list installed | grep nginx
yum check-update
```

## 换国内源（阿里云镜像示例）

```bash
# 备份原源
sudo mv /etc/yum.repos.d/CentOS-Base.repo /etc/yum.repos.d/CentOS-Base.repo.bak
# 下载对应版本的阿里云源（CentOS 7 为例）
sudo curl -o /etc/yum.repos.d/CentOS-Base.repo https://mirrors.aliyun.com/repo/Centos-7.repo
sudo yum clean all && sudo yum makecache    # 清缓存重建
```

注意 CentOS 7 已停止维护，官方源下线，新装机器建议直接用 Rocky/Alma 9 或 Ubuntu。

## EPEL：必备扩展源

很多常用包（如 nginx 老版本、htop）在基础源里没有，装 EPEL：

```bash
sudo yum install epel-release
```

## 和 apt 的对应关系（速记）

| 操作 | yum | apt |
|------|-----|-----|
| 安装 | yum install | apt install |
| 更新 | yum update | apt update + upgrade |
| 卸载 | yum remove | apt remove |
| 搜索 | yum search | apt search |
| 详情 | yum info | apt show |
