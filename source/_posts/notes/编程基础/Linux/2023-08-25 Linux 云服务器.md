# Linux 云服务器

先说结论：云服务器是练 Linux 性价比最高的方式——真实环境、随时重装、不怕弄坏。

## 选购要点

- **厂商**：阿里云、腾讯云、华为云都有新用户优惠机，几十元/年。
- **地域**：选离自己近的节点，延迟低。
- **镜像**：直接选官方 Ubuntu LTS 或 Rocky Linux，别选带面板的"应用镜像"，先把裸系统玩明白。
- **配置**：1 核 2G 足够学习；练手期不用升配。
- **计费**：学习选按量付费或活动年付，不用时记得释放/退订。

## 第一次连接

云服务器默认给你公网 IP 和密码（或让你设密钥），本地直接 SSH 连接：

```bash
ssh root@你的公网IP
# 指定端口
ssh -p 22 root@你的公网IP
```

Windows 10/11 自带 OpenSSH 客户端，PowerShell 里直接能用。

## 安全组 = 云上的防火墙

- 安全组在厂商控制台配置，决定哪些端口能被公网访问。
- 原则：**只放行需要的端口**。学习期放 22（SSH）和 80/443（网页）就够。
- 连不上服务器，先查安全组，再查服务器内部防火墙，顺序别反。

## 拿到服务器后的基础加固

```bash
apt update && apt upgrade -y          # 更新系统
adduser ops                            # 建一个日常用户，别一直用 root
ssh-keygen -t ed25519                  # 本地生成密钥
ssh-copy-id ops@你的公网IP             # 推送公钥，改用密钥登录
```

进阶（熟悉后再做）：改 SSH 端口、禁用 root 密码登录（`PasswordAuthentication no`）、装 fail2ban 防爆破。

## 三个必须养成的习惯

1. **改坏了别慌**：控制台有 VNC/OrcaTerm 救急登录，不走 SSH 也能进。
2. **动手前打快照**：厂商免费或低价提供，一键回滚，比任何备份教程都靠谱。
3. **不用就关机或释放**：按量计费的机器挂着也是烧钱。
