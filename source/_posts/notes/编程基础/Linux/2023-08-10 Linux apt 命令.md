# Linux apt 命令

先说结论：apt 是 Debian/Ubuntu 的包管理器。最容易混的是 update 和 upgrade——update 只刷软件列表，upgrade 才真正升级。

## 适用系统

- Debian / Ubuntu / Kali 及其衍生版。
- RHEL/CentOS 系用 yum/dnf，别混。

## update 和 upgrade 的区别（必懂）

```bash
sudo apt update     # 只更新"可用软件列表"，不装不升，安全，装啥之前先跑它
sudo apt upgrade    # 按照刚才刷新的列表，真正升级已安装的包
```

记忆：update 是"看菜单"，upgrade 是"点菜上菜"。

## 常用命令

```bash
sudo apt update                    # 刷新软件列表
sudo apt upgrade -y                # 升级所有可升级的包
sudo apt install nginx -y          # 安装
sudo apt install nginx=1.24.*      # 安装指定版本
sudo apt remove nginx              # 卸载（保留配置文件）
sudo apt purge nginx               # 卸载并删配置
sudo apt autoremove                # 清掉不再需要的依赖
apt search nginx                   # 搜索
apt show nginx                     # 包详情
apt list --installed | grep nginx  # 查已安装
apt list --upgradable              # 看哪些能升级
```

`remove` 和 `purge` 的区别：purge 连 `/etc` 里的配置一起删，重装想要干净环境时用 purge。

## 换国内源（Ubuntu 22.04 示例）

```bash
sudo cp /etc/apt/sources.list /etc/apt/sources.list.bak   # 先备份
sudo sed -i 's|archive.ubuntu.com|mirrors.aliyun.com|g; s|security.ubuntu.com|mirrors.aliyun.com|g' /etc/apt/sources.list
sudo apt update    # 换源后必须刷新
```

- Ubuntu 24.04 起源配置迁移到 `/etc/apt/sources.list.d/ubuntu.sources`，改那个文件。
- 也可以直接 `sudo apt edit-sources` 编辑。

## 常见问题

- **报错 "Unable to locate package"**：先 `apt update`，还没有就检查源配置或包名拼写。
- **报错 "could not get lock"**：另一个 apt 在跑（或上次没退干净），等它结束，别强杀。
- **`apt` 与 `apt-get`**：apt 是给人类用的新命令（进度条、输出友好），脚本里仍建议用 apt-get（接口稳定）。日常一律 apt。
