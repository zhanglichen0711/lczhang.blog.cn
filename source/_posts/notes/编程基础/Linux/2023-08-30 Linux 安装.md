# Linux 安装

先说结论：学习用装虚拟机或 WSL，工作用直接买云服务器，物理机双系统最不推荐入门选。

## 先选发行版

- **Ubuntu**：资料最多，社区活跃，新手首选。推荐 LTS 版本（如 24.04），支持 5 年。
- **Debian**：稳定、干净，服务器常用，包管理与 Ubuntu 同系。
- **CentOS Stream / Rocky / AlmaLinux**：企业服务器生态，命令风格偏 RHEL 系（yum/dnf）。
- 新手别纠结，选 Ubuntu LTS 就行，学会了换发行版很快。

## 四种安装方式对比

| 方式 | 适合场景 | 成本 |
|------|---------|------|
| WSL（Windows 子系统） | 学习命令、开发环境 | 最低，一条命令 |
| 虚拟机（VMware/VirtualBox） | 完整体验、练习分区/服务 | 中，需下载镜像 |
| 云服务器 | 部署项目、长期练手 | 每月几十元起 |
| 物理机安装 | 折腾硬件、专用机器 | 有装坏风险 |

## 虚拟机安装要点（以 Ubuntu 为例）

1. 去官网下载 ISO 镜像，别用第三方来源。
2. 虚拟机配置建议：2 核 CPU、4G 内存、40G 磁盘，够用。
3. 安装时选"最小安装"，省时间也省空间。
4. 磁盘分区新手直接选"使用整个磁盘"，让安装器自动分。
5. 记住设置的密码；安装完成后第一件事是更新系统。

## 装完先做三件事

```bash
sudo apt update && sudo apt upgrade -y   # 更新系统（Debian/Ubuntu）
cat /etc/os-release                       # 确认版本
ip addr                                   # 查看本机 IP
```

## 常见问题

- **虚拟机很卡**：检查是否开启了 CPU 虚拟化（BIOS 里的 VT-x/AMD-V）。
- **装完没网**：虚拟机网络改回 NAT 模式，最省事。
- **想重装**：虚拟机直接删掉重建，这就是推荐它入门的原因——怎么折腾都不心疼。
