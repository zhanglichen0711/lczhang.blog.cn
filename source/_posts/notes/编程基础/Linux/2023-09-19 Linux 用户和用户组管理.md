# Linux 用户和用户组管理

先说结论：Linux 是多用户系统，核心就三个配置文件（passwd/shadow/group）加一组 user/group 命令；日常操作用 sudo，别用 root 干活。

## 三个核心文件

| 文件 | 内容 | 权限 |
|------|------|------|
| `/etc/passwd` | 用户基本信息（用户名、UID、家目录、shell） | 所有人可读 |
| `/etc/shadow` | 密码哈希与有效期 | 仅 root 可读 |
| `/etc/group` | 用户组信息 | 所有人可读 |

passwd 里每行七段：`用户名:密码占位:UID:GID:备注:家目录:shell`，shell 是 `/sbin/nologin` 表示不能登录。

## 用户管理命令

```bash
sudo useradd -m -s /bin/bash ops   # 建用户并创建家目录（Ubuntu 用 adduser 更省心）
sudo passwd ops                    # 给用户设密码
id ops                             # 查看用户的 UID / 所属组
whoami                             # 我是谁
who / w                            # 谁在线
sudo usermod -aG docker ops        # 把用户加进 docker 组（-a 追加，-G 组列表）
sudo usermod -L ops                # 锁定账号
sudo userdel -r ops                # 删用户并删除家目录
```

`usermod -aG` 里的 **-a 别漏**，漏了会把用户从其他组里踢出去。

## 组管理

```bash
sudo groupadd dev          # 建组
sudo groupdel dev          # 删组
groups ops                 # 看用户在哪些组
getent group docker        # 看组里有哪些成员
```

## su 与 sudo

- `su - 用户名`：切换用户，`-` 连环境一起切，切 root 要输 root 密码。
- `sudo 命令`：以 root 权限执行单条命令，输自己的密码。
- **习惯用 sudo 而不是 su**：操作有日志、权限粒度可控、不易误伤系统。

## sudo 授权

编辑 sudo 权限**永远用** `sudo visudo`（保存前会做语法检查，直接改文件写错会把自己锁在外面）：

```
ops     ALL=(ALL:ALL) ALL        # 完全 sudo 权限（Ubuntu 建用户时勾 sudo 即有）
%dev    ALL=(ALL) NOPASSWD: /usr/bin/systemctl   # dev 组免密执行 systemctl
```

## 常见问题

- **新用户加组后不生效**：退出重新登录，或 `newgrp 组名`。
- **useradd 后登录异常**：多半是没加 `-m`（没有家目录）或 shell 是 nologin。
- **UID 惯例**：0 是 root，1-999 系统账号，1000 起是普通用户。
