# Linux 磁盘管理

先说结论：流程就四步——分区 → 格式化 → 挂载 → 写进 fstab。日常用得最多的是 df/du 查空间。

## 先看状态（用得最多）

```bash
df -h            # 各文件系统的容量、已用、挂载点（-h 人类可读）
du -sh /var      # 某个目录总共占多大；-s 汇总
du -h --max-depth=1 / 2>/dev/null | sort -rh | head   # 根目录下谁最占空间
lsblk            # 块设备树：盘、分区、挂载点一目了然
free -h          # 内存和 swap（顺便记）
```

磁盘满了先跑 `du` 那条，十有八九是大日志。

## 分区

```bash
sudo fdisk -l                     # 列出所有磁盘和分区
sudo fdisk /dev/sdb               # 交互式分区（MBR）：n 新建 → w 写入
sudo parted /dev/sdc              # GPT 分区，大于 2T 的盘用它
```

fdisk 里按 `m` 看帮助，常用：`n` 新建、`d` 删除、`p` 打印、`w` 保存退出。

## 格式化（建文件系统）

```bash
sudo mkfs.ext4 /dev/sdb1          # ext4，通用稳妥
sudo mkfs.xfs /dev/sdb1           # xfs，RHEL 默认，大文件友好
```

## 挂载

```bash
sudo mkdir /data
sudo mount /dev/sdb1 /data        # 临时挂载，重启失效
umount /data                      # 卸载（提示 busy 就先退出该目录）
df -h | grep data                 # 确认挂上了
```

## 写进 /etc/fstab：开机自动挂载

```
# 设备            挂载点   类型   选项     dump pass
/dev/sdb1        /data    ext4   defaults 0    2
```

```bash
sudo mount -a     # 检验 fstab：没报错且挂上了才安全
```

**改 fstab 前先备份，改完必跑 `mount -a` 验证**——写错一行开机就会进救援模式。更稳的写法用 UUID：`blkid` 查出 UUID 替换设备名，防止盘符顺序变化。

## 概念备忘

- **swap**：内存不够时顶上的交换分区/文件；`swapon --show` 查看。
- **LVM**：把多块盘聚成可动态扩容的存储池（PV→VG→LV），生产常用，学习阶段知道概念即可。
- **扩容思路**：云盘在控制台扩容后，还要在系统里 `growpart` + `resize2fs`（或 xfs_growfs）才真正生效。
