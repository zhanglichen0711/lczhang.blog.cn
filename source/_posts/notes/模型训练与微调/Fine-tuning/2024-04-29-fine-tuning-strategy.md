"用别人训好的模型"这件事有个学名：**迁移学习（Transfer Learning）**——把在一个任务上学会的知识，迁移到另一个相关任务。微调只是迁移学习的一种。这一篇先建立迁移学习的大框架，再落到实操决策：**什么时候该微调、微调哪些层、全参还是冻结**。

## 迁移学习的谱系

| 方式 | 做法 | 数据需求 | 改动 |
| --- | --- | --- | --- |
| 特征提取 | 冻结预训练模型，只训新加的分类头 | 几百条 | 最小 |
| 部分微调 | 冻结底层，只训高层 + 分类头 | 几千条 | 中 |
| 全参微调 | 所有参数一起训 | 几万条 | 最大 |

**直觉**：预训练模型的底层学到的是"通用特征"（边缘、语法、通用语义），高层学到的是"任务相关"（领域表达）。任务数据越少，越应该**冻结底层**——数据不够时动底层会毁掉通用能力（灾难性遗忘）。

## 数据量决定策略

| 你的数据量 | 推荐策略 |
| --- | --- |
| < 1000 条 | 特征提取（只训分类头）或干脆提示词 |
| 千~万级 | 部分冻结：冻结底层，微调高层 |
| 万级以上 | 可以考虑全参微调（或 LoRA） |

**血泪经验**：数据少却全参微调，模型会"记住你那几千条、忘了全世界"——训练集上 100 分，一换场景就崩。数据越少，越要克制地动参数。

## 用代码表达三种策略

以 Hugging Face 生态微调一个分类/生成模型为例：

```python
from transformers import AutoModelForSequenceClassification, Trainer

model = AutoModelForSequenceClassification.from_pretrained("bert-base-chinese")

# 策略一：特征提取 —— 冻结所有预训练层，只训分类头
for param in model.bert.parameters():
    param.requires_grad = False        # 底座参数不动
# model.classifier 默认 requires_grad=True，只训它

# 策略二：部分冻结 —— 冻结前 6 层，后 6 层 + 分类头可训
for i, layer in enumerate(model.bert.encoder.layer):
    if i < 6:
        for p in layer.parameters():
            p.requires_grad = False
```

```python
# 策略三：全参微调 —— 什么都不冻结
for param in model.parameters():
    param.requires_grad = True
```

`requires_grad` 就是"这个参数要不要学"的开关——**微调策略本质是在选"哪些参数值得用你的小数据去动"**。

## 微调的超参数纪律

微调和从头训练的超参数完全不同，记住这张表：

| 超参 | 从头训练 | 微调 |
| --- | --- | --- |
| 学习率 | 1e-3 量级 | **1e-5 ~ 5e-5**（小！） |
| epoch | 几十~上百 | **2 ~ 5**（少！） |
| 优化器 | Adam/SGD | AdamW + weight_decay |
| 批大小 | 随意 | 能塞下就大点（BN 类注意） |

**学习率小、epoch 少**是微调的两条铁律——预训练权重已经很好了，你要做的是"轻轻拨动"，不是"重新训练"。学习率 1e-3 微调 BERT 的后果：几轮就把预训练知识冲光。

## 灾难性遗忘：微调最大的坑

微调学会领域任务的同时，可能**忘掉通用能力**——这叫灾难性遗忘。三个防护：

1. **冻结底层**（数据少时尤其重要）；
2. **混入通用数据**：训练集里掺一部分通用/原任务数据，让模型"不忘本"；
3. **留评估集对比**：微调前后都跑一遍通用 benchmark，指标掉了就是遗忘。

## 小结

迁移学习 = **用预训练权重起步，按数据量决定动多少参数**：几百条只训头（特征提取）、几千条冻结底层微调高层、几万条才考虑全参。微调的超参数纪律是"**学习率小、epoch 少**"，最大风险是灾难性遗忘（冻结 + 混数据 + 对比评估三防）。理解了"该动哪些参数"，下一篇的最优解——LoRA——就顺理成章了：与其纠结冻结哪些层，不如让模型只学一小块"增量"。
