真实业务里很少有"平坦的 5 分类"——更多是层级结构：质量缺陷先分一级（7 类：渗漏、开裂、蜂窝……），再分二级（27 类）。层级分类比平坦分类难在**类别多、样本分散、层级关系要利用**。这一篇用"建筑质量缺陷定级"这个场景，讲清层级分类的两种主流架构和落地要点——它对应你简历里"一级 7 类、二级 27 类、准确率 96%"那段实践。

## 业务问题

现场质量员提交一段描述，系统要给出**二级分类**（精度到"露筋""蜂窝""麻面"这级），因为整改方案按二级类别匹配规范。难点：样本集中在常见类，长尾类别（如"预埋件偏移"）样本很少；描述口语化严重（"板子上有好多小坑"→ 麻面）。

## 架构选择：平铺 vs 层级

### 方案 A：直接训练 27 类（平铺）

最简单：把 27 个二级类当独立类别训一个模型。问题：**样本被摊薄**（每类更少）、类别相似度高（"蜂窝"vs"麻面"）难分。

### 方案 B：两级级联（先一级后二级）

先训一个 7 类一级分类器，再**按一级类别各训一个二级分类器**（或一个大二级模型带"一级"约束）。好处：**利用层级结构、每个分类器更专注**；坏处：错误会传播（一级分错，二级必错）。

### 方案 C：单模型 + 层级感知（实战常用折中）

一个模型直接预测二级标签，但**把一级信息作为约束**：训练时用"一级正确则奖励"的层级损失，或推理时先用一级结果过滤候选二级。实现简单、又能利用层级。

```python
# 实操最常见：一个模型出 27 类，但评估与后处理结合一级结构
# 预测二级标签 → 映射到一级 → 与一级模型结果校验，冲突时取高置信度
```

**工程建议**：先跑"平铺 27 类"当基线，再看要不要上层级结构——多数时候平铺 + 足够数据就能到可用线，层级结构主要救"长尾类别"。

## 数据与标注的实战细节

### 样本不平衡：最常见的坑

27 类里前 5 类可能占 80% 样本。处理组合拳：

```python
from sklearn.utils.class_weight import compute_class_weight

# 1. 类别权重：loss 里给少样本类别加权
weights = compute_class_weight("balanced", classes=np.unique(y), y=y)
loss_fn = nn.CrossEntropyLoss(weight=torch.tensor(weights, dtype=torch.float32))

# 2. 长尾类别做同义扩充（把"麻面"改写多种说法）
# 3. 欠采样/过采样，视数据量而定
```

### 脏标签：分类效果的最大杀手

现场描述标注主观性强，标签噪声常见。**先做标注一致性检查**：抽样 100 条让两人标，算一致率——低于 85% 说明标签本身有问题，模型再调也白搭。

## 低置信度兜底：LLM 二审

分类模型对熟悉的表述很自信，但长尾或模糊输入会硬着头皮错分。生产上给分类加一道"置信度闸门"——**低置信度样本转人工或 LLM 兜底**：

```python
def classify_with_fallback(text: str, model, threshold: float = 0.85):
    prob = predict_proba(model, text)          # 拿到各类概率
    top_label, top_score = top_class(prob)

    if top_score >= threshold:
        return top_label, "auto"
    # 低置信度：交给 LLM（带规范提示）或人工
    return llm_second_review(text), "llm"
```

这个"高置信自动 + 低置信兜底"的架构，是**分类系统真正落地**的关键——它承认模型有盲区，并用更贵的资源（人/LLM）去补盲区，而不是让模型硬撑。

## 评估：别只看整体准确率

层级分类必须**逐层级、逐类别看**：

```python
from sklearn.metrics import classification_report

# 一级 7 类、二级 27 类分别出 report
print(classification_report(y1_true, y1_pred))    # 一级
print(classification_report(y2_true, y2_pred))    # 二级
```

重点盯两个数：**长尾类别的 F1**（前 5 类都 0.95 不算本事）、**一级分对但二级分错的比例**（说明层级约束没用上，值得上方案 B/C）。

## 小结

层级文本分类的落地心法：**先平铺建基线，用类别权重与数据增强打不平衡，靠置信度闸门 + LLM/人工兜底堵盲区，按层级逐类评估**。它不只是一个模型问题，而是一套"模型 + 数据 + 兜底 + 评估"的工程系统——这也是它在你简历里能写"96% 准确率 + 低置信 LLM 兜底"的原因：系统设计贡献了大半。

分类这条路走通了。但今天 NLP 的终点早不只是"贴标签"——大模型时代，文本从"被分类"走向"被生成"。最后一篇：从分类到生成，NLP 的下半场。
