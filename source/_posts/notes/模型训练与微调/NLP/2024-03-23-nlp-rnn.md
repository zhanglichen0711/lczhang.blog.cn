Transformer 篇章从 RNN 的缺陷讲起，但 RNN 家族本身值得完整认识——它曾是序列建模的统治结构，而且 LSTM 的"门控"思想至今有借鉴价值。这一篇讲清 RNN 的结构、它"记不住"的病根、LSTM/GRU 怎么开药，以及放在今天的坐标系里它还剩什么用。

## RNN：按顺序读，边读边记

RNN 处理序列的方式是"一步一步走"：读第 t 个词时，把**上一步的隐藏状态** $h_{t-1}$ 和当前词一起算，得到新的隐藏状态 $h_t$——隐藏状态就是它对"已经读过的内容"的记忆。

```python
import torch.nn as nn

# PyTorch 内置 RNN，一行搭好
rnn = nn.RNN(input_size=100, hidden_size=128, batch_first=True)
```

隐藏状态的更新（简化）：

```text
h_t = tanh(W_h · h_{t-1} + W_x · x_t + b)
```

**读完全句后**，最后一步的 $h_T$（或全部 $h$ 的池化）就是句子的向量表示，可以接分类头做情感分析、文本分类。

## 病根：梯度消失，长距离记不住

RNN 的 $h$ 是逐词传递的。训练时梯度要从句尾一路穿回句首，**每穿一步就要乘一次 $W_h$ 相关的因子**——如果小于 1，几十步之后梯度趋近于零（梯度消失），句首的信息根本收不到更新信号。结果：**第 1 个词和第 50 个词的关系，模型学不会**。

> 句子："我五年前在北京工作，现在准备回___去。" 要填"北京"，得记住开头。RNN 大概率做不到。

## LSTM：用"门"决定记什么、忘什么

LSTM（长短期记忆）的破局思路：给记忆单元加**三个门**，让模型自己学会"什么时候该记、什么时候该忘、什么时候该输出"：

| 门 | 作用 | 直觉 |
| --- | --- | --- |
| 遗忘门 | 决定丢掉多少旧记忆 | "上一步的信息过时了，忘掉" |
| 输入门 | 决定写入多少新信息 | "当前词值得记住" |
| 输出门 | 决定放出多少记忆 | "把记忆里的多少拿出来用" |

门的作用是**让信息可以选择性长距离穿行**——该记的（"北京"）通过门的"放行"一路带到句尾，不该记的（"了""的"）被遗忘门过滤。LSTM 因此能记住几百步之前的信息，成为 RNN 时代处理长文本的主力。

```python
lstm = nn.LSTM(input_size=100, hidden_size=128, num_layers=2, batch_first=True)

# 前向：seq 是 (batch, seq_len, input_size)，out 是每步输出
out, (h_n, c_n) = lstm(seq)
```

`h_n` 是最后一步的隐藏状态、`c_n` 是最后的记忆单元——常用 `h_n` 当句子表示接分类头。

## GRU：LSTM 的轻量版

GRU 把三个门精简成两个（重置门 + 更新门），参数更少、训练更快，效果和 LSTM 基本相当。工程上**没特殊理由时 GRU 和 LSTM 二选一都行，常优先 GRU**（更快更省）。PyTorch 一行切换：

```python
gru = nn.GRU(input_size=100, hidden_size=128, batch_first=True)
```

## 用 LSTM 做一个文本分类

```python
import torch
import torch.nn as nn

class LSTMClassifier(nn.Module):
    def __init__(self, vocab_size, embed_dim=100, hidden=128, num_classes=2):
        super().__init__()
        self.embed = nn.Embedding(vocab_size, embed_dim)
        self.lstm = nn.LSTM(embed_dim, hidden, batch_first=True)
        self.head = nn.Linear(hidden, num_classes)

    def forward(self, x):               # x: (batch, seq_len)
        emb = self.embed(x)             # (batch, seq_len, embed)
        out, (h, c) = self.lstm(emb)    # h: (1, batch, hidden)
        return self.head(h.squeeze(0))  # 用最后一步隐藏状态分类
```

分类头接的是**最后一步的隐藏状态**——它携带了整个序列的"记忆"。

## 时代坐标：RNN 现在还有用吗

诚实定位：2017 年 Transformer 之后，NLP 主流的序列建模已经被 Transformer 取代（可并行、长距离更强）。RNN/LSTM 家族如今主要用于：

1. **教学价值**：理解"顺序建模"和"门控思想"，是看懂更复杂结构的必修课；
2. **特定场景**：序列较短、对延迟敏感、或需流式逐词处理的场景，LSTM 仍有身影；
3. **历史背景**：读老代码、复现旧论文时你需要看得懂它。

一句话：**RNN 是序列建模的"第一代答案"，Transformer 是"最终答案"**。学它不是为了用它，而是为了理解问题本身——为什么序列需要特殊结构、梯度消失怎么被门控解决，这些认知是通用的。

## 小结

RNN 逐词传递记忆但有梯度消失的病根，**LSTM 用遗忘/输入/输出三个门让信息选择性长距离穿行，GRU 精简为两个门更轻更快**。虽然 Transformer 已成主流，但"门控记忆"的思想与"为什么序列模型需要特殊设计"的理解，仍是 NLP 与深度学习的必修认知。

从词向量到 RNN，模型越来越强但都要从头训练。下一篇迎来范式革命：BERT 与预训练——不再从零学起，而是在海量语料上学好的模型上做微调。
