传统 NLP 每个任务都要从头训一个模型，数据不够效果就差。BERT 开启了范式革命：**先用海量无标注文本把"语言理解"预训练好，再在具体任务上用小成本微调**。这一篇讲清这套范式的逻辑，并用 Transformers 库实操一个文本分类微调——它是你简历里 BERT 层级分类的直接技术底座。

## 范式：预训练 + 微调

```text
第一阶段：预训练（烧钱，大厂做一次）
海量文本（维基、全网）→ 学"通用语言理解" → 得到 BERT 权重
  │ 每个词根据上下文动态表示；填词任务学语义
第二阶段：微调（便宜，业务方做）
少量标注数据（几千条）→ 在 BERT 顶上接任务头 → 针对任务调整个别层
```

**为什么这套范式有效**：语言理解（语法、指代、常识关联）是通用的，BERT 已经在海量数据上学好了；具体任务（判断"这段描述属于哪类缺陷"）只需要在这套理解能力上"轻轻拨一下"。所以微调**几千条数据**就能达到从前几万条从头训练的效果——这正是预训练模型的巨大杠杆。

## 用 Transformers 微调文本分类

```bash
pip install transformers datasets
```

```python
from transformers import AutoTokenizer, AutoModelForSequenceClassification, Trainer, TrainingArguments
from datasets import Dataset

# 1. 加载中文预训练模型与分词器
model_name = "bert-base-chinese"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForSequenceClassification.from_pretrained(
    model_name, num_labels=5)          # 换成你的类别数

# 2. 数据：文本 + 标签
train_data = Dataset.from_dict({"text": texts, "label": labels})

# 3. 预处理：分词 → input_ids/attention_mask
def tokenize(batch):
    return tokenizer(batch["text"], padding="max_length",
                     truncation=True, max_length=128)

train_data = train_data.map(tokenize, batched=True)

# 4. 训练配置（几百条数据，2-3 epoch 就够）
training_args = TrainingArguments(
    output_dir="./bert_cls",
    num_train_epochs=3,
    per_device_train_batch_size=16,
    learning_rate=2e-5,          # 微调用很小的学习率！
    evaluation_strategy="epoch",
)

trainer = Trainer(model=model, args=training_args,
                  train_dataset=train_data, eval_dataset=val_data)
trainer.train()
```

三个关键点（都是"预训练微调"的独特纪律）：

1. **学习率必须小**（1e-5~5e-5）——BERT 已经学得很好，学习率大了会把学到的知识"冲掉"；
2. **epoch 要少**（2~5）——任务数据少，训多了立刻过拟合；
3. **分词用模型的 tokenizer**——自己 jieba 切完再喂会破坏 BERT 的输入约定。

## 微调后怎么用

```python
from transformers import pipeline

classifier = pipeline("text-classification",
                      model="./bert_cls", tokenizer=model_name)
result = classifier("混凝土表面出现蜂窝麻面，面积约0.5平方米")
print(result)   # [{'label': 'LABEL_2', 'score': 0.97}]
```

## BERT 家族与中文模型

"BERT"现在泛指"双向编码器预训练模型"家族。中文任务常用的几个：

- **bert-base-chinese**：Google 官方中文版（字级，按字切）；
- **RoBERTa-wwm-ext / ERNIE**：中文增强版，通常效果更好；
- **领域模型**：有建筑/法律/医疗领域微调过的 BERT（如法律 Bert），领域任务优先找这类——已经"懂行业"，再微调事半功倍。

## 什么时候微调 BERT，什么时候不上

| 场景 | 决策 |
| --- | --- |
| 数据 < 1000 条 | 先跑 FastText 基线；BERT 可能过拟合 |
| 数据几千~几万条、要语义理解 | BERT 微调是甜区 |
| 推理延迟敏感、无 GPU | 考虑蒸馏/量化后的轻量模型 |
| 任务在"检索/生成" | 不在这篇范围（那是 RAG/LLM 的事） |

**流程铁律：永远先建传统基线，再上 BERT 对比**——用数据说话，别用情怀。

## 小结

预训练 + 微调让 NLP 从"每个任务从头训"变成"加载通用能力 + 小成本适配"：**BERT 提供语言理解底座，微调用小组件和很小的学习率完成领域适配**。这套范式正是你简历里 BERT 分类、乃至今天所有大模型应用（RAG、Agent）共同的技术前提——先理解它，后面的 Fine-tuning 版块会展开到 LLM 层面。
