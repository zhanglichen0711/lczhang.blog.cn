前面讲的 MLP 处理小表格没问题，但直接拿它处理图像会撞墙：一张 224×224 的彩色图展开成向量是 15 万个输入，第一层若接 1000 个神经元就是 1.5 亿个参数——数据稍微多一点就过拟合到没法训。**卷积神经网络（CNN）** 用两个巧妙设计解决了这个问题：局部连接 + 权值共享。这一篇讲透它的核心部件。

## 全连接为什么不适合图像

图像的规律是**局部的**：判断"是不是猫耳朵"，只需看某片小区域，不需要看整张图。全连接让每个神经元看整张图的所有像素——既浪费参数，又学不到"局部特征在不同位置都适用"这件事（猫耳朵在左上和右下本质是同一个特征）。

## 卷积：用一个小窗口扫全图

卷积层用一个很小的"滤波器"（也叫卷积核，比如 3×3）在图像上滑动，每滑到一个位置就做一次加权求和：

```text
输入图（如 224×224×3）
   ▼ 用 3×3 卷积核滑过每个位置，得到一个特征图
特征图（如 224×224×64，64 = 64 个不同滤波器）
```

两个关键性质：

1. **局部连接**：每个输出只看输入的一个小邻域（3×3），参数骤减；
2. **权值共享**：同一个滤波器扫遍全图——"边缘检测器"在图的任何位置都能工作。64 个滤波器 = 64 种特征（边缘、角、纹理……）。

```python
import torch.nn as nn

conv_block = nn.Sequential(
    nn.Conv2d(3, 16, kernel_size=3, padding=1),   # 输入 3 通道 → 输出 16 个特征图
    nn.ReLU(),
    nn.MaxPool2d(2),                               # 下采样：尺寸减半
    nn.Conv2d(16, 32, kernel_size=3, padding=1),
    nn.ReLU(),
    nn.MaxPool2d(2),
)
```

## 池化：浓缩信息、抗平移

卷积之后常跟池化（Pooling），最常用最大池化（MaxPooling）：取小窗口里的最大值。

- **作用一：降维**——特征图尺寸减半，计算量大减；
- **作用二：提取主特征**——窗口内取最大，只保留"最显著"的激活；
- **作用三：轻微平移不变性**——物体移动几个像素，池化输出变化不大。

## CNN 的经典结构模式

几乎所有 CNN 都是同一个模式叠出来的：

```text
[卷积 + ReLU]×N  →  池化  →  [卷积 + ReLU]×N  →  池化  →  ...  →  展平  →  全连接分类
   特征提取阶段（自动学特征）                          分类阶段（用特征做决策）
```

**前半段卷积层学特征、后半段全连接做分类**——这是理解 CNN 的心智框架。特征层越深，学到的特征越抽象（浅层边缘 → 中层纹理 → 深层语义部件）。

## 用 torchvision 直接跑通一个 CNN

MNIST 手写数字分类（经典入门），完整训练就几十行：

```python
import torch
import torch.nn as nn
from torchvision import datasets, transforms
from torch.utils.data import DataLoader

class SimpleCNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(1, 16, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),   # 28→14
            nn.Conv2d(16, 32, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),  # 14→7
        )
        self.classifier = nn.Sequential(
            nn.Flatten(),
            nn.Linear(32 * 7 * 7, 10),       # 展平后接全连接出 10 类
        )

    def forward(self, x):
        return self.classifier(self.features(x))

model = SimpleCNN()
print(model)
```

训练它和前面 MLP 完全一样（DataLoader → loss → backward → step），只是网络结构从"线性堆叠"变成了"卷积 + 池化"。**训练代码不用变，换模型就换效果**——框架把差异都封装在 `nn.Sequential` 里了。

## 通道数怎么设计（理解维度）

卷积层的输出通道数（特征图数量）是人工设计的超参数，常见规律是**逐层翻倍**：16 → 32 → 64……因为浅层特征图分辨率高但通道少，深层分辨率低但通道多——用"数量换空间"。

形状变化规则一句话：**卷积通常保持宽高（padding=1、kernel=3），池化把宽高减半，通道数翻倍**。看到报错尺寸不对，按这个规律核对。

## CNN 之后：现代视觉的发展

CNN 是视觉的"地基"（从 2012 年的 AlexNet 到 ResNet），但今天的主流已经演进：图像分类、检测（YOLO 这类，对应多模态那篇的图文融合）、以及视觉 Transformer（ViT）。**CNN 的价值不止于它本身**——理解"局部连接 + 权值共享 + 层次特征"这套思想，才能看懂后面所有视觉模型的演进逻辑。

## 小结

CNN 用两个设计破解了图像难题：**卷积用局部感受野 + 权值共享把参数从亿级压到千级，池化浓缩信息抗扰动**。结构上记住"特征提取 + 分类"两段式。用 PyTorch 搭一个能跑的分类 CNN，是本篇的验收标准——它也是后面所有视觉任务的起跑线。
