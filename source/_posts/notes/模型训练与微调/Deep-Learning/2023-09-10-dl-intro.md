机器学习那几篇里，效果好不好很大程度取决于**特征工程**——我们手动把数据变成模型能懂的数值。这套方法论在图像、语音、复杂文本上碰到了墙：一张图片的"特征"是什么？边缘？纹理？没人能用手工规则设计得明白。深度学习回答了这个问题：**特征不靠人设计，让模型从数据里自己学**。这一篇讲清这个范式转变，为后面整个 Deep-Learning 篇章奠基。

## 机器学习 vs 深度学习：特征从哪来

| | 传统机器学习 | 深度学习 |
| --- | --- | --- |
| 特征 | 人手工设计（特征工程） | **模型自动学习**（多层抽象） |
| 适用数据 | 表格、结构化数据 | 图像、语音、文本等非结构化数据 |
| 模型结构 | SVM、树、线性模型 | 多层神经网络 |
| 数据需求 | 千~万级样本可用 | 通常需要大量数据 |

核心差异一句话：**传统方法把"表示"（特征）当输入，深度学习把"表示"当学习目标**。一张图片进神经网络，第一层学到边缘，第二层学到纹理，第三层学到部件——人没有告诉它"看边缘"，它是从"这个任务该怎么分"反推出来的。

## 神经网络：特征学习的载体

深度学习的载体是多层神经网络。一个最朴素的直觉图：

```text
输入层（原始数据，如图片像素）
   │
隐藏层 1 ──> 学到低级特征（边缘）
隐藏层 2 ──> 学到中级特征（纹理/形状）
隐藏层 3 ──> 学到高级特征（部件/语义）
   │
输出层（分类结果 / 预测值）
```

每一层做的事其实很"朴素"：**对上一层的输出做一次线性变换，再过一次非线性激活函数**。但几十上百层这样堆叠，就能表达极其复杂的函数。这就是"深度"的含义——不是玄学，是表示能力的层层抽象。

## 三个让深度学习"站起来"的支柱

1. **大数据**：特征从数据里学，数据量就是燃料。ImageNet 百万级图片让深度模型第一次在视觉上超过手工特征；
2. **算力（GPU）**：神经网络训练是大量矩阵运算，天生适合 GPU 并行——没有 GPU 时代的算力，深度学习等不到爆发；
3. **算法突破**：反向传播（怎么高效算梯度）、ReLU（解决梯度消失）、批量归一化等，让"堆很多层"从不可能变成可行。

这三样缺一不可——这也是为什么神经网络 1980 年代就有雏形，却到 2012 年前后才真正起飞。

## 深度学习的三种经典形态

现代深度学习按数据类型分了三条主线，本书后面的章节会分别展开：

| 形态 | 处理的数据 | 代表结构 |
| --- | --- | --- |
| 卷积网络 CNN | 图像 | 卷积层提取空间特征 |
| 循环网络 RNN/LSTM | 序列（文本、时间线） | 按时间步建模 |
| Transformer | 序列（现在是文本/多模态主流） | 自注意力 |

这三条线最终汇合到今天的"预训练 + 微调"范式——先在海量数据上学会通用表示，再在特定任务上小成本适配（这是 Fine-tuning 篇章的内容）。

## 一个必须建立的观念：训练是"调参"

和传统机器学习"拟合一条线"类似，深度学习训练的本质也是**优化**：定义损失函数（预测和真实差距多大），用梯度下降不断调整网络里成千上万个参数，让损失越来越小。

```python
# 后面会用 PyTorch 写完整实现，这里先建立"训练循环长什么样"的直觉
for epoch in range(num_epochs):
    loss = compute_loss(model(X_batch), y_batch)   # 算当前差距
    loss.backward()                                 # 算每个参数的梯度
    optimizer.step()                                # 沿梯度更新参数
```

记住这个骨架，后面的反向传播、优化器、PyTorch 篇章全是在填充它的细节。

## 小结

深度学习不是"更复杂的机器学习"，而是一次**表示学习的范式转变**：不再由人设计特征，而是让多层网络从数据里自动学出层次化特征。它的前提是大数据 + GPU + 算法三支柱，它的核心机制是"前向计算 → 损失 → 反向传播 → 参数更新"这条训练循环。
