神经网络听起来高深，但它最小的组成单元——**感知机**——其实简单得让人意外。这一篇从感知机讲起，逐步推演出"为什么多层网络更强"，把神经网络的第一块积木搭明白。

## 感知机：一个带权重的投票器

感知机（Perceptron）是最早的神经网络单元（1958 年，Frank Rosenblatt）。它的逻辑朴素得像投票：每个输入特征按权重打分，加起来过阈值，决定输出 1 还是 0。

$$y = \begin{cases} 1 & \text{if } w_1x_1 + w_2x_2 + b > 0 \\ 0 & \text{otherwise} \end{cases}$$

```python
import numpy as np

def perceptron(x, w, b):
    """x: 特征向量；w: 权重；b: 偏置"""
    z = np.dot(w, x) + b      # 加权求和
    return 1 if z > 0 else 0

# 例：AND 逻辑门
w = np.array([1.0, 1.0]); b = -1.5
print(perceptron(np.array([1, 1]), w, b))   # 1
print(perceptron(np.array([0, 1]), w, b))   # 0
```

一个感知机本质是**一条线性决策边界**（和逻辑回归同源：加权求和 + 阈值）。它能学会 AND、OR 这类线性可分的问题。

## 感知机的致命局限：学不会 XOR

1969 年 Minsky 用 XOR 问题给了感知机一记重击：XOR 需要"两个都不同才输出 1"，它的正负样本**在二维平面上无法用一条直线分开**（像两条对角交叉的带子）。单层感知机永远学不会它。

关键洞见由此而来：**一条线不够，那就用多条线拼**。多层网络 = 用第一层的多条线性边界，去组合出第二层的非线性边界：

```python
# 直觉：XOR = (A AND NOT B) OR (NOT A AND B)
# 先算两条"线"（子边界），再对它们的结果做一次判断——这就是多层的意义
```

## 多层网络：从线到面

把多个感知机组成一层，层与层之间全连接，就是**多层感知机（MLP）**，也是"神经网络"最基础的样子：

```text
输入 x ──► 隐藏层（多个神经元，每条都是线性边界）
              │ 每个神经元的输出过非线性激活
              ▼
         输出层（组合这些边界做最终判断）
```

**关键点：层之间必须夹非线性激活函数**。如果只是线性变换叠线性变换，数学上等价于一层（叠再多也是线性），网络就退化成单层——白堆。非线性的激活函数（如 ReLU）才让"多层 > 单层"成立。

## 用 sklearn 直接跑一个 MLP 验证直觉

先不写反向传播（下一篇讲），用现成库验证"MLP 能学会线性模型学不会的边界"：

```python
from sklearn.neural_network import MLPClassifier
from sklearn.datasets import make_moons

# 弯月形数据：线性不可分
X, y = make_moons(n_samples=500, noise=0.1)

# 单层（线性）模型 vs 多层感知机
mlp = MLPClassifier(hidden_layer_sizes=(16, 16),  # 两个隐藏层
                    activation="relu", max_iter=500)
mlp.fit(X, y)
print("MLP 测试得分:", mlp.score(X, y))
```

`hidden_layer_sizes=(16, 16)` 表示两个隐藏层、每层 16 个神经元。这样的网络已经能把弯月形数据切得干干净净——而 SVM 需要核技巧才能做到的事，MLP 靠"堆层 + 激活"就能表达。

## 隐藏层为什么"越多越强"（也有代价）

- **层数增加 → 表达能力增强**：理论上足够宽的神经网络能逼近任意连续函数（万能近似定理）；
- **但随之而来两个问题**：
  1. 参数爆炸——全连接层参数 = 输入数 × 神经元数，图片那种高维输入直接吃不消（所以图像要用卷积，后面讲）；
  2. 训练变难——层深了梯度容易消失/爆炸（所以要有好的初始化、激活、归一化，后面专篇讲）。

这也是深度学习的"甜蜜烦恼"：**模型够强了，问题变成了怎么把它稳定地训练出来**。

## 小结

感知机是一条线性边界，多个带非线性的层叠起来就能画任意边界——这是神经网络的立身之本。记住三个要点：单层学不会 XOR 这类线性不可分问题；多层靠"线性变换 + 非线性激活"获得表达力；堆层能变强但会带来参数与训练难度的新问题。
