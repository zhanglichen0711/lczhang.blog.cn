Transformer 论文的原始形态是"编码器-解码器"结构，用于机器翻译：左边读原文，右边生成译文。虽然今天的大模型多数只用其中一半（BERT 用编码器、GPT 用解码器），但理解完整架构是看懂一切变体的基础。这一篇拆开这两半，讲清它们各干什么、怎么协作。

## 全景图：两半各司其职

```text
编码器（Encoder）                     解码器（Decoder）
读整句原文 → 提炼语义                   根据原文语义 → 逐个生成译文词
┌──────────────────┐               ┌──────────────────────────┐
│ 输入: I love you  │               │ 输出: 我 爱 你 <结束>      │
│   ↓              │               │   ↑ 上一步输出也喂回输入      │
│ 多头自注意力      │               │ 掩码多头自注意力(只看已生成)  │
│   ↓              │               │   ↓                        │
│ 前馈网络 ×N 层    │               │ 交叉注意力(查编码器输出)      │
│   ↓              │               │   ↓                        │
│ 语义表示 K,V      │──传递──→       │ 前馈网络 ×N 层              │
└──────────────────┘               └──────────────────────────┘
```

- **编码器**：一次性看完整句原文，输出每个词的"语义表示"（含上下文）；
- **解码器**：逐词生成译文——每生成一个词，都要**回头查询编码器的输出**（这就是"交叉注意力"，解码器的 Q 去匹配编码器的 K/V）。

## 解码器为什么必须"掩码"

生成是**逐词的**：输出第 3 个词时，模型只能看到前 2 个词，绝不能偷看后面的词（否则训练时答案就泄漏了）。所以解码器的自注意力要加**掩码（Mask）**，把"未来位置"屏蔽掉：

```text
注意力矩阵（行=当前词，列=能看的词）：
           能看 词1 词2 词3
当前词1:   ✓   ✗   ✗
当前词2:   ✓   ✓   ✗
当前词3:   ✓   ✓   ✓     ← 三角形：只能看自己和前面
```

实现上就是把未来位置设为负无穷，softmax 后权重为 0：

```python
def causal_mask(size):
    mask = torch.triu(torch.ones(size, size), diagonal=1)  # 上三角为 1
    return mask.masked_fill(mask == 1, float("-inf"))
```

**训练时也这么限制**——虽然训练时整句译文都在手上，但必须假装"只看前面的"，模型学到的是"基于已生成内容预测下一个词"的能力，推理时才一致。

## 交叉注意力：两半的"对话"

解码器的每一步不只靠自己的历史，还要**查原文**。这就是解码器里的第二层注意力——交叉注意力：

```text
Q ← 解码器当前位置（正在生成"爱"）
K,V ← 编码器输出（整句原文的语义表示）
→ 结果：生成每个词时，注意力动态聚焦原文的相关部分
```

翻译"我 love you"时，生成"爱"的瞬间，交叉注意力会重点看向原文的 "love"——**这种"生成时回看原文"的机制，就是注意力机制最初的价值**。

## 掩码 vs 交叉注意力的位置

一个解码器层内部按顺序是：

```python
class DecoderLayer(nn.Module):
    def __init__(self, d_model, num_heads):
        super().__init__()
        self.self_attn = MultiHeadAttention(d_model, num_heads)   # 看自己（掩码）
        self.cross_attn = MultiHeadAttention(d_model, num_heads)  # 看编码器
        self.ff = ...                                             # 前馈
        self.norms = ...

    def forward(self, x, encoder_out, mask):
        x = x + self.self_attn(self.norm1(x), mask=mask)   # 掩码自注意力
        x = x + self.cross_attn(self.norm2(x), encoder_out)  # 交叉注意力
        x = x + self.ff(self.norm3(x))
        return x
```

**第一步看自己（掩码防偷看），第二步看原文（交叉注意力）**——顺序不能反。

## 端到端：训练与推理的差别

- **训练**：整个目标句一次性进解码器（配合掩码），一次前向算出所有位置的预测，loss 一次性回传——**可以并行**，这也是 Transformer 训练快的原因；
- **推理**：只能从 `<开始>` 逐个生成，每生成一个词把它追加进输入再算一次——串行，但每步只需算增量。

## 小结

完整 Transformer = **编码器读原文提语义 + 解码器带掩码逐词生成、再靠交叉注意力回看原文**。三个关键机制各管一摊：自注意力学关系、掩码防偷看保证自回归一致性、交叉注意力让生成对齐输入。理解了这版完整架构，下一篇看它的两个著名"半身"——BERT（只留编码器）和 GPT（只留解码器），以及它们如何统治了预训练时代。
