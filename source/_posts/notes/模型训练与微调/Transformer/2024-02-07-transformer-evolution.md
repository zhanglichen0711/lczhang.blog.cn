原始 Transformer 是"编码器+解码器"的完整翻译机。但预训练时代的两个王者各取了一半：**BERT 拿走编码器，GPT 拿走解码器**。同样一个结构，为什么拆成两半各自封王？这一篇讲清两条路线的分野，以及它们如何汇流成大模型时代。

## 两个分支的骨架

```text
BERT（2018, Google）              GPT（2018 起, OpenAI）
只留编码器                        只留解码器
├─ 双向：能看到整句上下文           ├─ 单向：只能看左侧历史
├─ 擅长"理解"任务                  ├─ 擅长"生成"任务
│  分类、抽取、判别                 续写、对话、生成
├─ 预训练任务：完形填空              ├─ 预训练任务：预测下一个词
│  （Masked LM，盖住词猜它）          （Next Token Prediction）
└─ 微调：接个分类头做下游任务        └─ 微调/提示：直接对话续写
```

**一句话**：BERT 是"填空式"学理解，GPT 是"续写式"学生成。同一个自注意力，前者能看两边（双向），后者只看左边（单向，就是上一篇的掩码）。

## BERT：双向理解，填空训练

BERT 的预训练任务极聪明：随机把 15% 的词盖成 `[MASK]`，让模型根据**左右两边**的上下文猜被盖住的词。

```text
输入: [CLS] 我 [MASK] 北京 [SEP]
目标: 猜出 [MASK] = 爱（需要看左边"我"和右边"北京"）
```

因为要看"两边"，编码器天然适配（解码器的掩码反而碍事）。学会填空 = 学会了词在上下文中的语义——这就是"上下文动态表示"。下游任务（文本分类、问答、实体识别）只需**在 BERT 顶上接一个分类头微调**，效果立刻碾压从头训练——这正是 NLP 章节会展开的"预训练 + 微调"范式。

## GPT：单向生成，续写训练

GPT 更简单粗暴：只做一件事——**预测下一个词**。给它"今天天气真"，它学的是最大化"好/不错/糟糕"这些下一个词的概率。

```text
输入: 今天 天气 真
目标: 预测下一个 → 好
然后: 今天 天气 真好 → 预测 → 适合出门 ...
```

因为只靠左侧预测右侧，解码器的因果掩码刚好契合。这个看似"笨"的任务有个杀手级优势：**互联网上的任何文本都是免费的训练数据**（不需要人工标注），数据量可以无限堆。GPT 的路线就是"大力出奇迹"：模型越来越大、数据越来越多，能力随之涌现——直到 ChatGPT 级别的对话能力。

## 双向 vs 单向：为什么 GPT 赢了

一个绕不开的问题：BERT 双向看得更全，为什么最后是"单向"的 GPT 路线统治了大模型时代？

关键在**任务形态**。预训练的目标不是"做任务"，而是学会"生成语言"。能生成，就能对话、能写代码、能当 Agent——**能力是通用的**；而 BERT 擅长的是"判断"，要接任务头才能用。再叠加生成式训练的规模化优势，GPT 路线在"通用智能"这个方向上一路领先。今天的主流 LLM（DeepSeek、Qwen、Llama）都是 GPT 式**仅解码器**结构。

## 通用骨架：现在看 LLM 就像看老朋友

理解了这两条线，现在打开任何大模型的结构说明（比如 Llama、Qwen），你会发现全是你学过的东西：

```text
仅解码器 Transformer（现代 LLM 的统一骨架）
├─ Embedding：词转向量 + 位置编码
├─ N × 解码器层：
│   ├─ 掩码多头自注意力（因果：只看左边）
│   ├─ 前馈网络 FFN
│   └─ 残差 + LayerNorm
└─ 输出层：预测下一个词的概率分布
```

区别只在**规模**（几十亿参数、几十上百层）和**细节**（RoPE 位置编码、GQA、SwiGLU 激活等工程优化）——骨架没变。**这也是为什么这个版块值得学透：你在直接理解现代大模型的内脏**。

## 小结

BERT 与 GPT 是同一枚 Transformer 硬币的两面：**编码器 + 双向 + 填空 → 理解派；解码器 + 单向 + 续写 → 生成派**。生成式路线因"能力通用 + 数据无限"胜出，成为今天 LLM 的底座。看懂这两条线的分野与汇流，你就站在了从"经典 Transformer"通往"大模型时代"的桥头。
