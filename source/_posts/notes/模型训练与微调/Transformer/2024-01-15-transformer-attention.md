自注意力是 Transformer 的心脏，Q、K、V 是它的三个字母。这一篇不讲公式天书，用一个"查资料"的类比把注意力机制讲透——你会发现它本质是一个**加权求和**，只是"权重"是自己动态算出来的。

## 一个类比：查资料的流程

想象你在写报告要"查资料"：你会带着一个问题（**Query**，查询），在一堆资料里按关键词（**Key**，索引）找最相关的几份，然后重点读这几份的内容（**Value**，内容）。

注意力机制做的完全是同一件事：

| 概念 | 类比 | 作用 |
| --- | --- | --- |
| **Q**（Query） | 你的问题 | 想找什么 |
| **K**（Key） | 资料的标题/索引 | 拿什么去匹配 |
| **V**（Value） | 资料的实际内容 | 最终取用的信息 |

"北京"这个词要理解自己，就把自己当 Q，去和序列里每个词的 K 匹配，算出和谁相关，再用相关度做权重去加权 V——相关度高的词贡献大，相关度低的几乎不贡献。

## 注意力的三步计算

对一个词（第 $i$ 个位置），它和另一个词（第 $j$ 个位置）的注意力计算分三步：

**第 1 步：算相关度（Q·K）**

```text
score(i, j) = Q_i · K_j        # 点积：两个向量越像，值越大
```

**第 2 步：归一化成权重（softmax）**

```text
weight(i, j) = softmax_j(score(i, j))    # 变成所有词上求和为 1 的权重
```

**第 3 步：按权重加权求和取 V**

```text
Output_i = Σ_j  weight(i, j) × V_j       # 相关度高的 V 贡献大
```

第 $i$ 个词的最终表示 = **序列里所有词的 V 按相关度加权求和**。词与词之间的关系（谁影响谁、影响多大），完全由数据学出来的 Q/K/V 变换决定。

## 用一个手算例子看本质

简化到无语义，只感受计算流程。设序列两个词，各自只有 1 维的 Q、K、V：

```python
import numpy as np

# 两个词的 Q、K、V（简化为一维）
Q = np.array([0.8, 0.3])      # 词1、词2 的查询
K = np.array([0.9, 0.2])      # 词1、词2 的键
V = np.array([0.5, 1.0])      # 词1、词2 的值

# 第 1 步：词1 分别和词1、词2 算点积得分
scores = Q * K                 # 逐位置点积（一维简化）
print("得分:", scores)         # 词1 更"匹配"词1

# 第 2 步：softmax 成权重
def softmax(x):
    e = np.exp(x - x.max())
    return e / e.sum()

weights = softmax(scores)
print("权重:", weights)        # 词1 权重高

# 第 3 步：加权求和得到"更新后的词1"
output_1 = (weights * V).sum()
print("词1 的新表示:", output_1)
```

可以看到：**词 1 的新表示 = 自己(0.5)和词2(1.0)按"谁更相关"加权混起来的结果**。真实场景里 V 是高维向量，这一步就是"把相关词的语义揉进当前词"。

## 为什么要 Q、K、V 三套而不是一套

直觉问题：为什么不直接用词向量本身算相似度？因为**"拿什么去匹配"和"匹配到后取什么"是两件事**——一个词作为"被查询者"（K）和作为"提供信息者"（V）的角色不同。词向量经过三组不同的线性变换变成 Q/K/V，模型就能学到更丰富的匹配逻辑。这也是"表示"从静态词向量走向"上下文动态表示"的关键一步。

## 自注意力 vs 注意力

两个词常被混用：

- **注意力（Attention）**：广义，Q 来自一个地方、K/V 来自另一个地方（比如翻译时，解码器的 Q 去查编码器的 K/V）；
- **自注意力（Self-Attention）**：**Q、K、V 都来自同一个序列**——序列内部自己看自己，建立词与词的关系。

Transformer 里用的是自注意力（编码器侧），翻译等跨序列场景用标准注意力（解码器侧）。理解"自己匹配自己"是自注意力的特征即可。

## 小结

注意力机制 = **Q 找 K 算相关度 → softmax 成权重 → 加权取 V**，本质是一次"数据自己决定向谁借信息"的加权求和。它让每个词一步直达全序列的相关词——这就是长距离依赖的解法。有了单头注意力，下一篇讲它怎么升级成多头、并补上"位置"这个信息维度。
