## 线性回归问题

### 1. 正规方程法

- 一元线性回归：y = wx +b  目标值只与一个因变量有关系 w: 斜率(权重)  b:截距(偏置)

- 多元线性回归：y = w1*x1+w2*x2 + w3 x3 + …  + b = w^T x+b

```python
# 导包
from sklearn.linear_model import LinearRegression
# 机器学习建模流程
# 1.数据获取
x = [[160], [166], [172], [174], [180]]
y = [56.3,60.6,65.1,68.5,75]
# 2.数据预处理 - 缺失，无效数据
# 3.特征工程
# 4.模型训练
# 4.1 创建模型（实例化）
model = LinearRegression()
# 4.2 训练模型（拟合）
model.fit(x, y)  # 通过特征+对应的标签进行训练
# 5.模型预测
x_pre = [[192]]
y_pre = model.predict(x_pre)
# 查看预测结果
print(y_pre)
# 查看权重和偏置
print(f'斜率：{model.coef_}，截距：{model.intercept_}')
# 6.模型评估
```

- 误差：预测值-真实值

- 损失函数：

​		最小二乘法：Σ(f(xi)-yi)²

​		平均绝对误差：1/mΣ|f(xi)-yi|

​		均方误差：1/mΣ(f(xi)-yi)²

​		均方根误差：根号1/mΣ(f(xi)-yi)²

- 损失函数'->函数的瞬时变化率

- 瞬时变化率=0表示函数为最小值

### 2. 梯度下降法

- 梯度:指北针

  - 梯度:函数上升的方向
  - 梯度的反方向:函数下降的方向

- 梯度=损失函数 '

- 梯度更新：w新=w旧-学习率*梯度

  - 学习率不能太大 -- 梯度震荡

    学习率不能太小 -- 梯度爆炸

    学习率：0.001-0.01

  - 停止

    - 最大更新次数
    - 更新变化值

- 分类方法

  - 全梯度下降 FGD
    - 使用全部样本的梯度值
  - 随机梯度下降 SGD
    - 随机选择一个样本的梯度值更新权重
  - 小批量梯度下降 mini-batch
    - 随机选择小部分样本的梯度值更新权重
  - 随机平均梯度 SAG
    - 使用以前产生的梯度值来指导当前的梯度计算

### 4.线性回归模型评估方法

- MAE越小误差越小
- MSE会放大预测误差较大的样本的影响
- RMSE越小误差越小，一般大于MAE
- MAE和RMSE越接近，模型的误差越低
