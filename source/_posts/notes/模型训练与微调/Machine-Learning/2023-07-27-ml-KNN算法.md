## 一、KNN算法

### 1. 概念

- K-近邻算法
  - 寻找与最近邻的K个样本，对未知样本进行预测
  - 样本的距离通过欧氏距离来度量

### 2. 分类

- 基于选出的样本标签进行投票，出现次数最多的类别
  - sklearn.neighbors.KNeighborsClassifier

### 3. 回归

- 基于选出的样本标签，求其平均值
  - sklearn.neighbors.KNeighborsRegressor

### 4. API的使用

```python
# 模型训练
model = KNeighborsClassifier() # 默认值是5
model.fit(x,y)
# K值过小--过拟合
# K值过大--欠拟合
```

### 6. 超参数选择

- 交叉验证
  - 数据集的划分：将训练集划分为 n 份，一份做验证集，其他做训练集 
- 网格搜索
  - 获取最优的超参数
    - best_params_：最优超参
    - best_score_：最好结果
    - best_estimator_：最佳模型
    - cv_results_：每次交叉验证后的验证集和训练集的准确率结果

```python
# 导包
from sklearn.datasets import load_iris # 鸢尾花案例
from sklearn.metrics import accuracy_score # 结果准确率
from sklearn.model_selection import train_test_split, GridSearchCV # 交叉验证及网络搜索
from sklearn.neighbors import KNeighborsClassifier # KNN分类
from sklearn.preprocessing import StandardScaler # 标准化

datasets = load_iris()
# 数据集划分
x_train, x_test, y_train, y_test = train_test_split(datasets.data, datasets.target, test_size=0.2)
# 标准化
scaler = StandardScaler()
# 第一步需要fit_transform标准化，后续基于此标准转化
x_train = scaler.fit_transform(x_train)
x_test = scaler.transform(x_test)
# 模型实例化
model = KNeighborsClassifier(n_neighbors=5)
# 交叉验证和网格搜索（算法思想）
new_model = GridSearchCV(estimator=model, param_grid={'n_neighbors': [i for i in range(1, 10)]}, cv=4)
# 模型训练
new_model.fit(x_train, y_train)
# 模型测试
y_pre = new_model.predict(x_test)
print(accuracy_score(y_test, y_pre))
# 最优超参
print(new_model.best_params_)
# 最高分
print(new_model.best_score_)
# 最佳模型
print(new_model.best_estimator_)
# cv结果
print(new_model.cv_results_)
```

### 7. 分类问题评估

- **混淆矩阵**
  - TP：真实值是正例 ，预测值为正例（正确）
  - FN：真实值是正例，预测值为反例（错误）
  - FP：真实值是反例，预测值为正例（错误）
  - TN：真实值是反例，预测值为反例（正确）

![image-20260718143752574](E:\blog_hexo\xiaohei-blog\source\img\image-20260718143752574.png)

```python
#混淆矩阵
from sklearn.metrics import confusion_matrix
y_true=['恶','恶','恶','恶','恶','恶','良','良','良','良']
y_pre1=['恶','恶','恶','良','良','良','良','良','良','良']
y_pre2=['恶','恶','恶','恶','恶','恶','恶','恶','恶','良']
print(confusion_matrix(y_true, y_pre1, labels=['恶', '良']))
[[3 3]
 [0 4]]
print(confusion_matrix(y_true, y_pre2, labels=['恶', '良']))
[[6 0]
 [3 1]]
```

- **精确率𝑃𝑟𝑒𝑐𝑖𝑠𝑖𝑜𝑛**
  - 查准
  - P = TP / ( TP + FP )：猜对的正样本 / 预测的正样本数量
- **召回率𝑅𝑒𝑐𝑎𝑙𝑙**
  - 查全
  - P = TP / ( TP + FN )：猜对的正样本 / 真实的正样本数量
- **F1-score**
  - 2 * 精确率 * 召回率 / (精确率+召回率)
  - 综合能力、综合稳定性指标 

```python
# API
from sklearn.metrics import accuracy_score,precision_score,recall_score,f1_score
print('准确率:',accuracy_score(y_true, y_pre1))
print('精确率:',precision_score(y_true, y_pre1, pos_label='恶'))
print('召回率:',recall_score(y_true, y_pre1, pos_label='恶'))
print('F1:',f1_score(y_true, y_pre1, pos_label='恶'))
```

## 二、决策树

### 1.原理

- 强制二分
- 通过基尼值选择最优的划分节点
  - gini值=2(p正)(1-p正)
  - 基尼值越小划分质量越高
- 重复逐层划分
- 剪枝，防止过拟合

### 2.API

- Criterion:特征选择标准
- min_samples_split:内部节点再划分所需最小样本数
- min_samples_leaf:叶子节点最少样本数
- max_depth:决策树最大深度
- model = DecisionTreeClassifier()
- 独热编码
  - one-hot
  - new_x = pd.get_dummise(x)  把字符串改成布尔值

### 4. 剪枝

- 预剪枝
  - 决策树生成过程中，每个节点划分前进行
  - 训练测试时间少，有欠拟合风险
  - 兜底
- 后剪枝
  - 先生成完整决策树，自底向上地对非叶节点进行考察
  - 训练测试时间多，泛化能力强
  - 优化
