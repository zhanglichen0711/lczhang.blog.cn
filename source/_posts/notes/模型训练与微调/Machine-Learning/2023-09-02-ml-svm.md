逻辑回归这类线性模型有个天花板：**边界是线性的**。真实数据往往弯弯曲曲、线性切不开。支持向量机（SVM）是经典机器学习里解决这个问题的代表——它的思路分两层：先找"最稳"的线性边界，再用核方法把非线性数据变到能线性切的高维空间。

## 直觉：边界要"离两类都远"

假设两类点能被一条线分开。能分开的线有无数条，SVM 选的是**离两类样本都最远的那条**（最大间隔）。理由很工程：边界离数据远，新来的样本更不容易被分错——泛化更好。

离边界最近的那些样本点叫**支持向量**，它们是"撑住"这条边界的决定性样本。这个性质带来一个实际好处：**SVM 的模型只由支持向量决定**，删掉其他样本不影响模型。

```python
from sklearn.svm import SVC
from sklearn.datasets import make_classification

X, y = make_classification(n_samples=500, n_features=10, random_state=42)
model = SVC(kernel="linear", C=1.0)
model.fit(X, y)
print("支持向量个数:", len(model.support_vectors_))
```

## 线性分不开怎么办：核方法

很多数据在原始空间里根本没有线性边界（比如"内圈/外圈"的同心圆）。SVM 的破局点是**核方法**：不直接在高维空间算，而是用核函数在原始空间里等价地算出"高维空间的内积"。

最常用的核：

```python
# RBF 核（默认）：能逼近任意形状的边界，非线性首选
svm_rbf = SVC(kernel="rbf", C=1.0, gamma="scale")

# 多项式核：适合边界接近多项式的情况
svm_poly = SVC(kernel="poly", degree=3)
```

拿同心圆数据试一下就知道差异：

```python
from sklearn.datasets import make_circles

X, y = make_circles(n_samples=300, noise=0.1, factor=0.4)

svc_linear = SVC(kernel="linear").fit(X, y)   # 线性：几乎没法分
svc_rbf = SVC(kernel="rbf").fit(X, y)         # RBF：能圈出内圈

print("linear 得分:", svc_linear.score(X, y))
print("rbf 得分:", svc_rbf.score(X, y))
```

## 两个关键参数：C 和 gamma

SVM 参数不多，主要就两个，理解它们就能调：

| 参数 | 控制什么 | 调大 | 调小 |
| --- | --- | --- | --- |
| `C` | 对误分类的容忍度 | 更严格拟合、易过拟合 | 更宽容、边界更平滑（欠拟合） |
| `gamma`（RBF） | 单个样本的影响半径 | 影响范围小、边界复杂（易过拟合） | 影响范围大、边界平滑 |

新手最容易犯的错是把 `gamma` 调得过大——模型开始"围着每个训练点画圈"，训练得分 100%、测试一塌糊涂（典型过拟合）。

**参数用网格搜索找，别手调**：

```python
from sklearn.model_selection import GridSearchCV

param_grid = {"C": [0.1, 1, 10], "gamma": ["scale", 0.1, 1]}
search = GridSearchCV(SVC(kernel="rbf"), param_grid, cv=5)
search.fit(X_train, y_train)
print("最优参数:", search.best_params_)
print("最优 CV 得分:", search.best_score_)
```

## 放今天的坐标系里看 SVM

必须诚实：在大规模数据和深度学习面前，SVM 不再是主角。但它在经典机器学习里仍有三席之地——

1. **小样本、高维**：样本量不大时，SVM（尤其线性 SVM）效果稳、不易过拟合；
2. **文本分类**：线性 SVM 在 TF-IDF 特征上的文本分类曾长期是强基线；
3. **理解深度学习前的"桥梁"**：SVM 的"间隔最大化"思想，与后面神经网络的"特征表示 + 分类头"一脉相承——它帮你建立"模型到底在优化什么"的直觉。

## 小结

SVM = **找最大间隔的线性边界 + 核方法处理非线性**。记住三件事：边界离数据越远越稳；数据线性分不开就换 RBF 核；`C` 和 `gamma` 决定拟合程度，用网格搜索找。经典机器学习里，它是"结构化数据小样本"场景最可靠的选择之一。
