## 一、集成学习

### 1. 思想

- 多个弱学习器组合成一个更强大的学习器，得到更好性能

### 2. 分类

- Bagging
  - 有放回的抽样
  - 平权投票决定预测结果
  - 并行训练

![image-20260901214913937](E:\blog_hexo\xiaohei-blog\source\img\image-20260901214913937.png)

- Boosting
  - 重点关注前一个训练器不足的地方进行训练
  - 加权投票决定预测结果
  - 串行的训练

![image-20260901214943994](E:\blog_hexo\xiaohei-blog\source\img\image-20260901214943994.png)

### 3. 随机森林

- RandomForestClassifier
- n_estimators
  - 决策树数量
- max_depth
  - 最大深度

```python
# 4.模型训练
# 4.1 决策树
model1 = DecisionTreeClassifier()
model1.fit(x_train, y_train)
y_pre1 = model1.predict(x_test)
# 4.2 随机森林
model2 = RandomForestClassifier()
model2.fit(x_train, y_train)
y_pre2 = model2.predict(x_test)
# 4.3 随机森林 - 超参优化
model3 = RandomForestClassifier()
model3 = GridSearchCV(model3, param_grid={'n_estimators': [10,30,50], 'max_depth': [6,8,10,None]}, cv=4)
model3.fit(x_train, y_train)
y_pre3 = model3.predict(x_test)
```

## 二、聚类算法

### 1. 概念

- 根据样本相似性分类
  - 欧氏距离
- 自动发现数据集中的内在结构和模式
- 无监督学习算法

### 2. 分类方法

- 颗粒度分类：细聚类、粗聚类
- 实现方法分类：KMeans

### 3. KMeans

- n_clusters：聚类中心数量
- 实现步骤
  - 确定聚类类别数量K
  - 随机选择K个样本点作为簇心
  - 计算每个样本点距离簇心的距离，判断赝本属于哪个簇
  - 重新计算簇心
  - 重复以上两个步骤
  - 直到新簇心与旧簇心一致结束


![image-20260901215120290](E:\blog_hexo\xiaohei-blog\source\img\image-20260901215120290.png)

- 模型评估方法

  - 误差平方和SSE
    - 肘方法：确定 n_clusters 的值
    - SSE 越小，表示数据点越接近它们的中心，聚类效果越好

  ![image-20260901215156996](E:\blog_hexo\xiaohei-blog\source\img\image-20260901215156996.png)

  - CH轮廓系数
    - calinski_harabasz_score
    - 簇间分散度 / 簇内聚合度
      - 越大越好
  - SC轮廓系数
    - silhouette_score
