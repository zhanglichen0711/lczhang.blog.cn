### 2. 简单查询

语法:

```sql
select [distinct]
* | 列名 [as 别名],列名 [as 别名]
from 表;

说明:
	distinct : 表示 去重,  对输出的结果进行去重操作
	* :  表示所有的字段
	| : 表示 或者的意思, 左边 和 右边的内容 不能再一个表中重复出现
```

需求说明:

```sql
-- 简单查询:
/*
   语法:
      select [distinct]
        * | 列名1 [as 别名1] ,列名2 [as 别名2] ....
      from 表;

   说明:
     * : 所有的字段
     | : 或者的关系, 表示要不就写左边语法 要不就写右边的语法 只能二选一
    distinct : 用于去重的操作.针对行与行之间如果有重复 可以通过该关键词去重
 */
-- 1 查询所有的商品.
select
  *
from day04_dql.product;
-- 2 查询商品名和商品价格.
select
  pname,
  price
from day04_dql.product;
-- 3 别名查询.使用的关键字是as（as可以省略的）.
-- 3.1 表别名: 为表起一个别名 p   在单表查询中 无意义
select
  p.pname,
  p.price
from day04_dql.product as p ;

select
  p.pname,
  p.price
from day04_dql.product p ;
-- 在实践应用中 表别名 建议省略 as 书写
-- 3.2 列别名: 将表中所有的字段在展示的时候全部使用中文
select
 pid as '商品编号' ,
 pname as '商品名称' ,
 price as '价格',
 category_id as '分类编号'
from day04_dql.product;

-- 在实践应用中 一般不会省略as操作
-- 4 去掉重复值:  查询商品分类ID , 并且去重展示
select
  distinct  category_id
from day04_dql.product;
-- 5 查询结果是表达式（运算查询）：将所有商品的价格+10元进行显示.
select
 pid,
 category_id,
 price + 10 as price,
 pname
from day04_dql.product;

```

### 3. 条件查询

| 比较运算符     |                             |                                                              |
| -------------- | --------------------------- | ------------------------------------------------------------ |
|                | > < <=  >=  =  <> !=        | 大于、小于、大于(小于)等于、不等于                           |
|                | BETWEEN  ...AND...          | 显示在某一区间的值(含头含尾)                                 |
|                | IN(set)                     | 显示在in列表中的值，例：in(100,200)                          |
|                | LIKE '张%'<br />LIKE '%涛%' | 模糊查询，Like语句中，<br />%代表零个或多个任意字符，<br />\_代表一个字符，<br />例如：first_name like '_a%'; |
|                | IS NULL <br />IS NOT NULL   | 判断是否为空                                                 |
| **逻辑运算符** |                             |                                                              |
|                | and                         | 多个条件同时成立                                             |
|                | or                          | 多个条件任一成立                                             |
|                | not                         | 不成立，例：where not(salary>100);                           |

需求说明:

```sql
/*
  语法:
      select [distinct]
        * | 列名1 [as 别名1] ,列名2 [as 别名2] ....
      from 表 [where 条件];
   比较运算符:
       > < >= <= <> !=
          条件语法格式:
                字段名 [>|<|>=|<=|<>|!=] 值
       between 起始值 and 结束值 : 范围查询
          作用: 获取某个范围内数据(包头包尾)
          条件语法格式:
                字段名 between 起始值 and 结束值
       in(值1,值2,值3....):
          作用: 用于获取某个字段的 值1,值2,值3的内容 有就显示, 没有就不显示
          条件语法格式:
               字段名 in(值1,值2,值3....)

       like : 模糊查询
          作用: 用于模糊匹配表中数据, 将匹配到的数据返回
          条件语法格式:
               字段名 like '通配符 + 要查询内容 组合'
          通配符有哪些?
             % :  表示 0~N个任意字符
             _ :  表示 1个任意字符

          例如:
              name like '张%' : 查询姓张用户
              name like '张_' : 查询姓张用户,并且名只有1个
              name like '%佳%' : 查询名字里面含有佳的用户
              name like '_佳%' : 查询名字里面第二个字为佳的用户
       is [not] null:  获取某列那些值为null 或者buweinull
           条件语法格式:
               字段名 is [not] null
   逻辑运算符:
       and :  多个条件必须同时都符合的情况获取出来
          条件语法格式:
               条件1 and 条件2 and 条件3 ....
       or  :  多个条件, 将每个条件符合的数据全部获取出来
          条件语法格式:
               条件1 or 条件2 or 条件3 ....
               条件1 or (条件2 and 条件3) ....
       not :  进行取反操作  把符合条件的反向的数据获取到
           条件语法格式:
               not (条件1 or 条件2 or 条件3 ....)
 */
-- 条件查询:
-- 查询商品名称为“花花公子”的商品所有信息：
-- 查询价格为800商品
-- 查询价格不是800的所有商品
-- 查询商品价格大于60元的所有商品信息
-- 查询商品价格在200到800之间所有商品
-- 查询商品价格是200或800的所有商品
-- 查询含有'霸'字的所有商品
-- 查询以'香'开头的所有商品
-- 查询第二个字为'想'的所有商品
-- 商品没有分类的商品
-- 查询有分类的商品
```

条件查询的课上的代码

```sql
-- 条件查询:
-- 查询商品名称为“花花公子”的商品所有信息：
select
  *
from day04_dql.product where pname = '花花公子';
-- 查询价格为800商品
select
  *
from day04_dql.product where price = 800 ;
-- 查询价格不是800的所有商品
select
  *
from day04_dql.product where price != 800 ;

select
  *
from day04_dql.product where price <> 800 ;
select
  *
from day04_dql.product where not price = 800 ;
-- 查询商品价格大于60元的所有商品信息
select
  *
from  day04_dql.product where price > 60 ;
-- 查询商品价格在200到800之间所有商品
select
  *
from day04_dql.product where price between 200 and 800;
select
  *
from day04_dql.product where price >= 200 and price <= 800;
-- 查询商品价格是200或800的所有商品
select
  *
from day04_dql.product where price = 200 or price = 800;
select
  *
from day04_dql.product where price in(200,800);
-- 查询含有'霸'字的所有商品 : 模糊查询
select
  *
from day04_dql.product where pname like '%霸%';
-- 查询以'香'开头的所有商品
select
  *
from day04_dql.product where pname like '香%';
-- 查询第二个字为'想'的所有商品
select
  *
from day04_dql.product where pname like '_想%';
-- 商品没有分类的商品
select
  *
from day04_dql.product where category_id is null ;
-- 查询有分类的商品
select
  *
from day04_dql.product where category_id is not null ;
```
