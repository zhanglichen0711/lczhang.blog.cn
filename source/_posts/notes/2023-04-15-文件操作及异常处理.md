## 1. 异常处理

- 异常捕获
  - try:    尝试执行的代码
  - except Exception as e:    如果报错执行的代码
  - else:    代码没报错执行的代码
  - finally:    代码报不报错都执行的代码

```python
try:
    # 尝试执行的代码
    print(1)
    print(1/0)
except Exception as e:
    # 如果报错执行的代码
    print('出错了',e)   # division by zero
else:
    print('没出错')
finally:
    print('有没有错都输出')
```

## 2. 文件操作

- open()打开函数
  - 打开已经存在的文件
  - 创建一个新文件
  - 文件对象=open(文件名，打开模式，编码格式)
  - file=文件名
  - mode=打开模式
    - r  只读，文件不存在则报错
    - w 覆盖写入，文件不存在则先创建文件
    - a 追加写入，
    - b 二进制流
    - w+ 读写文件
    - wb+ 二进制方式读写文件
    - r+ 读写文件
    - rb+ 而兼职方式读写文件
    - wb 二进制方式写入文件
    - a+ 追加创建文件
    - ab 二进制方式追加文件
    - ab+ 二进制方式追加创建文件
  - encoding=编码格式
- close()关闭函数
  - 文件对象.close()
- read()读操作
  - 文件对象.read(num)
    - num表示读取的长度
    - 不写num代表全读
  - 文件对象.readline
    - 一次读取一行
    - 再调用读取第二行
- with open() as f
  - 文件操作执行后自动关闭

```python
# 1.打开文件
f = open('text.txt', 'r', encoding='utf-8')
# 2. 读取文件内容
# 2.1 read
#  读取全部
print(f.read())
# 读取1个字符
print(f.read(1))
# 2.2 readline
# 读取一行
print(f.readline())
# 读取第二行
print(f.readline())
# 3. 关闭文件
f.close()

# 打开文件
f = open('123.txt', 'w', encoding='utf-8')
# 写入文件
f.write('学python,来黑马')
# 关闭文件
f.close()

# 读取
f1=open(
    file='image.png',        # 读取图片用二进制，不用设置encoding
    mode='rb+',
)
content=f1.read()
print(content)
# 要复制的文件
f2=open(
    file='图片.png',
    mode='wb+',
)
f2.write(content)
f1.close()
f2.close()

```

- 文件夹操作
  - os.remove
    - 删除文件
  - os.rmdir
    - 删除文件夹
  - os.mkdir
    - 创建文件夹
  - with open
    - 创建文件
  - os.listdir
    - 获取当前文件夹下的内容列表

```python
import os
# 1. 文件重名名
os.rename('text.txt','text1.txt')
# 2. 文件删除
os.remove('图片.png')
# 3. 创建新文件夹
os.mkdir('test')
# 4.切换当前路径
print(os.getcwd())
# 4.1 切换到test，直接找test下的东西
os.chdir('test')
# 4.2 基于当前文件的相对路径找test下的文件
with open('test/test.py'):
     print(1)
# 5. 获取目录下的文件+文件夹
print(os.listdir())
# 6.删除指定的目录（空目录）
os.rmdir('test')

# 获取环境变量
os.getenv()
```
