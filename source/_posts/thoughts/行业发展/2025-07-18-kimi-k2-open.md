七月中旬，月之暗面发布了 Kimi K2。如果说 R1 让开源摸到了推理前沿，Qwen3 让开源覆盖了全尺寸，那 K2 的意义是第三个维度——**开源第一次做到了万亿参数规模，并且性能真的对齐了闭源前沿。**

## 和上一代 / 同行的差异

K2 是一个总参数 1 万亿的 MoE 模型，但每次推理只激活 32B 参数。对比一下这组数字的含义：

- **对 Kimi 自己**：上一代 K1.5 是稠密架构，K2 直接跳到万亿 MoE——架构路线的切换比参数增长本身更值得注意；
- **对开源生态**：此前最大的开源 MoE 是 Qwen3-235B、DeepSeek V3 的 671B，K2 是第一个迈过 1 万亿门槛的开放权重模型；
- **对闭源**：发布时的评测里，K2 在数学、代码、Agent 任务上对齐了当时的 GPT-5 和 Claude 4.5 这一档——**"开源落后闭源一代"的说法第一次站不住脚。**

## 对应用层最实际的两点

**激活参数才是真成本。** 很多人看到"1 万亿参数"以为推理会很贵，但 MoE 的推理成本由激活参数决定——32B 激活意味着单次推理的成本和一个小几十 B 的稠密模型差不多，能力却摸到前沿。K2 的 API 定价（约 0.15 美元 / 百万输入、2.5 美元 / 百万输出）比同档闭源低一个量级。**总参数负责能力上限，激活参数负责成本下限，这俩得分开看。**

**Agent 场景是被点名优化的。** K2 发布时官方强调它在多步工具调用、长任务执行上的表现，跑分也集中在 Agentic 任务上。对正在做 Agent 的人来说，这比"综合榜第一"更有信号意义——**厂商开始为 Agent 的真实负载训练模型了**，而不只是刷学术基准。

## 权重开源那一步（更新）

K2 发布后权重也逐步开放。权重到手意味着：之前只能通过 API 用的前沿级能力，现在可以自托管、可以按自己的数据微调——数据敏感项目第一次能"把前沿模型放进自己机房"。

## 记一笔

行业一年前在争论"Scaling Law 是不是失效了"，今年开源侧连着给出 R1、Qwen3、K2 三个答案。观察下来有个稳定的规律：**开源和闭源的差距从来不在"有没有能力"，而在"能力能不能被自托管"。** K2 把这条线又往前推了一大截——对做应用的人，可选的前沿模型第一次不再是"那两家的 API"。
