下半年海外两大闭源厂商的发布节奏，信息量比参数更大。八月初 OpenAI 放出 GPT-5，九月底 Anthropic 跟进 Claude Sonnet 4.5，中间还夹着各家小模型。把它们放一起看，能读出这两家在往哪个方向押注。

## GPT-5：和 GPT-4o 的差异

GPT-5 相比 GPT-4o 是跨代提升，但更有信号意义的是它的**形态变化**：

- **推理默认内置**：不再像 o 系列那样单独一个"思考版"，GPT-5 把慢思考整合进主模型，用户不需要自己判断"这题要不要用推理模型"——**模型自己决定想多久。**
- **免费开放**：发布即向免费用户开放，这是 OpenAI 第一次把旗舰能力直接放到免费入口——抢入口、抢习惯的意图很明显。
- **代码与 Agent 负载**：官方重点展示的不是聊天，而是长任务、工具使用、代码仓库级操作。

## Claude 4.5：把编码和上下文卷到极致

Anthropic 的 Sonnet 4.5 干脆把目标对准了开发者：

- **编码成为第一卖点**：官方定位是"最强的编码模型"，配合 Claude Code 做 agentic 编程，SWE-bench 一类的代码任务成为主战场——它不跟你比写诗，比的是改仓库。
- **1M 上下文（beta）**：窗口从 200K 拉到 1M，长文档、大代码库整库进上下文成为可能——**这对 RAG 是一个隐性的路线冲击**：以前必须检索，现在模型"读得下更多"，两种方案在长上下文场景开始正面竞争。
- 同场还有 Haiku 4.5 主打速度和低价（约 1 美元 / 百万输入、每秒处理上万 token），把"快模型"也拉到了接近前沿的水平。

## 合起来读：都在为 Agent 铺路

分开看是两家厂商，合起来看信号高度一致：

- 推理从"特殊模式"变成"默认行为"（GPT-5）——因为 Agent 每步都需要判断；
- 编码和长任务成为旗舰卖点（两边都是）——因为开发者是第一批重度 Agent 用户；
- 上下文和工具调用被反复强调——因为 Agent 的真实负载就是"长上下文 + 频繁调工具"。

## 对做应用的人意味着什么

**别只盯单点能力，看负载方向。** 这两家下半年卷的东西，恰好是 Agent 生产化的三个瓶颈：推理可靠性、长上下文、工具执行。模型侧在替应用层解决一部分问题，但注意一个反作用——**上下文越长，RAG 的"必要性"论述就越要重新讲清楚**：检索的价值不只是省 token，更是权限过滤和引用溯源，这两件事不会因为窗口变大而消失。

模型在卷什么，往往就是应用层下一个三年的主战场。下半年这个信号指向很明确：**Agent。**
